    api.Data／api.USData

    表格式資料查詢：一次取一張表，回傳 pandas.DataFrame，欄位是中文名稱。台股用 api.Data，美股用 api.USData。

    api.Data 方法摘要

    方法 回傳 說明
    get(table, *args) DataFrame 取一張表
    get_table(type='print') None / dict 列出帳號可用的表與參數

    api.USData 方法摘要

    方法 回傳 說明
    get(table, *args) DataFrame 取一張美股表
    get_table(type='print') None / dict 列出可用的美股表
    get_snapshots(symbols) dict 美股即時報價快照（台股沒有）

    方法說明

    get

    api.Data.get(table, *args)
api.USData.get(table, *args)

    取一張表。

    參數 型別 說明
    table str 表名，見 台股資料一覽、美股資料 api.USData
    *args 該表要的參數，依表而定：股票代號、起訖日（'yyyyMMdd'）、分鐘數、代號 list…

    回傳：pandas.DataFrame。

    api.Data.get('日_K線資料表', '2330', '20261001', '20261029')

            日期 股票代號 開盤價 最高價 最低價 收盤價  成交量 成交筆數 次日開盤參考價
2026-10-01     2330 2490.0 2510.0 2485.0 2510.0 20666.0  57634.0         2510.0
2026-10-02     2330 2505.0 2515.0 2495.0 2500.0 15792.0  65783.0         2500.0
...

    Note

    參數給錯時，錯誤訊息會印出該表的正確用法。表名不存在會拋 ValueError: 找不到 table；帳號方案沒有的表會拋 PermissionError。

    get_table

    api.Data.get_table(type='print')
api.USData.get_table(type='print')

    列出帳號可用的表與每張表要的參數。

    參數 型別 說明
    type str 'print'（預設）印出清單；'dic' 回傳字典

    回傳：type='print' 回傳 None；type='dic' 回傳 {分段: {表名: 參數提示}}。

    t = api.Data.get_table(type='dic')
names = [n for sec in t.values() for n in sec]     # 全部表名

    get_snapshots

    api.USData.get_snapshots(symbols)

    美股即時報價快照，一次查多檔。只有 api.USData 有。

    參數 型別 說明
    symbols list[str] 美股代號，例如 ['AAPL', 'MSFT']

    回傳：dict[str, Symbol]，每檔一個物件，含 open／high／low／close／volume／previousClose／netChange／percentChange／timestamp。

    詳細說明：資料總覽、表格查詢 api.Data、美股資料 api.USData

    api.USData

    美股表格查詢，用法與 api.Data 相同，另有 get_snapshots。可用的表見 美股資料 api.USData。
