    下單串接總覽

    SnowyOwl 負責資料、選股與回測，不直接下單。要把訊號送到券商，以券商提供的 Python API 下單： SnowyOwl 算出「要持有什麼」，券商 API 查出「目前持有什麼」，兩者的差額就是要送出的委託。

    運作方式

    步驟 使用 產出
    計算訊號 SnowyOwl（api.MSMP、api.USMSMP、api.bt.Tools） 目標部位，例如 {'2330': 2, '2317': 1}（張）
    查詢部位 券商 API 目前部位，格式與目標部位相同
    計算差額 本頁的 order_diff() 每檔要買賣的數量
    送出委託 券商 API 委託書號、成交回報

    SnowyOwl 與券商 API 是各自獨立的套件，在同一個 Python 環境安裝即可，兩者的登入互不影響。

    資料日期

    api.MSMP、api.USMSMP 的資料到前一個交易日，bt.Tools.get_fut_ohlc 的資料到昨日。 以這些資料算出的訊號適合在開盤前或開盤後執行，屬於「收盤後決策、隔日執行」的流程。 盤中訊號請用 api.Data 的分 K，見 盤中與分 K。

    支援的券商

    券商 套件 市場 說明頁
    凱基證券 kgisuperpy 台股、台指期 凱基 Superpy
    富邦證券 fubon_neo 台股、台指期 富邦 Neo API
    永豐金證券 shioaji 台股、台指期 永豐 Shioaji

    各券商的帳戶開通、API 申請、憑證與交易規則以券商公告為準。

    計算訊號

    台股選股名單

    以前一交易日的收盤價與成交量篩選，排除 ETF，每檔買 1 張：

    import pandas as pd
import snowyowl as so

api = so.login('user@x.com', 'pwd')
M = api.MSMP

close = pd.DataFrame(M.日_K.Close)
vol   = pd.DataFrame(M.日_K.Volume)          # 單位：張
etf   = set(M.list['etf'])

ma20 = close.rolling(20).mean()
cond = (close.iloc[-1] > ma20.iloc[-1]) & (vol.iloc[-1] >= 5000)
picks = [s for s in cond[cond].index if s not in etf]

target = {s: 1 for s in picks}               # 目標部位：代號 → 張數
print(close.index[-1], len(target))

    台指期方向

    以日 K 收盤價與 20 日均線決定多空，1 為多單 1 口、-1 為空單 1 口：

    df = api.bt.Tools.get_fut_ohlc('TXF', freq='D')
c  = df['收盤價']
direction = 1 if c.iloc[-1] > c.rolling(20).mean().iloc[-1] else -1

    美股選股名單

    api.USMSMP 的 Volume 單位是股，成交值以 Volume × Close 計算。目標部位以股數表示：

    U = api.USMSMP
close = pd.DataFrame(U.日_K.Close)
value = (pd.DataFrame(U.日_K.Volume) * close).iloc[-1]   # 前一交易日成交值（美元）

top = value.nlargest(20).index
ret = close[top].pct_change(20).iloc[-1]
target = {s: 10 for s in ret.nlargest(5).index}          # 20 日漲幅前 5 名，每檔 10 股

    計算差額

    目標部位與目前部位都以 dict（代號 → 數量）表示。差額為正是買進，為負是賣出：

    def order_diff(target: dict, current: dict) -> dict:
    """回傳 {代號: 數量}，正數買進、負數賣出，略過不需變動的代號。"""
    keys = list(target) + [k for k in current if k not in target]
    diff = {k: target.get(k, 0) - current.get(k, 0) for k in keys}
    return {k: v for k, v in diff.items() if v != 0}

order_diff({'2330': 2, '2317': 1}, {'2330': 1, '2454': 1})
    輸出
    {'2330': 1, '2317': 1, '2454': -1}

    各券商頁的「串接 SnowyOwl」一節，示範如何把券商的部位查詢結果轉成 current，再依差額逐檔下單。

    先在模擬環境確認

    下單程式會送出真實委託。請先以券商的模擬（測試）環境確認數量單位、買賣方向與委託條件，再切換到正式環境。
