    富邦 Neo API

    富邦證券的新一代 API fubon_neo 提供台股與期貨選擇權下單。本頁示範台股與台指期下單、查詢庫存，並把 SnowyOwl 算出的目標部位送成委託。 完整功能以 富邦新一代 API 文件 為準。

    安裝與登入

    SDK 自 2026-11-12 起可從 PyPI 安裝：

    pip install fubon-neo

    在此之前，從富邦新一代 API 網站下載 wheel 檔安裝：pip install fubon_neo-<版本>-cp37-abi3-<平台>.whl。

    from fubon_neo.sdk import FubonSDK, Order, FutOptOrder
from fubon_neo.constant import (BSAction, MarketType, PriceType, TimeInForce, OrderType,
                                FutOptMarketType, FutOptPriceType, FutOptOrderType)

sdk = FubonSDK()
accounts = sdk.login("身分證字號", "登入密碼", r"C:\CAFubon\身分證字號\身分證字號.pfx", "憑證密碼")
if not accounts.is_success:
    raise SystemExit(accounts.message)

stock_acc  = next(a for a in accounts.data if a.account_type == "stock")    # 證券帳戶
futopt_acc = next(a for a in accounts.data if a.account_type == "futopt")   # 期貨帳戶

    login 回傳 Result，data 為帳戶清單。所有查詢與下單方法都回傳 Result，以 is_success、message、data 判斷結果。

    使用條件與測試環境

    使用前需有富邦帳戶與數位憑證，並簽署 API 風險使用聲明書、完成連線測試；期貨下單另需向富邦期貨申請。 測試環境以 FubonSDK(30, 3, "wss://neoapitest.fbs.com.tw/TASP/XCPXWS") 連線，測試帳號由富邦新一代 API 網站提供。

    台股下單

    order = Order(
    buy_sell=BSAction.Buy,
    symbol="2330",
    price="1000",
    quantity=1000,
    market_type=MarketType.Common,
    price_type=PriceType.Limit,
    time_in_force=TimeInForce.ROD,
    order_type=OrderType.Stock,
)
res = sdk.stock.place_order(stock_acc, order)
print(res.is_success, res.message)
    參數 說明
    buy_sell BSAction.Buy／Sell
    price 價格，型別為字串。市價單不填
    quantity 股數，1 張為 1000
    market_type MarketType.Common（整股）、IntradayOdd（盤中零股）、Odd（盤後零股）、Fixing（定盤）
    price_type PriceType.Limit（限價）、Market（市價）、LimitUp、LimitDown、Reference
    time_in_force TimeInForce.ROD／IOC／FOK
    order_type OrderType.Stock（現股）、Margin（融資）、Short（融券）、DayTrade（現股當沖）

    盤中零股把 market_type 改為 MarketType.IntradayOdd，quantity 填股數，例如 100。

    台指期下單

    order = FutOptOrder(
    buy_sell=BSAction.Buy,
    symbol="TXFL6",
    price="23000",
    lot=1,
    market_type=FutOptMarketType.Future,
    price_type=FutOptPriceType.Limit,
    time_in_force=TimeInForce.ROD,
    order_type=FutOptOrderType.Auto,
)
res = sdk.futopt.place_order(futopt_acc, order)
    參數 說明
    symbol 商品代號 + 月份字母（A＝1 月 … L＝12 月）+ 年份末碼，例如 2026 年 12 月台指期為 'TXFL6'
    lot 口數
    market_type FutOptMarketType.Future（日盤）、FutureNight（夜盤）
    price_type FutOptPriceType.Limit（限價）、Market（市價）、RangeMarket（範圍市價）、Reference
    order_type FutOptOrderType.New（新倉）、Close（平倉）、Auto（自動）、FdayTrade（當沖）

    刪單與查詢

    方法 說明
    sdk.stock.get_order_results(stock_acc) 當日股票委託，data 為委託清單
    sdk.stock.cancel_order(stock_acc, order_result) 刪單，傳入委託清單中的一筆
    sdk.accounting.inventories(stock_acc) 股票庫存
    sdk.accounting.unrealized_gains_and_loses(stock_acc) 未實現損益
    sdk.futopt.get_order_results(futopt_acc) 當日期貨委託
    sdk.futopt.cancel_order(futopt_acc, order_result) 期貨刪單
    sdk.futopt_accounting.query_single_position(futopt_acc) 期貨部位 
    orders = sdk.stock.get_order_results(stock_acc)
for o in orders.data:
    print(o.order_no, o.stock_no, o.buy_sell, o.quantity, o.filled_qty, o.status)

    庫存 Inventory 的數量以股計：today_qty 為整股餘額，odd.today_qty 為零股餘額。 期貨部位 Position 的 symbol 為帳務代碼（台指期為 "FITX"），tradable_lot 為可交易口數，buy_sell 為多空方向。

    回報事件

    def on_order(code, content):
    print('委託', code, content)

def on_filled(code, content):
    print('成交', code, content)

sdk.set_on_order(on_order)            # 證券委託
sdk.set_on_filled(on_filled)          # 證券成交
sdk.set_on_futopt_order(on_order)     # 期貨委託
sdk.set_on_futopt_filled(on_filled)   # 期貨成交

    回報函式在獨立的執行緒執行，函式內發生的例外不會傳出，需在函式內自行處理。

    串接 SnowyOwl

    以 下單串接總覽 的選股名單 target（代號 → 張數）與 order_diff()，把庫存調整成目標部位：

    inv = sdk.accounting.inventories(stock_acc)
current = {i.stock_no: i.today_qty // 1000 for i in inv.data
           if i.order_type == OrderType.Stock and i.today_qty >= 1000}   # 現股張數

for symbol, qty in order_diff(target, current).items():
    order = Order(
        buy_sell=BSAction.Buy if qty > 0 else BSAction.Sell,
        symbol=symbol, quantity=abs(qty) * 1000,
        market_type=MarketType.Common, price_type=PriceType.Market,
        time_in_force=TimeInForce.IOC, order_type=OrderType.Stock,
    )
    res = sdk.stock.place_order(stock_acc, order)
    if not res.is_success:
        print('送單失敗', symbol, res.message)

    台指期以總覽的 direction（1 或 -1）調整為 1 口多單或空單：

    pos = sdk.futopt_accounting.query_single_position(futopt_acc)
now = sum(p.tradable_lot if p.buy_sell == BSAction.Buy else -p.tradable_lot
          for p in pos.data if p.symbol == "FITX")
diff = direction - now
if diff != 0:
    order = FutOptOrder(
        buy_sell=BSAction.Buy if diff > 0 else BSAction.Sell,
        symbol="TXFL6", lot=abs(diff),
        market_type=FutOptMarketType.Future, price_type=FutOptPriceType.RangeMarket,
        time_in_force=TimeInForce.IOC, order_type=FutOptOrderType.Auto,
    )
    res = sdk.futopt.place_order(futopt_acc, order)
