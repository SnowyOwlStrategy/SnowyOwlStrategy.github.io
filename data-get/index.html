    表格查詢 api.Data

    api.Data 以表格形式查詢台股資料：一次取一張表，回傳 pandas.DataFrame，欄位是中文名稱。 適合查單一標的的明細、完整財報與分 K。美股的 api.USData 用法相同，見 美股資料 api.USData。

    語法

    api.Data.get_table(type='print')    # 列出可用的表與參數
api.Data.get(table, *args)          # 取一張表

    get_table

    列出帳號可用的表名與每張表需要的參數。

    參數

    參數 型別 預設值 說明
    type str 'print' 'print'：印出表名與參數，回傳 None。'dic'：回傳 dict

    回傳

    type='print' 時回傳 None。type='dic' 時回傳 {分段: {表名: 參數}} 的 dict，分段依參數型態區分（多股單期、單股多期、分 K…）。

    範例

    api.Data.get_table()                       # 印出（回傳 None）
t = api.Data.get_table(type='dic')         # 回傳 {分段: {表名: 參數}}
names = [n for sec in t.values() for n in sec]
len(names)
    輸出
    114

    可用的表依帳號方案而定，上例為 2026-10-29 的台股結果。每張表的用途、資料區間與欄位見 台股資料一覽。

    參數標記

    get_table() 以下列標記表示每張表需要的參數，get() 依標記的順序傳入：

    標記 意思 呼叫寫法
    （空白） 不用參數 api.Data.get('台股產業對照表')
    "symbol" 股票代號 api.Data.get('公司基本資料', '2330')
    "symbol" ,"startDate"(yyyyMMdd) ,"endDate"(yyyyMMdd) 代號、起訖日（包含頭尾） api.Data.get('日_K線資料表', '2330', '20261001', '20261029')
    "date"(yyyyMMdd) 日期字串 api.Data.get('成交金額及股本-多檔股票指定時間', '20261029')
    "symbol" ,minutes(1/3/5/15/30/60) 代號、分鐘數 api.Data.get('取得歷史分K(含加權/櫃買指數)', '2330', 5)
    List[symbol、...] 代號 list api.Data.get('批次取得個股預測處置資料', ['2033', '2221'])

    get

    取一張表。

    參數

    參數 型別 說明
    table str 表名，與 get_table() 列出的完全一致
    *args 該表的參數（股票代號、日期、分鐘數…），依 get_table() 標示的順序以位置傳入

    回傳

    pandas.DataFrame。每次呼叫發出一次網路請求，並顯示一行 INFO - Fetching table: ...。

    資料區間依表而定：依起訖日回傳、一次回傳全部歷史，或固定回傳最新 1000 筆。每張表屬於哪一種見 台股資料一覽。

    Note

    api.Data 需要登入時取得授權。登入時若顯示 [系統訊息] Token無效，api.Data 不會建立，見 登入與登出。

    錯誤處理

    錯誤訊息 原因 處理方式
    ValueError: 參數輸入錯誤，正確用法：Data.get('個股季財報資訊-單檔股票多個區間', '2330') 缺少必填參數 依訊息中的正確用法補上參數
    ValueError: 找不到 table: 不存在的表 表名不存在 用 get_table() 確認表名
