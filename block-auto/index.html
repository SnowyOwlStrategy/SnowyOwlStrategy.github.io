    通用積木

    通用積木 a1／a2／a3 讓資料欄位、窗格長度、聚合方式、位移與倍數都由參數指定。 原生積木的合法值無法表達的條件，例如「成交量大於前一日 5 日均量的 1.35 倍」「近 10 日至少 7 日投信買超」，可以用通用積木組成。

    三個通用積木

    積木名稱 代號 算式
    dataA<>dataB+C a1 左側 <> 右側 + 常數
    (dataA-dataB)/abs(dataB)<>C a2 (左側 − 右側) ÷ |右側| <> 常數（變化率）
    dataA/abs(dataB)<>C a3 左側 ÷ |右側| <> 常數（比值）
    • a2／a3 的分母取絕對值；分母為 0 時條件不成立。a3 未指定 right 時分母為 0，條件不成立。
    • a2／a3 的常數是比值：0.2 表示 20%，0.05 表示 5%。a1 的常數是欄位本身的單位（張、元、%）。
    • 美股使用同名積木，以 con_us()／screener_us() 執行，沒有 pool 參數。

    通用積木組成的條件與原生積木相同：可以和其他積木一起 AND，並產生 選股程式碼。

    語法

    api.Block.con_tw('dataA<>dataB+C', left=..., operator=..., **params)
api.Block.con_tw(id='a1', left=..., operator=..., **params)

    參數

    左右兩側各有一組對稱的參數。left 與 operator 必填，其餘都有預設值。

    參數 預設值 說明
    left／right left 必填；right 為 None 資料來源，格式為單一字串 '表.欄'，例如 '日_K.Volume'。right 未指定時右側視為 0
    operator 必填 >、<、>=、<=、==、crossup（向上穿越）、crossdown（向下穿越）
    left_rolling／right_rolling 1 窗格長度。1 表示不聚合、直接取原值。資料不足 N 根時以現有根數計算
    left_agg／right_agg 'mean' 聚合方式：mean、max、min、sum、std、last
    left_shift／right_shift 0 往前位移的根數。1 表示取前一根的值（不含當根）
    left_pct／right_pct 0 該側的增減百分比。35 表示 ×1.35，-20 表示 ×0.8
    const 0（a3 為 1.0） 常數。a1 加在右側；a2／a3 為比較門檻，以比值表示
    continue_days 1 窗格 K：連續成立 K 根才算成立
    continue_times None 近 K 根中至少 M 根成立。未指定時等於 K（全部成立）；M 大於 K 時條件不成立
    rank None 取排名前 N 名。operator='>' 取最大的、'<' 取最小的
    pool ['all'] rank 的排名母體，寫法與 screener_tw(pool=...) 相同，~ 表示排除

    單側的計算方式：

    該側 = agg( data , rolling ).shift(shift) * (1 + pct/100)

    rank 與 pool

    rank 在排名前先套用 pool。使用 rank 時，con_tw() 的 pool 請填與 screener_tw(pool=...) 相同的值。 只在 screener_tw() 指定股池時，排名母體是全市場，前 N 名中不在股池內的股票會被移除，結果少於 N 檔： 例如前 30 名在 pool=['tse','otc','~etf','~KY','~DR'] 內只剩 13 檔；con_tw() 也指定相同的 pool 時則是完整 30 檔。

    從 get_table 取回的參數填值

    get_table_tw() 回傳通用積木的參數清單，自由值參數為 []。填入需要的參數後可直接交給 con_tw()：

    • 值為 [] 的參數視為未指定，使用預設值。
    • left_agg／right_agg 仍是整份清單（['mean','max',...]）時，視為 'mean'。
    p = api.Block.get_table_tw()['dataA<>dataB+C']
p['left'] = '日_三大法人.投信買賣超張數'
p['operator'] = '>'
p['const'] = 200
api.Block.con_tw(p)
# {'id': 'a1', 'left': '日_三大法人.投信買賣超張數', 'left_rolling': 1, 'left_agg': 'mean',
#  ..., 'const': 200, 'continue_days': 1, 'continue_times': None, 'rank': None, 'pool': None}

    估值 日_指標.本益比 .股價淨值比 .市值 .peg

    籌碼集中 其他_籌碼集中.籌碼集中度_20日 .主力買賣超張數_5日 .家數差_20日
    月營收 月_營收.YoY .MoM .金額_千 .累積YoY
    季財報 季財報_財務指標.營業毛利率 .營業利益率 .稅後淨利率 .ROE_稅後權益報酬率 .每股稅後淨利 .負債比率 .營收成長率、季財報_損益表_千.eps（單季）

    週／月頻 週_K.* 月_K.* 週_技術指標.* 月_技術指標.*

    美股（con_us()）可用 日_K.Open/High/Low/Close/Volume、季財報_財務指標.*、季營收.YoY、季股利資訊.*。 美股沒有 漲跌幅、adj_*、日_技術指標、日_三大法人。

    完整的表與欄位見 MSMP 資料表與欄位。

    月、季、年頻資料

    月_營收.*、季財報_財務指標.*、季股利資訊.* 等月、季、年頻資料會自動轉成日頻： 以公告日對齊（月頻為次月 10 日、季頻為財報公告日），下市後的資料自動排除，訊號與所有計算值都以日頻呈現。 最新一期沒有資料的股票（未公告、已下市）不沿用舊值，條件不成立。

    左右兩側頻率不同時，兩側各取最新公告值後對齊，不保證是同一期間。例如 季股利資訊.現金股利（年頻）÷ 季財報 EPS， 2330 在 2026-05-15 為 22.00 ÷ 22.08 = 99.6%，是 2025 全年股利除以 2026Q1 累計 EPS。兩側請盡量使用同頻率的欄位，例如 現金股利_季 配 eps。

    季股利資訊.年殖利率

    季股利資訊.年殖利率 今年度（2026-Y）的列已出現，但多數股票的值為 0 或不完整（2412、2884、1101 為 0.0，2330 為 0.29）。 公告日一到即取代 2025 年的值，因此「殖利率 > 5%」目前只有 2 檔（以 2025-Y 的值計算有 390 檔）。要使用去年的殖利率，請加上 left_shift=1。

    常見說法與參數對照

    說法 寫法 例
    昨日、前一根 *_shift=1 昨日成交量 > 3000 張：left='日_K.Volume', left_shift=1, operator='>', const=3000
    今日、最新一根 不指定 shift left='日_K.Volume', operator='>', const=3000
    N 日均 *_rolling=N, *_agg='mean' 5 日均量 > 2000 張：left_rolling=5, left_agg='mean', const=2000
    N 日最高／最低 *_rolling=N, *_agg='max'／'min' 創 20 日新高：left='日_K.Close', operator='>', right='日_K.Close', right_rolling=20, right_agg='max', right_shift=1
    N 倍 *_pct=(N-1)*100 量 > 前一根 5 日均量 1.35 倍：right_rolling=5, right_agg='mean', right_shift=1, right_pct=35
    連續 N 天 continue_days=N 連 3 天漲：left='日_K.漲跌幅', operator='>', const=0, continue_days=3
    N 天中至少 M 天 continue_days=N, continue_times=M 近 10 日至少 7 日投信買超：left='日_三大法人.投信買賣超張數', operator='>', const=0, continue_days=10, continue_times=7
    近四季合計 *_rolling=4, *_agg='sum' 近四季 EPS > 0：left='季財報_損益表_千.eps', left_rolling=4, left_agg='sum', operator='>', const=0
    成長 X%、較上季增加 X% a2，左右同欄、right_shift=1、const=X/100 單季 EPS 季增 20%：id='a2', left/right='季財報_損益表_千.eps', right_shift=1, operator='>', const=0.2
    佔比 > X% a3，const=X/100 投信買超佔成交量 > 5%：id='a3', left='日_三大法人.投信買賣超張數', operator='>', right='日_K.Volume', const=0.05
    前 N 名 rank=N，並指定 pool 三大法人買超前 30 名：left='日_三大法人.三大法人買賣超_張數', operator='>', const=0, rank=30, pool=[...]
    突破、向上穿越 operator='crossup'（跌破用 'crossdown'） KD 黃金交叉：left='日_技術指標.K', operator='crossup', right='日_技術指標.D'
    排除 X < N operator='>', const=N 排除股價 < 10：left='日_K.Close', operator='>', const=10
    為 0、沒有買賣 operator='==', const=0 投信 20 天沒有買賣：left='日_三大法人.投信買賣超張數', operator='==', const=0, continue_days=20
    • 積木保留符合條件的股票。「排除近 5 日均量 < 2000 張」要寫成 operator='>', const=2000。
    • 買賣超欄位以 > 表示買超、< 表示賣超、== 表示沒有買賣。

    範例

    以下檔數為資料日 2026-09-24 的結果。範例中 N = 'dataA<>dataB+C'、con_tw 即 api.Block.con_tw。

    與常數比較

    right 不指定時右側視為 0，條件即「左側 <operator> 常數」：

    N = 'dataA<>dataB+C'
b = api.Block.con_tw(N, left='日_K.Volume', operator='>', const=3000)
b
    輸出
    {'id': 'a1', 'left': '日_K.Volume', 'left_rolling': 1, 'left_agg': 'mean',
 'left_shift': 0, 'left_pct': 0, 'operator': '>', 'right': None,
 'right_rolling': 1, 'right_agg': 'mean', 'right_shift': 0, 'right_pct': 0,
 'const': 3000, 'continue_days': 1, 'continue_times': None, 'rank': None, 'pool': None}

    api.Block.screener_tw([b], pool=['tse','otc','~etf','~KY','~DR'])['dataframe'].shape[0]
# 222

    # 近 5 日均量 > 2000 張
con_tw(N, left='日_K.Volume', left_rolling=5, left_agg='mean',
       operator='>', const=2000)                                    # 370 檔

# 月營收 YoY > 20%（月頻，自動轉日頻）
con_tw(N, left='月_營收.YoY', operator='>', const=20)                # 793 檔

    兩側比較

    成交量 > 前一根的 5 日均量 × 1.35。right_shift=1 讓均量不含當根：

    b = api.Block.con_tw(N, left='日_K.Volume', operator='>',
                     right='日_K.Volume', right_rolling=5, right_agg='mean',
                     right_shift=1, right_pct=35)
api.Block.screener_tw([b], pool=['tse','otc','~etf','~KY','~DR'])['dataframe'].shape[0]
    輸出
    263

    同一條件也可以用 a3 寫成比值，結果相同（263 檔）：

    con_tw('dataA/abs(dataB)<>C',
       left='日_K.Volume', right='日_K.Volume',
       right_rolling=5, right_agg='mean', right_shift=1,
       operator='>', const=1.35)

    連續成立、計數與排名

    # 前 2~21 天投信買賣超皆為 0
#   left_shift=1 從前一天起算（不含當日）
#   continue_days=20 要求連續 20 根，即前 2~21 天
con_tw(N, left='日_三大法人.投信買賣超張數', left_shift=1,
       operator='==', const=0, continue_days=20)

# 近 10 日中至少 7 日投信買超
con_tw(N, left='日_三大法人.投信買賣超張數', operator='>', const=0,
       continue_days=10, continue_times=7)                         # 88 檔

# 三大法人買賣超 > 300 張，取最大的前 30 名
con_tw(N, left='日_三大法人.三大法人買賣超_張數',
       operator='>', const=300, rank=30,
       pool=['tse','otc','~etf','~KY','~DR'])                       # 30 檔

# 收盤價最低的前 20 名（operator='<' 時 rank 取最小的）
con_tw(N, left='日_K.Close', operator='<', const=9999, rank=20,
       pool=['tse','otc','~etf','~KY','~DR'])                       # 20 檔

    continue_times 也適用於季資料，例如「前 8 季至少 6 季 EPS > 0」：

    con_tw(N, left='季財報_損益表_千.eps', operator='>', const=0,
       continue_days=8, continue_times=6)

    a2 變化率：財報季增

    a2 左右使用同一欄位、右側 shift=1，即「(本季 − 上季) ÷ |上季|」：

    b = api.Block.con_tw('(dataA-dataB)/abs(dataB)<>C',
                     left='季財報_財務指標.營業毛利率',
                     right='季財報_財務指標.營業毛利率',
                     right_shift=1, operator='>', const=0)
api.Block.screener_tw([b], pool=['tse','otc','~etf','~KY','~DR'])['dataframe'].shape[0]
    輸出
    925

    這個條件等同原生積木 毛利率較上一季成長(衰退)（f7），而且可以換成任何財報欄位，例如 營業利益率、稅後淨利率、ROE_稅後權益報酬率、每股淨值。

    要求成長幅度時，常數以比值表示：

    # 單季 EPS 較上季成長 20% 以上
con_tw('(dataA-dataB)/abs(dataB)<>C',
       left='季財報_損益表_千.eps', right='季財報_損益表_千.eps',
       right_shift=1, operator='>', const=0.2)                      # 896 檔

    分母取絕對值，上季虧損時也能正確判斷方向：上季 −0.37、本季 −0.18，變化率為 +51%（虧損縮小）。

    a3 比值：佔比

    # 投信買賣超 / 成交量 > 5%
con_tw('dataA/abs(dataB)<>C',
       left='日_三大法人.投信買賣超張數', right='日_K.Volume',
       operator='>', const=0.05)                                    # 49 檔

    通用積木可以表達的條件

    以下條件都可以用通用積木組成（未註明代號的為 a1）：

    條件 積木與參數
    K > 80 left='日_技術指標.K', operator='>', const=80
    K < 20 同上，operator='<', const=20
    RSI6 > 80 left='日_技術指標.rsi_6', operator='>', const=80
    MACD 柱 > 0 left='日_技術指標.macd_hist', operator='>', const=0
    MACD 黃金交叉 left='日_技術指標.macd_dif', operator='crossup', right='日_技術指標.macd_dea'
    KD 黃金交叉 left='日_技術指標.K', operator='crossup', right='日_技術指標.D'
    ADX > 25 left='日_技術指標.ADX', operator='>', const=25
    穿越布林上軌 left='日_K.Close', operator='crossup', right='日_技術指標.bulin_upper'
    MACD 紅柱連 3 日遞增 a2，left/right='日_技術指標.macd_hist', right_shift=1, const=0, continue_days=3
    ROE > 15% left='季財報_財務指標.ROE_稅後權益報酬率', operator='>', const=15
    毛利率 > 30% left='季財報_財務指標.營業毛利率', operator='>', const=30
    營收 YoY > 20% left='月_營收.YoY', operator='>', const=20
    營收連 3 月 YoY > 0 同上，const=0, continue_days=3
    營收 MoM > 10% left='月_營收.MoM', operator='>', const=10
    營收創 12 月新高 left/right='月_營收.金額_千', right_rolling=12, right_agg='max', right_shift=1
    本益比 < 15 left='日_指標.本益比', operator='<', const=15
    股價淨值比 < 1 left='日_指標.股價淨值比', operator='<', const=1
    殖利率 > 5% left='季股利資訊.年殖利率', operator='>', const=5（今年度的值見上方 note）
    EPS 季增 a2，left/right='季財報_財務指標.每股稅後淨利', right_shift=1, const=0
    任一財報欄位季增 a2，左右同欄位、right_shift=1、const=0
    近四季 EPS > 0 left='季財報_損益表_千.eps', left_rolling=4, left_agg='sum', operator='>', const=0
    前 8 季至少 6 季 EPS > 0 left='季財報_損益表_千.eps', operator='>', const=0, continue_days=8, continue_times=6
    現金股利發放率 > 30% 且近四季 EPS > 0 a3，left='季股利資訊.現金股利_季', right='季財報_損益表_千.eps'，兩側 rolling=4, agg='sum'、const=0.3，再 AND 上一列
    漲幅 > 5% left='日_K.漲跌幅', operator='>', const=5
    漲停（> 9.9%） 同上，const=9.9
    連 3 日上漲 同上，const=0, continue_days=3
    收紅 K left='日_K.Close', operator='>', right='日_K.Open'
    創 20 日新高 left/right='日_K.Close', right_rolling=20, right_agg='max', right_shift=1
    破 20 日低 同上，right_agg='min', operator='<'
    5 日線 > 20 日線 left_rolling=5, left_agg='mean', right_rolling=20, right_agg='mean'
    5 日線與 20 日線黃金交叉 同上，operator='crossup'
    振幅 > 3% a3，left='日_K.High', right='日_K.Low', const=1.03
    成交額前 100 大 left='日_K.成交額_百萬', const=0, rank=100, pool=[...]
    近 5 日均量 > 2000 張 left_rolling=5, left_agg='mean', const=2000
    成交量 > 前一根 5 日均量 × 1.35 right_rolling=5, right_agg='mean', right_shift=1, right_pct=35
    前 2~21 天投信買賣超皆為 0 left_shift=1, operator='==', const=0, continue_days=20
    三大法人買賣超 > 300 張取前 30 operator='>', const=300, rank=30, pool=[...]

    填權息天數 季股利資訊.填權息天數（年頻）

    MSMP 沒有現成欄位，且無法以 rolling、shift、continue 組成的條件，請使用原生積木： 例如連續 N 年配息、葛林布雷排名、分點籌碼、產業分類，以及需要年度對年度對齊的比值。

    以通用積木寫成的具名積木

    台股有一組以 a1／a3 寫成的具名積木，資料來源、聚合方式、位移等已固定，只開放部分參數。 用法與原生積木相同，con_tw(名稱, ...) 會自動帶入固定的值。

    積木名稱 代號 開放的參數
    投信買賣超(張數)連續P日<>N張 a1 continue_days、operator、const
    近N個交易日投信買賣超(千股)<>V a1 left_rolling、operator、const
    近N個交易日三大法人買賣超合計(千股)>0 a1 left_rolling
    連續N年(不含今年)填權息天數皆<M天 a1 continue_days、const
    營業利益率(%)>上一季 a1 無
    稅後純益率(%)>上一季 a1 無
    券資比<>N%的Top20清單 a1 operator、const
    前N季EPS至少有M季<>V元 a1 continue_days、continue_times、operator、const
    近N個交易日投信買超天數>=M天 a1 continue_days、continue_times
    現金股利發放率>N% a3 const（比值，0.05 = 5%）
    近四季EPS>0 a1 無 
    api.Block.con_tw('前N季EPS至少有M季<>V元', continue_days=8, continue_times=6,
                 operator='>', const=0)
# {'id': 'a1', 'continue_days': 8, 'continue_times': 6, 'operator': '>', 'const': 0,
#  'left': '季財報_損益表_千.eps'}

    現金股利發放率>N% 的分母取絕對值，近四季 EPS 為負但仍有配息的公司也會通過（發放率 > 5% 的 1611 檔中有 91 檔）。 要排除這類公司，請再 AND 上 近四季EPS>0。

    完整策略範例

    N = 'dataA<>dataB+C'
B = api.Block
POOL = ['tse', 'otc', '~etf', '~KY', '~DR']

# 量能強
# 昨日成交量 > 3000 張，且最新一根量 > 前一根 5 日均量 ×1.35
b1 = B.con_tw(N, left='日_K.Volume', left_shift=1, operator='>', const=3000)
b2 = B.con_tw(N, left='日_K.Volume', operator='>',
              right='日_K.Volume', right_rolling=5, right_agg='mean',
              right_shift=1, right_pct=35)
B.screener_tw([b1, b2], pool=['tse','otc','~etf'])          # 32 檔

# 外資關注
# 近 5 日均量 > 2000 張，前 2~21 天投信買賣超皆為 0，當日投信買超 > 50 張
c1 = B.con_tw(N, left='日_K.Volume', left_rolling=5, left_agg='mean',
              operator='>', const=2000)
c2 = B.con_tw(N, left='日_三大法人.投信買賣超張數', left_shift=1,
              operator='==', const=0, continue_days=20)
c3 = B.con_tw(N, left='日_三大法人.投信買賣超張數', operator='>', const=50)
B.screener_tw([c1, c2, c3], pool=POOL)   # 當日 0 檔，全期 460 次 / 262 個交易日

# 三大法人買超 Top30
d1 = B.con_tw(N, left='日_三大法人.三大法人買賣超_張數',
              operator='>', const=300, rank=30, pool=POOL)
B.screener_tw([d1], pool=POOL)                              # 30 檔

    「外資關注」當日沒有股票同時符合三個條件（第二個條件 1361 檔、第三個條件 60 檔，交集為空），sig 形狀為 (1000, 1877)，欄數正常。 全期共有 460 次訊號，最近一次是 2026-09-08 的大銀微系統（4576）。sig 欄數的判讀見 執行選股。

    用於回測

    通用積木的 sig 與原生積木格式相同（日期 × 股票代號的 bool 矩陣），可以直接作為回測的訊號欄：

    r = B.screener_tw([c1, c2, c3], pool=POOL)
df['sig'] = df['DateTime'].map(r['sig'][SYM]).fillna(False)
core.feed_data(df, ['DateTime','開盤價','最高價','最低價','收盤價','成交量'],
               columns=['sig'])          # 額外欄位需在 columns 宣告

    完整的策略架構見 回測概覽 與 策略範例。

    Tip

    當日的選股結果是以今天的資料選出，不宜直接當作歷史回測的標的。回測請使用固定的股票清單，或以 sig 逐日決定進出場。
