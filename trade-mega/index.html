    兆豐 Speedy API

    兆豐證券的 Speedy API（megaSpeedy）提供台股、期貨選擇權與美股複委託下單。本頁示範台股與台指期下單、查詢庫存，並把 SnowyOwl 算出的目標部位送成委託。 完整功能以 兆豐證券 API 專區 為準。

    安裝與登入

    Speedy API 不從 PyPI 安裝，而是從兆豐證券 API 專區下載壓縮檔。解壓縮後，把以下三項放進程式的工作目錄：

    項目 說明
    megaSpeedy 資料夾 內含 spdOrderAPI.py（交易）、spdQuoteAPI.py（行情）與 DLL。64 位元為 megaSpeedyAPI_64.dll，32 位元為 megaSpeedyAPI.dll
    Temp 資料夾 API 組委託電文時使用，不可刪除
    speedyAPI_config.json 連線設定

    交易 API 以繼承 spdOrderAPI 的方式使用：覆寫 OnConnected、OnLogonResponse 等事件方法，再呼叫 Connect 連線。

    import json, threading
from megaSpeedy.spdOrderAPI import spdOrderAPI

class MegaOrder(spdOrderAPI):
    def __init__(self, user_id, password, accounts):
        super().__init__()
        self.login_args = (user_id, password, accounts)
        self.logon = threading.Event()

    def OnConnected(self):
        self.LogonProxy(*self.login_args)

    def OnLogonResponse(self, IsSucceed, ReplyString):
        print('登入', IsSucceed, ReplyString)
        if IsSucceed:
            self.logon.set()

mega = MegaOrder('A123456789', '登入密碼', '0123456,0234567')   # 證券帳號,期貨帳號（各 7 碼）
if not mega.EnableMEGACA(r'C:\cert\A123456789.pfx', 'A123456789', '憑證密碼'):
    raise SystemExit(mega.GetLastErrorMsg())
mega.Connect('spapitest.emega.com.tw', 56789, 5)   # 主機、埠號、逾時秒數
if not mega.logon.wait(30):
    raise SystemExit('登入失敗或逾時')

mega.SetAccount('TWSE', '7000', '0123456')         # 上市：分公司代號、證券帳號
mega.SetAccount('OTC', '7000', '0123456')          # 上櫃
mega.SetAccount('TAIFEX', 'F030000', '0234567')    # 期貨：分公司代號固定為 F030000
    方法 說明
    EnableMEGACA(pfx_path, pfx_id, pfx_pwd) 載入 PFX 憑證：路徑、憑證身分證字號、憑證密碼。成功回傳 True
    Connect(IP, Port, TimeoutSec) 連線交易主機，連上後觸發 OnConnected
    LogonProxy(ID, Password, Account) 登入：身分證字號（大寫）、電子交易密碼、帳號。證券與期貨帳號各 7 碼，以逗號分隔
    SetAccount(Exchange, BrokerID, Account) 設定下單帳號。Exchange 為 'TWSE'（上市）、'OTC'（上櫃）、'TAIFEX'（期貨），需大寫
    GetLastErrorMsg() 最近一次的錯誤訊息
    IsConnected()／Disconnect() 查詢連線狀態／中斷連線

    使用條件與測試環境

    Speedy API 僅支援 Windows，下單需使用 PFX 格式憑證（由「憑證e點通」申請與展期）。 使用前需有兆豐證券或期貨帳戶，簽署 API 風險預告暨使用聲明書，並以權限申請軟體完成申請。 測試環境主機為 spapitest.emega.com.tw（證券、期貨埠號 56789），完成測試並經兆豐通知開通後， 將 Connect 與 speedyAPI_config.json 的主機改為 spapi.emega.com.tw。 證券與期貨下單上限為每秒 20 筆。

    台股下單

    nid = mega.SendNewOrderEx('tse', 'snowyowl', '2330', 1000, 'B', 1, 'L', 'R', 'N', 'A', '0')
if nid == 0:
    print('送單失敗', mega.GetLastErrorMsg())

    SendNewOrderEx 依序傳入下表參數，回傳當日唯一的委託序號 NID，0 表示欄位錯誤或簽章失敗。

    參數 說明
    Market 'tse'（上市）、'otc'（上櫃）、'fut'（期貨）、'opt'（選擇權），需小寫
    UDD 自訂字串，最多 15 個英數字，會帶回回報事件
    Symbol 股票代號
    Price 價格，型別為數字
    Side 'B'（買進）、'S'（賣出）
    OrderQty 數量。整股為張數，零股為股數
    OrderType 'L'（限價）、'M'（市價）、'P'（範圍市價）
    TimeInForce 'R'（ROD）、'I'（IOC）、'F'（FOK）
    TradingSession 'N'（一般）、'I'（盤中零股）、'O'（盤後零股）、'A'（盤後定價）
    PositionEffect 證券填 'A'
    TWSEOrdType '0'（現股）、'3'（融資）、'4'（融券）、'A'（現股當沖）

    盤中零股把 TradingSession 改為 'I'，OrderQty 填股數，例如 100。

    台指期下單

    nid = mega.SendNewOrderEx('fut', 'snowyowl', 'TXFL6', 23000, 'B', 1, 'L', 'R', 'N', 'A', '')

    期貨與台股使用同一個 SendNewOrderEx，差異如下：

    參數 說明
    Market 'fut'
    Symbol 商品代號 + 月份字母（A＝1 月 … L＝12 月）+ 年份末碼，例如 2026 年 12 月台指期為 'TXFL6'，小台為 'MXFL6'
    OrderQty 口數
    TradingSession 'N'
    PositionEffect 'A'（自動新平倉）、'D'（當沖）
    TWSEOrdType 期貨填空字串 ''

    刪單、改單與查詢

    刪單與改單需要委託書號 OrderID，由 OnReplyNewOrder 事件取得（與 SendNewOrderEx 回傳的 NID 不同）。

    方法 說明
    SendCancelOrderEx(Market, UDD, Symbol, Price, Side, OrderID, TradingSession, TWSEOrdType) 刪單
    SendReplaceOrderEx(Market, UDD, Symbol, OrderID, Side, Price, OrderQty, OrderType, TimeInForce, TradingSession, TWSEOrdType) 改價或減量：改價時 OrderQty 填 0，減量時 Price 填 0
    makeStockAccountInquriy(param) 股票庫存，stksumList 為各檔持股
    queryStkOrder(param)／queryStkMatch(param) 股票委託／成交
    queryFutUncoverRT(param) 期貨未平倉部位，dataList 為各筆部位
    queryFutOrder(param)／queryFutMatch(param) 期貨委託／成交
    queryMargin(param) 期貨權益數與保證金

    查詢方法以 dict 傳入參數，回傳 JSON。證券帳務的 branch_id 為分公司代號，期貨帳務的 branch_id 固定為 '098'：

    def parse(r):
    return json.loads(r) if isinstance(r, str) else r

inv = parse(mega.makeStockAccountInquriy({'branch_id': '7000', 'cust_id': '0123456'}))
for s in inv['stksumList']:
    print(s['stkno'], s['stkna'], s['trade'], s['qtyl'], s['qtybm'], s['qtysm'])
    欄位（stksumList） 說明
    stkno、stkna 股票代號、名稱
    trade 交易別：'0' 現股、'3' 融資、'4' 融券、'A' 現股當沖
    stype 市場別：'H' 上市、'O' 上櫃、'R' 興櫃
    qtyl 昨餘額股數
    qtybm／qtysm 今日買進／賣出成交股數
    qtyc 調整股數（現償或匯撥），負數為減少
    t32unit 每張股數

    期貨部位 dataList 的欄位以 v1～v27 表示：v5 為買賣別（'B'／'S'），v6 為商品代碼，v7 為商品月份（yyyymm），v10 為未平倉口數（字串，例如 '0053'）。代碼與月份欄位右側補空白，使用前先 strip()。

    回報事件

    在 spdOrderAPI 的子類別覆寫以下方法，接收委託與成交回報：

    class MegaOrder(spdOrderAPI):
    # ...接續「安裝與登入」的類別

    def OnReplyNewOrder(self, NID, UDD, Symbol, Price, Side, OrderQty, OrderType, TimeInForce, OrderID):
        print('委託', NID, Symbol, Side, OrderQty, OrderID)

    def OnRejectOrder(self, NID, UDD, ActionFrom, ErrCode, ErrMsg):
        print('失敗', NID, ActionFrom, ErrCode, ErrMsg)    # ActionFrom：N 新單、C 刪單、R 改單

    def OnFill(self, NID, UDD, OrderID, ReportSequence, FillPrice, FillQty, FillTime):
        print('成交', OrderID, FillPrice, FillQty, FillTime)
    事件 說明
    OnReplyNewOrder 新單委託成功，OrderID 為委託書號
    OnReplyCancelOrder 刪單成功
    OnReplyReplaceOrder 改單成功
    OnRejectOrder 新單、刪單或改單失敗
    OnFill 成交回報
    OnDisconnected 連線中斷

    以 NID 對應 SendNewOrderEx 送出的委託。在其他平台（如兆豐贏家）下的委託不會觸發回報事件，但可透過查詢方法取得與刪單。

    串接 SnowyOwl

    以 下單串接總覽 的選股名單 target（代號 → 張數）與 order_diff()，把庫存調整成目標部位。 上市或上櫃以 api.MSMP.list 判斷：

    otc = set(api.MSMP.list['otc'])
num = lambda x: int(float(x or 0))

inv = parse(mega.makeStockAccountInquriy({'branch_id': '7000', 'cust_id': '0123456'}))
current = {}
for s in inv['stksumList']:
    if s['trade'] != '0':                       # 只計現股
        continue
    shares = num(s['qtyl']) + num(s['qtybm']) - num(s['qtysm']) + num(s['qtyc'])
    lots = shares // num(s['t32unit'])
    if lots > 0:
        current[s['stkno']] = current.get(s['stkno'], 0) + lots   # 現股張數

for symbol, qty in order_diff(target, current).items():
    market = 'otc' if symbol in otc else 'tse'
    side = 'B' if qty > 0 else 'S'
    nid = mega.SendNewOrderEx(market, 'snowyowl', symbol, 0, side, abs(qty), 'M', 'I', 'N', 'A', '0')
    if nid == 0:
        print('送單失敗', symbol, mega.GetLastErrorMsg())

    台指期以總覽的 direction（1 或 -1）調整為 1 口多單或空單：

    pos = parse(mega.queryFutUncoverRT({'branch_id': '098', 'cust_id': '0234567', 'stock': '', 'currency': ''}))
now = sum(int(p['v10']) * (1 if p['v5'] == 'B' else -1)
          for p in pos['dataList']
          if p['v6'].strip() in ('TXF', 'FITX') and p['v7'].strip() == '202612')
diff = direction - now
if diff != 0:
    nid = mega.SendNewOrderEx('fut', 'snowyowl', 'TXFL6', 0, 'B' if diff > 0 else 'S',
