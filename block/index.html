    積木選股概覽

    api.Block 把選股條件包裝成「積木」：每個積木是一個具名條件，帶有固定的參數與合法值。 組合多個積木後執行選股，可以取得符合條件的股票清單、各積木的計算值、訊號矩陣，以及等價的可執行程式碼。

    運作方式

    選股分成四個步驟：

    步驟 方法 說明
    查詢積木 get_table_tw() 列出每個積木的代號、參數與合法值
    組合條件 con_tw(name, **params) 把積木與參數組成條件 dict
    執行選股 screener_tw(block_list, pool=None, date='now') 多個條件同時成立（AND）的股票
    取用結果 r['dataframe']、r['date']、r['sig']、r['code'] 選股結果、資料日期、訊號矩陣、程式碼 
    # 查詢積木：參數能填什麼
api.Block.get_table_tw()['今日收盤價<>開高低P%']
# {'id': 'o1',
#  'operator': ['<', '>'],
#  'ohlc_field': ['adj_Open', 'adj_High', 'adj_Low'],
#  'percent': [1, 2, 3, 5, 7, 9]}

# 組合條件：未指定的參數使用預設值
b1 = api.Block.con_tw('今日收盤價<>開高低P%',
                      operator='>', ohlc_field='adj_High', percent=3)
# {'id': 'o1', 'operator': '>', 'ohlc_field': 'adj_High', 'percent': 3,
#  'close_field': 'adj_Close', 'period': 1}

# 執行選股：多個條件之間是 AND
r = api.Block.screener_tw([b1])

# 取用結果
r['dataframe']   # 符合條件的股票與各積木的計算值
r['date']        # 結果對應的資料日期
r['sig']         # 訊號矩陣（日期 × 股票代號，值為 bool）
r['code']        # 等價的可執行程式碼

    積木數量為台股 416 個、美股 260 個（2026-10-21）：

    len(api.Block.get_table_tw()), len(api.Block.get_table_us())
    輸出
    (416, 260)

    原生積木的參數合法值無法表達的條件，可以改用 通用積木 自行指定資料欄位、窗格、聚合方式與位移。

    快速範例

    組合兩個積木執行一次選股：

    b1 = api.Block.con_tw('今日收盤價<>開高低P%',
                      operator='>', ohlc_field='adj_High', percent=3)
b2 = api.Block.con_tw('今日收盤價(開低高)與近D日內最高價<P%',
                      period=20, percent=5)
r = api.Block.screener_tw([b1, b2])
print(r['date'], r['dataframe'].shape)

    台股與美股方法對照

    台股與美股各有一組方法，市場已綁定在方法名稱上：

    台股 美股 用途
    get_table_tw() get_table_us() 每個積木的參數與合法值
    con_tw(name, **params) con_us(name, **params) 組合條件
    screener_tw(block_list, pool=None, date='now') screener_us(block_list, date='now') 執行選股

    美股沒有股池，screener_us() 沒有 pool 參數。同名積木在台股與美股的參數可能不同，兩邊需各自查詢。

    本章內容

    頁面 說明
    查詢積木 get_table_tw()／get_table_us()：積木代號、參數與合法值
    組合條件 con_tw()／con_us()：把積木與參數組成條件
    執行選股 screener_tw()／screener_us()：執行選股與回傳結構
    股池 pool 參數與 api.MSMP.list 股票分群
    通用積木 a1／a2／a3：自訂資料欄位與比較方式
    選股程式碼 r['code']：閱讀與執行積木的等價程式碼
    台股積木一覽 台股全部積木的說明、參數與合法值
    美股積木一覽 美股全部積木的說明、參數與合法值
