    積木 Block 總覽

    所屬章節：積木 Block 以 2026-08-20 實際執行結果為準（台股 402 個積木、美股 257 個）

    Overview

    api.Block 把選股條件包成「積木」：每個積木是一個具名條件，帶固定的參數與合法值。 組好一組積木後交給 screener，回傳符合條件的股票清單、中間計算值，以及等價的可執行程式碼。

    台股與美股各一組同名結尾的方法，market 已綁定，呼叫端不用再傳：

    台股 美股 用途
    list_conditions_tw(category=None) list_conditions_us(category=None) 列出註冊的積木與其 metadata
    get_table_tw() get_table_us() 每個積木的參數與合法值
    con_tw(name, **params) con_us(name, **params) 組出一個積木 dict
    screener_tw(block_list, pool=None, date='now') screener_us(block_list, date='now') 執行選股

    標準流程

    # 1. 查有哪些積木、參數能填什麼
api.Block.get_table_tw()['今日收盤價<>開高低P%']
# {'operator': ['<', '>'],
#  'close_field': ['adj_Open', 'adj_High', 'adj_Low'],
#  'percent': [1, 2, 3, 5, 7, 9]}

# 2. 組積木（不指定的參數走預設值）
b1 = api.Block.con_tw('今日收盤價<>開高低P%',
                      operator='>', close_field='adj_High', percent=3)
# {'id': 'o1', 'operator': '>', 'close_field': 'adj_High', 'percent': 3}

# 3. 執行（多個積木是 AND）
r = api.Block.screener_tw([b1])

# 4. 取用
r['dataframe']   # 符合的股票 + 各積木的中間值
r['date']        # 這批結果對應的資料日期
r['sig']         # 完整訊號矩陣（日期 × 股票代號 的 bool）
r['code']        # 等價的可執行 python 程式碼

    Manual Sample Input/Output

    Example 1：積木數量

    input

    len(api.Block.get_table_tw()), len(api.Block.get_table_us())

    output

    (402, 257)

    input

    len(api.Block.list_conditions_tw()), len(api.Block.list_conditions_us())

    output

    (406, 298)

    list_conditions 比 get_table 多，因為前者讀 condition registry（程式碼裡註冊的 全部類別），後者讀 block_spec.json（只收 Excel 中「狀態＝啟用」的積木）。 多出來的積木無法用 con 建立，詳見 積木清單查詢。

    Example 2：完整一次選股

    input

    b1 = api.Block.con_tw('今日收盤價<>開高低P%',
                      operator='>', close_field='adj_High', percent=3)
b2 = api.Block.con_tw('今日收盤價(開低高)與近D日內最高價<P%',
                      period=20, percent=5)
r = api.Block.screener_tw([b1, b2])
print(r['date'], r['dataframe'].shape)
r['dataframe'].head(3)
