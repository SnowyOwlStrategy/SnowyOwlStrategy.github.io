    執行選股

    screener_tw()／screener_us() 以一組條件執行選股，回傳符合條件的股票、各積木的計算值、訊號矩陣與等價程式碼。 多個條件之間是 AND。條件用 組合條件 的 con_tw()／con_us() 建立。

    語法

    api.Block.screener_tw(block_list, pool=None, date='now')     # 台股
api.Block.screener_us(block_list, date='now')                # 美股

    參數

    參數 型別 預設值 說明
    block_list list[dict] con_tw()／con_us() 建立的條件清單，彼此為 AND
    pool list[str] None 選股範圍，僅台股。None 等同 ['all']（全市場），見 股池
    date str 'now' 'now'、'last' 或 'YYYY-MM-DD'，說明如下
    date 取用的資料日期
    'now' 今天（含）以前最後一個有資料的日期
    'last' 訊號矩陣的最後一列
    'YYYY-MM-DD' 該日期（含）以前最後一個有資料的日期

    盤中執行時 MSMP 資料只到前一交易日，'now' 與 'last' 通常相同。 月頻、季頻資料的日期可能排到未來（例如 api.MSMP.INDEX['Q'] 最後一筆是 2026-11-16），此時 'last' 會取到未來的日期，取當日結果請用 'now'。

    回傳

    dict，包含四個 key：

    key 型別 說明
    dataframe DataFrame 符合條件的股票，一列一檔，含各積木的計算值
    date Timestamp 結果對應的資料日期
    sig DataFrame 訊號矩陣，日期（index）× 股票代號（columns），值為 bool
    code str 等價的可執行程式碼，見 選股程式碼

    dataframe 的欄位：

    欄位 說明
    stock_id 股票代號
    sig 最終訊號，只列出通過的股票，因此全部為 True
    cond<N>_sig 第 N 個積木的訊號
    cond<N>_* 第 N 個積木的計算值，欄名依積木而定
    • dataframe 依股票代號排序。要挑選標的時，請自行依成交額或積木的計算值排序。
    • 沒有股票符合條件時，dataframe 是 (0, 0) 的空 DataFrame，沒有任何欄位。
    • sig 是完整的歷史訊號矩陣，不只當日。

    範例

    以下範例的資料日為 2026-08-19（美股 2026-08-18）。

    單一條件

    b1 = api.Block.con_tw('今日收盤價<>開高低P%',
                      operator='>', ohlc_field='adj_High', percent=3)
r = api.Block.screener_tw([b1])
print(list(r))
print(r['date'], r['dataframe'].shape, r['sig'].shape)
r['dataframe'].head(3)
    輸出
    ['code', 'dataframe', 'date', 'sig']
2026-08-19 00:00:00 (2343, 8) (1000, 2865)

  stock_id   sig  cond1_sig  cond1_close  cond1_ohlcData  cond1_ohlc_processed  cond1_olhc_metrics  cond1_comparison_ratio
0   00400A  True       True      14.7200         14.3600               11.0725             10.7500                 1.3294
1   00401A  True       True      13.3800         13.1500               10.8150             10.5000                 1.2372
2   00402A  True       True       9.7200          9.6300                9.1670              8.9000                 1.0603

    sig 包含 1000 個交易日 × 2865 檔。

    多個條件

    b1 = api.Block.con_tw('今日收盤價<>開高低P%',
                      operator='>', ohlc_field='adj_High', percent=3)
b2 = api.Block.con_tw('今日收盤價(開低高)與近D日內最高價<P%',
                      period=20, percent=5)

print(api.Block.screener_tw([b1])['dataframe'].shape[0], '檔（僅積木1）')
print(api.Block.screener_tw([b2])['dataframe'].shape[0], '檔（僅積木2）')
r = api.Block.screener_tw([b1, b2])
print(r['dataframe'].shape[0], '檔（AND）')
list(r['dataframe'].columns)
    輸出
    2343 檔（僅積木1）
1040 檔（僅積木2）
816 檔（AND）

['stock_id', 'sig',
 'cond1_sig', 'cond1_close', 'cond1_ohlcData', 'cond1_ohlc_processed',
 'cond1_olhc_metrics', 'cond1_comparison_ratio',
 'cond2_sig', 'cond2_close', 'cond2_high', 'cond2_rolling_high',
 'cond2_distance_pct']

    條件增加時，cond<N>_* 欄位依序累加。

    指定日期

    for d in ('now', 'last'):
    r = api.Block.screener_tw([b1], date=d)
    print(f"date={d!r} -> {r['date']}, {r['dataframe'].shape[0]} 檔")
    輸出
    date='now' -> 2026-08-19 00:00:00, 2343 檔
date='last' -> 2026-08-19 00:00:00, 2343 檔

    美股

    b = api.Block.con_us('今日收盤價<>開高低P%',

r = api.Block.screener_us([b])
print(r['date'], r['dataframe'].shape, r['sig'].shape)
r['dataframe'].head(3)

    沒有股票符合條件

    以下條件要求收盤價高於當日最高價的 1.03 倍，不會有股票符合：

    b = api.Block.con_us('今日收盤價<>開高低P%',
                     operator='>', field1='High', percent=3)
r = api.Block.screener_us([b])
print(r['dataframe'].shape, list(r['dataframe'].columns), r['sig'].shape)
    輸出
    (0, 0) [] (1000, 13169)

    此時 dataframe 沒有 stock_id 欄。取股票代號時請先確認筆數：

    df = r['dataframe']
symbols = df['stock_id'].tolist() if len(df) else []

    選不出股票時，可從 r['sig'].shape 的欄數判斷原因：

    sig 欄數 意義
    不為 0（如上例的 13169） 條件正常，只是當日沒有股票符合
    0 積木沒有產生訊號

    自行讀取訊號矩陣

    當日結果請用 r['dataframe'] 與 r['date']。季頻積木的 sig 可能多出一列未來的公告日： 例如 2026-10-21 時季財報已有 2026-Q3 的列，轉為公告日 2026-11-16。 自行讀取 sig 時，先截到今天，或對齊到日 K 的日期：

    import pandas as pd

sig = r['sig'].loc[:pd.Timestamp.today()]
# 或對齊到日 K 的日期
sig = r['sig'].reindex(api.MSMP.日_K.adj_Close.index)

    依計算值排序

    dataframe 依股票代號排序。要取計算值最大的幾檔，請自行排序：

    df = r['dataframe']
df.sort_values('cond1_comparison_ratio', ascending=False).head(5)

    首次執行

    積木用到的 MSMP 欄位在第一次使用時才下載，執行過程會顯示下載進度：

    輸出
    正在下載 最高價: 100%|##########| 10.6M/10.6M [00:01<00:00, 5.71MB/s]
下載成功
正在下載 最低價: 100%|##########| 6.63M/6.63M [00:01<00:00, 5.11MB/s]
下載成功

    因此同一組條件第一次執行約 6 秒，第二次約 0.8 秒。

    錯誤處理

    錯誤訊息 原因 處理方式
    KeyError: 'stock_id' 沒有股票符合條件時，dataframe 沒有欄位 先以 len(df) 確認筆數
    TypeError（pool） screener_us() 沒有 pool 參數 美股不傳 pool
    ValueError: percent1 (5) must be greater than percent2 (9) 參數之間的關係不成立（漲跌幅介於P1%到P2%之間 的 percent1 須大於 percent2） 依訊息調整參數
