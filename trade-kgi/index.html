    凱基 Superpy

    凱基證券的 Python API kgisuperpy 提供台股、台指期與複委託下單。本頁示範台股與台指期下單、查詢部位，並把 SnowyOwl 算出的目標部位送成委託。 完整功能以凱基證券的 kgisuperpy 文件為準。

    安裝與登入

    pip install kgisuperpy

    import kgisuperpy as kgi

api = kgi.login('身分證字號', '密碼', simulation=True)   # True：測試環境，False：正式環境
api.set_Account('證券帳號')        # 設定後才有 api.Order
api.set_FutAccount('期貨帳號')     # 設定後才有 api.FutOrder
    參數 型別 預設值 說明
    person_id str 身分證字號
    person_pwd str 密碼
    simulation bool True True 為測試環境，False 為正式環境

    api.show_account() 列出可用的帳號。

    正式環境的條件

    正式環境下單需要有效的 CA 憑證，並完成 API 風險預告書簽署與程式驗證。 測試環境的開放時段：證券為營業日 08:30 至隔日 05:00，期貨為 10:00～22:00。

    台股下單

    api.Order.create_order(action, symbol, qty, price=None,
                       time_in_force=kgi.TimeInForce.ROD,
                       order_cond=kgi.OrderCond.CASH,
                       odd_lot=False)
    參數 說明
    action kgi.Action.Buy／kgi.Action.Sell
    symbol 股票代號，例如 '2330'
    qty 正整數。整股以張計，零股以股計
    price 數字為限價；或 kgi.PriceType.MKT（市價）、LimitUp、LimitDown、Reference。None 時買進以漲停價、賣出以跌停價送出
    time_in_force kgi.TimeInForce.ROD／IOC／FOK
    order_cond kgi.OrderCond.CASH（現股）、MARGIN（融資）、SHORT_SELLING（融券）等
    odd_lot kgi.OddLot.Common（整股）、Odd（盤中零股）、Odd_AfterMarket（盤後零股）、Fixing（盤後定價）；傳 False／True 時依下單時間自動選擇整股或零股的交易時段

    呼叫即送出委託，成功時回傳 Trade 物件，失敗時回傳 None。

    # 2330 限價買進 1 張
trade = api.Order.create_order(action=kgi.Action.Buy, symbol='2330', qty=1, price=1000,
                               odd_lot=kgi.OddLot.Common)

# 盤中零股：qty 為股數
trade = api.Order.create_order(action=kgi.Action.Buy, symbol='2330', qty=100, price=1000,
                               odd_lot=kgi.OddLot.Odd)

    台指期下單

    api.FutOrder.create_order(action, symbol, qty, price,
                          time_in_force=kgi.TimeInForce.ROD,
                          position_effect=kgi.PositionEffect.Auto)
    參數 說明
    symbol 商品代號 + 月份字母（A＝1 月 … L＝12 月）+ 年份末碼，例如 2026 年 11 月台指期為 'TXFK6'
    qty 口數
    price 數字為限價；或 kgi.PriceType.MKT（市價）、kgi.PriceType.RangeMarket（範圍市價）
    position_effect kgi.PositionEffect.New（新倉）、Close（平倉）、DayTrade（當沖）、Auto（自動） 
    trade = api.FutOrder.create_order(action=kgi.Action.Buy, symbol='TXFK6', qty=1,
                                  price=kgi.PriceType.MKT,
                                  time_in_force=kgi.TimeInForce.IOC,
                                  position_effect=kgi.PositionEffect.Auto)

    刪單與查詢

    方法 回傳 說明
    api.Order.get_trades() dict 有效委託，key 為委託書號，value 為 Trade
    api.Order.cancel_order(order_id) Trade 刪單，可傳委託書號或 Trade
    api.Order.cancel_order_all() 刪除全部有效委託
    api.Order.get_deals() dict 今日成交，key 為股票代號
    api.Order.get_position() DataFrame 股票庫存，index 為股票代號
    api.FutOrder.get_trades()／cancel_order()／get_position() 期貨的對應方法

    委託書號在收到委託成功回報後才會產生，刪單請在回報之後進行。

    api.Order.get_position() 的數量欄位是 4 個元素的 list，依序為零股（股）、現股（張）、融資（張）、融券（張）：

    欄位 說明
    quantity_yd 昨日餘額
    quantity_B／quantity_S 今日買進／賣出成交
    quantity_td 今日持股餘額
    dealPrice_cash\|margin\|short 現股、融資、融券均價
    lastprice／unrealized／realized 市價、未實現損益、已實現損益

    回報事件

    以 set_event 註冊委託與成交回報。回報是 Event 物件，以屬性取值：

    def on_event(ev):
    if ev.task == kgi.Task.Deal:
        print('成交', ev.symbol, ev.action, ev.quantity, ev.price, ev.ts)
    elif ev.status == kgi.Status.Failed:
        print('失敗', ev.order_id, ev.msg)
    else:
        print(ev.task, ev.status, ev.order_id)

api.Order.set_event(on_event)
api.FutOrder.set_event(on_event)

    串接 SnowyOwl

    以 下單串接總覽 的選股名單 target（代號 → 張數）與 order_diff()，把庫存調整成目標部位：

    pos = api.Order.get_position()
current = {s: int(q[1]) for s, q in pos['quantity_td'].items() if q[1] > 0}   # 現股張數

for symbol, qty in order_diff(target, current).items():
    trade = api.Order.create_order(
        action=kgi.Action.Buy if qty > 0 else kgi.Action.Sell,
        symbol=symbol, qty=abs(qty), price=None,          # 買進以漲停價、賣出以跌停價送出
        odd_lot=kgi.OddLot.Common)
    if trade is None:
        print('送單失敗', symbol)

    台指期以總覽的 direction（1 或 -1）調整為 1 口多單或空單：

    fp = api.FutOrder.get_position()
row = fp[fp['symbol'] == 'TXFK6']
now = int(row['quantity_B'].sum() - row['quantity_S'].sum())   # 淨口數
diff = direction - now
if diff != 0:
    api.FutOrder.create_order(action=kgi.Action.Buy if diff > 0 else kgi.Action.Sell,
                              symbol='TXFK6', qty=abs(diff), price=kgi.PriceType.MKT,
                              time_in_force=kgi.TimeInForce.IOC,
                              position_effect=kgi.PositionEffect.Auto)
