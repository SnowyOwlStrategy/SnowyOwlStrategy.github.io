    snowyowl 與 api

    import snowyowl as so 之後用 so.login() 登入，取得 api 物件；所有功能都掛在 api 底下。

    函式摘要

    函式 說明
    so.login(person_id=None, person_pwd=None, type='account') 登入，回傳 api 物件

    api 成員摘要

    成員 型別 說明
    api.Data 物件 台股表格查詢
    api.USData 物件 美股表格查詢、即時快照
    api.MSMP 物件 台股矩陣資料（日期 × 代號）
    api.USMSMP 物件 美股矩陣資料
    api.bt 物件 回測引擎
    api.logout() 方法 登出並清除登入快取
    api.login() 方法 重新登入
    api.person_id／api.person_pwd／api.type str 登入時提供的帳號、密碼、登入方式

    功能範圍

    功能 提供方式
    表格查詢 api.Data（台股 114 張表，2026-10-29）、api.USData（美股 25 張表）
    矩陣資料 api.MSMP、api.USMSMP；台指期 1 分 K 在 api.MSMP._fut_TXF（2017-05 起）
    回測 api.bt
    盤中快照 美股 api.USData.get_snapshots()；台股以 api.Data.get() 查詢分 K
    即時行情訂閱 不提供
    下單與帳務 不提供

    函式說明

    so.login

    so.login(person_id=None, person_pwd=None, type='account')

    登入並回傳已初始化的 api 物件。

    參數 型別 說明
    person_id str 帳號。type='account' 時必填
    person_pwd str 密碼。type='account' 時必填
    type str 'account'（帳號密碼，預設）、'google'、'apple'（開啟瀏覽器登入，不需帳密）

    回傳：api 物件。

    import snowyowl as so

api = so.login('帳號', '密碼')          # 帳號密碼
api = so.login(type='google')          # Google 帳號（開啟瀏覽器）

    Note

    帳號或密碼留空時會顯示「登錄失敗」且不會登入。Google／Apple 登入首次需在瀏覽器驗證，之後 72 小時內不必重新驗證。

    詳細說明：登入與登出

    api 方法說明

    api.logout

    api.logout()

    清除 api 上的功能，並刪除本機登入快取（~/.snowyowl/auth.json）。帳號資訊會保留，可直接用 api.login() 重新登入。

    api.login

    api.login(person_id=None, person_pwd=None, type=None)

    重新登入。參數省略時沿用原本的值。

    api.logout()
api.login()        # 用原本的身分重新登入
