    回測概覽

    api.bt 是事件驅動的回測引擎：繼承 Core 撰寫策略、餵入 K 線逐根執行，再依商品設定產生績效報告。

    功能組成

    [n for n in dir(api.bt) if not n.startswith('_')]
    輸出
    ['Core', 'Tools', 'config', 'generate_report']
    成員 說明 詳細說明
    api.bt.Core 策略基底類別。繼承後覆寫 on_bar 等事件方法撰寫策略 撰寫策略、下單與成交
    api.bt.config(...) 商品設定：交易稅、手續費、合約乘數、保證金 商品設定與績效報告
    api.bt.generate_report(...) 把跑完的策略彙整成績效報告 商品設定與績效報告
    api.bt.Tools 歷史 K 線下載與參數最佳化 資料與週期、技術指標與參數最佳化

    config 與 generate_report 的簽名：

    import inspect
print(inspect.signature(api.bt.config))
print(inspect.signature(api.bt.generate_report))
    輸出
    (name: str = 'strategy', symbol: str = 'symbol', tax_long: float = 0, tax_short: float = 0, daytrade_discount: float = 1, fee: float = 0, unit: int = 1, margin_long: float = 1, margin_short: float = 1, lot_size: str = 'inf,0,floor,1') -> None
(core_dic: dict, margin_call: bool = False, capital=1000000, benchmark=None)

    Note

    api.bt 需要有效的登入授權。登入時顯示 Token無效 時不會建立 api.bt，見 登入與登出。

    基本流程

    1. 準備 K 線資料（DataFrame），需要時加上自訂的訊號欄。
    2. 繼承 api.bt.Core，在 on_bar 中用 self.Condition.Global() 下單。
    3. 建立策略實例，用 feed_data() 餵入資料，引擎逐根 K 棒執行策略並撮合委託。
    4. 用 api.bt.config() 設定商品的交易成本與合約乘數。
    5. 用 api.bt.generate_report({config: core}) 產生報告，查看 rp.report、rp.trade_detail 或 rp.dashboard()。

    快速範例：單檔均線策略

    以 2330 的還原價日 K 回測均線策略：MA20 在 MA60 之上且空手時，以 20 萬元買進；MA20 跌回 MA60 之下時全部賣出。程式取自 策略範例 的「單檔技術指標策略」。

    import pandas as pd

bt = api.bt

def daily_bars(api, symbol, adj=True):
    """回傳可直接餵 feed_data 的 df。adj=True 用還原價。"""
    k = api.MSMP.日_K
    p = 'adj_' if adj else ''
    cols = {'開盤價': f'{p}Open', '最高價': f'{p}High', '最低價': f'{p}Low',
            '收盤價': f'{p}Close', '成交量': f'{p}Volume' if adj else 'Volume'}
    df = pd.DataFrame({zh: getattr(k, en)[symbol] for zh, en in cols.items()})
    df.index.name = 'DateTime'
    return df.dropna().reset_index()      # ← dropna 必要，未上市期間是 NaN

SYM, AMOUNT = '2330', 200_000
df = daily_bars(api, SYM, adj=True)

class MaCross(bt.Core):
    def on_init(self):                      # 只放參數與狀態，下單會 RuntimeError
        self.n_fast, self.n_slow = 20, 60
        self.amount = AMOUNT
        self.close_list = []

    def on_bar(self, row):
        self.close_list.append(row['Close'])         # row 的 key 一律英文
        fast = self.Ind.rolling_mean(self.close_list, self.n_fast)
        slow = self.Ind.rolling_mean(self.close_list, self.n_slow)
        self.char['ma20'], self.char['ma60'] = fast[-1], slow[-1]   # 進 char 才上圖
        if len(self.close_list) < self.n_slow:
            return                                   # 暖身期不下單

        if fast[-1] > slow[-1] and self.global_qty == 0:
            qty = self.amount / row['Close']         # ★ 股數，必須搭 unit=1
            self.Condition.Global(True, qty, 0, self.PriceType.market_ioc, None, 'bk')
        elif fast[-1] < slow[-1] and self.global_qty > 0:
            self.Condition.Global(True, -self.global_qty, 0,
                                  self.PriceType.market_ioc, None, 'bp')

core = MaCross()
core.feed_data(df, ['DateTime', '開盤價', '最高價', '最低價', '收盤價', '成交量'])

cfg = bt.config(name='MA20_60_2330', symbol=SYM,
                fee=0.001425, tax_long=0, tax_short=0.003, unit=1)   # 個股稅率（ETF 用 0.001）
bench = df.set_index('DateTime')['收盤價']                           # buy&hold 對照
rp = bt.generate_report({cfg: core}, capital=1_000_000, benchmark=bench)
rp.dashboard(path='dashboard_ma.html', view='web')      # ★ 腳本裡要給 path；'web' = 存檔並開瀏覽器

    說明：

    • 日 K 從 api.MSMP.日_K 取得。使用還原價時，整組欄位都用 adj_*（含 adj_Volume）；dropna() 去掉未上市期間的 NaN。
    • feed_data() 的 args 依序指定時間與開高低收量的欄名；自訂的額外欄位要列在 columns，row 中才有這個 key。
    • qty = 金額 / 價格 是股數，要搭配 unit=1。台股證交稅只在賣出時收取，所以只填 tax_short=0.003，tax_long 維持 0。各類標的的設定見 商品設定與績效報告。
    • 指標寫進 self.char 才會畫在 K 線上。
    • 在 on_bar 送出的 market_ioc 委託以下一根 K 棒的開盤價成交，見 下單與成交。

    KPI 的定義見 商品設定與績效報告。

    報告內容

    屬性／方法 型別 內容
    rp.report DataFrame 績效 KPI。Strategy 欄為合併結果；多策略時每個 config.name 各一欄
    rp.trade_detail DataFrame 逐筆交易，21 欄，含 name／symbol／direction／pnl／cost
    rp.trade_main DataFrame 委託層級明細，進場與出場各一列
    rp.position DataFrame 部位變化
    rp.daily DataFrame 每日權益曲線，13 欄（含每日回撤金額 dd）
    rp.daily_close DataFrame 每日收盤價
    rp.dashboard() 方法 產生互動式 HTML 報表（總覽／績效分析／交易明細／個股分析四頁）
    rp.save(path=None) 方法 存成一個 xlsx 檔
    rp.set_benchmark(series) 方法 設定基準指數

    逐筆交易的屬性名稱是 rp.trade_detail。各表欄位見 商品設定與績效報告。

    多檔組合

    Core 一次處理一個商品。回測多檔組合時，每檔各建立一個策略實例，再把 {config: core} 字典一起交給 generate_report()，在報告中合併成組合。

    要讓多檔共用一份資金，下單數量填 0～1 的比例（投入當下資金的比例），capital 才會生效；數量填 1 以上的固定數量時，capital 不參與計算。

    core_dic = {}
for s in SYMS:
    c = PctStrategy()                  # 每檔一個策略實例，進場數量為 1/檔數
    c.feed_data(daily_bars(api, s), ['DateTime','開盤價','最高價','最低價','收盤價','成交量'])
    core_dic[api.bt.config(name=s, symbol=s, fee=0.001425,
                           tax_long=0, tax_short=0.003, unit=1000)] = c

rp = api.bt.generate_report(core_dic, capital=10_000_000)
print(rp.report['Strategy'])

    完整程式（含策略類別與儀表板）見 策略範例 的「多檔組合（共用資金池）」。

    讀取組合結果

    • Strategy 欄是組合結果：所有標的的交易依時間合併，共用一份 capital 計算。
    • 其餘各欄（以 config.name 命名）是該檔獨占全部資金的單獨結果，加總不等於 Strategy。

    進場比例與資金

    比例下單時，每筆進場的資金 ＝ 起始資金 ＋ 進場時間之前已實現的損益，不扣除未平倉部位占用的資金。多檔同時持有時，每檔都以同一份資金計算口數，比例 × 同時持有檔數大於 1 時，總部位會超過資金。比例取 1/檔數，總部位不會超過資金。

    資金 × 比例不足以買進一個單位（例如以張計時的一張台股）時，該筆口數依 lot_size 的 floor 取整為 0。詳細的計算方式見 商品設定與績效報告。

    錯誤處理

    錯誤訊息 原因 處理方式
    RuntimeError: make_daily: 每日損益全為 0，無法產生報表。
    常見原因是 pandas / numpy 版本不相容導致索引對不起來，...    		 所有交易的口數都是 0。最常見的情況是比例下單時，資金 × 比例買不起一張（台股一張 1000 股），口數取整為 0 提高 capital、減少檔數，或改用 unit=1 以股計
