    矩陣資料 MSMP

    api.MSMP（台股）與 api.USMSMP（美股）以矩陣提供歷史資料：每個欄位都是一張日期（index）× 股票代號（columns）的 DataFrame。 適合全市場的橫向運算，例如選股、排名與回測。

    資料在登入時下載到本機快取，使用時不需要授權。美股的差異見 美股矩陣資料 USMSMP。

    語法

    api.MSMP.日_K.Close            # 屬性存取
api.MSMP.get('日_K', 'Close')  # 字串存取，適合以變數指定表與欄位

    成員

    成員 型別 說明
    <表名>.<欄位> DataFrame 日期 × 股票代號的矩陣。表與欄位見 MSMP 資料表與欄位
    get(table, name) DataFrame 同上，以字串指定表名與欄位
    get_table() 印出 列出所有表與欄位
    list dict 股池
    INFO DataFrame 全市場基本資料（代號、名稱、上市日、下市日）
    INDEX dict 各頻率的日期序列（'D'、'M'、'Q'）
    TSE／OTC 物件 加權／櫃買指數（單欄矩陣）
    TSE_週／OTC_週／TSE_月／OTC_月 物件 指數的週／月頻
    DataFrame(df) ProboDataFrame 把一般 DataFrame 包成可與 MSMP 矩陣運算的型態
    msmp_to_dic(names, *dfs) dict 寬表轉長表，以股票代號分組
    _fut_TXF DataFrame 台指期 1 分 K，見 資料期間與頻率

    資料日期

    MSMP 的資料到前一個交易日。以 index[-1] 取得資料日期：

    api.MSMP.日_K.Close.index[-1]

    當日盤中資料請用 api.Data 的分 K，見 盤中與分 K。台股日頻的歷史長度（2026-10-21 為 500 筆）見 資料期間與頻率。

    重複使用的欄位先存成變數

    每次存取 api.MSMP.日_K.adj_Open 這類欄位都會發出一次資料請求（2026-10-21：存取 6 次發出 6 個請求）。在迴圈中重複使用同一個欄位時，先存成變數：

    import pandas as pd
o = pd.DataFrame(api.MSMP.日_K.adj_Open)

    常用查詢

    import pandas as pd
M = api.MSMP
k = M.日_K                                    # index 日期，columns 股票代號
k.Close.index[-1]                              # 資料日

t = k.漲跌幅.iloc[-1].dropna()
t[t >= 5].sort_values(ascending=False)         # 最後一個交易日漲幅 5% 以上
t[t >= 9.9]                                    # 漲停
k.成交額_百萬.iloc[-1].dropna().nlargest(5)     # 成交金額前 5 名（百萬元）
k.Close['2330'].dropna().tail(20)              # 某檔最近一個月

C = M.日_三大法人                               # 三大法人近一週（單位：張）
pd.DataFrame({z: getattr(C, z)['2330'] for z in
              ['外資買賣超張數', '投信買賣超張數', '自營買賣超張數',
               '三大法人買賣超_張數', '八大行庫_買賣超張數']}).tail(5)
(C.持股張數_外資['2330'] / C.發行總張數['2330'] * 100).iloc[-1]   # 外資持股比例 %

r = M.月_營收
r.金額_千['2330'].dropna().iloc[-1] / 1e5      # 最新月營收（億元；金額_千 ÷ 1e5）
name = M.INFO.set_index('股票代號')['股票名稱']  # 補股票名稱

    排行加上成交額門檻

    2026-10-20 漲幅前 10 名中有成交額只有 0.2、0.5 百萬元的股票。做漲幅排行時，加上 成交額_百萬 門檻，或在結果旁列出成交額。

    股池 list

    api.MSMP.list 是股池的 dict，key 是股池名稱（上市、上櫃、興櫃、ETF 等），value 是股票代號清單。美股 api.USMSMP 沒有 list。

    api.MSMP.list['tse']
api.MSMP.get('list', 'tse')   # 同上

    搭配矩陣篩選

    股池成員可以直接用來篩選 MSMP 矩陣的欄位（股票代號）：

    close = api.MSMP.日_K.adj_Close
tse_only = close.loc[:, close.columns.isin(api.MSMP.list['tse'])]

    全市場排除 ETF：

    mask = ~close.columns.isin(api.MSMP.list['etf'])
no_etf = close.loc[:, mask]

    取不重複的代號清單

    api.MSMP.list['all'] 中代號 '7834' 出現兩次：

    lst = api.MSMP.list['all']
len(lst), len(set(lst))
    輸出
    (2873, 2872)

    用 isin() 篩選不受影響。要把清單當作 DataFrame 的 columns 使用時，先去除重複並保持原順序：

    symbols = list(dict.fromkeys(api.MSMP.list['all']))

    未去除重複時，後續 reindex 會出現 InvalidIndexError: Reindexing only valid with uniquely valued Index objects。

    # 個股相對大盤的強弱
rel = api.MSMP.日_K.adj_Close / api.MSMP.TSE.adj_Close

    個股佔大盤的比重

    其他_大盤 與個股矩陣沒有共同的 columns，兩者相除會得到 0 欄的矩陣。個股佔全市場成交的比重，以個股矩陣自行加總計算：

    df = api.MSMP.日_K.成交額_百萬
ratio = df.div(df.sum(axis=1), axis=0) * 100

    9 個回看期間的 Beta：Beta一月、Beta二月、Beta三月、Beta六月、Beta九月、Beta一年、Beta二年、Beta三年、Beta五年。

    api.MSMP.日_CAPM.Beta一年['2330'].dropna().iloc[-1]      # 1.0926

    覆蓋檔數

    需要計算期間的表覆蓋的股票較少（新上市、興櫃股票常沒有值）。以下為 2026-10 的矩陣形狀：

    表 形狀
    日_K 2889 欄
    其他_籌碼集中 (500, 2463)，起始日與 日_K 相同
    日_CAPM (500, 2190)

    跨表運算前先確認 index 對齊，運算後以 .dropna() 去除沒有值的股票。

    錯誤處理

    錯誤訊息 原因 處理方式
    ValueError: 在 '日_K' 中找不到名為 '沒有這欄' 的欄位。 欄位名稱不存在 用 get_table() 或 MSMP 資料表與欄位 確認欄位名稱
    InvalidIndexError: Reindexing only valid with uniquely valued Index objects 以含重複代號的 api.MSMP.list['all'] 當 columns 先用 list(dict.fromkeys(...)) 去除重複，見 股池 list
