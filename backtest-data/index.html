    資料與週期

    策略透過 feed_data()、feed_tick_df() 或 feed_tick() 接收行情資料，引擎依資料逐根觸發事件。bt.Tools 提供個股與期貨的歷史 K 線下載，set_tick_period() 可把小週期資料聚合成指定週期，並支援多週期訊號。

    以下範例中的 bt 即 api.bt，core 為策略實例。

    餵入方式

    方式 呼叫 觸發的事件 適用情況
    整份 K 棒 core.feed_data(df) on_bar、on_intrabar、on_position 速度最快；單一週期、不需要多週期訊號
    週期聚合 core.set_tick_period(...) ＋ core.feed_tick_df(df) 上述事件 ＋ on_bar2／on_bar3、on_other* 多週期訊號；以小週期 K 線模擬盤中，停損停利的觸發順序最精確
    單筆 tick core.set_tick_period(...) ＋ core.feed_tick(row) 同上 即時行情

    feed_data() 不經過週期聚合，所以不會觸發 on_bar2／on_bar3／on_other*。feed_tick() 與 feed_tick_df() 要先呼叫 set_tick_period() 才能使用，設定完成時會顯示 [加載] feed_tick。

    feed_data

    一次餵入一根或多根完整的 K 棒，逐根觸發事件。

    語法

    core.feed_data(df,
               args=['DateTime', '開盤價', '最高價', '最低價', '收盤價', '成交量'],
               columns=['Settlement'])

    參數

    參數 型別 預設值 說明
    df DataFrame — K 棒資料，欄位由 args／columns 對應
    args list ['DateTime','開盤價','最高價','最低價','收盤價','成交量'] 時間、開、高、低、收、量六個欄名，依序對應
    columns list ['Settlement'] 要一併帶進每根 K 棒 row 的額外欄位，例如自訂訊號欄、'Settlement'

    args 只指定哪一欄代表哪個角色，row 中的 key 一律是英文 Open／High／Low／Close／Volume；columns 帶入的欄位保留原本的欄名。row 的完整欄位見 撰寫策略。

    範例

    以自訂欄位作為進出場條件時，該欄要列在 columns，row 中才有這個欄位：

    bars['mysig'] = bars['DateTime'].map(sig_series).fillna(False)
core.feed_data(bars, ['DateTime','開盤價','最高價','最低價','收盤價','成交量'],
               columns=['mysig'])

    K 棒時間

    DateTime 是 K 棒的收盤時間。自備資料時，DateTime 要填 K 棒的結束時間，不是開始時間。 以 feed_tick_df() 聚合時，標記為 09:00 的 K 棒在 period=[['0900','1330']] 下會歸入 10:00 的 K 棒。

    set_tick_period

    設定主商品的聚合週期與交易時段，並啟用 feed_tick()／feed_tick_df()。

    語法

    core.set_tick_period(freq=60,
                     period=[['0845','1345'], ['1500','0500']],
                     need_settlement=True,
                     args=['DateTime','開盤價','最高價','最低價','收盤價','成交量'],
                     columns=[])

    參數

    參數 型別 預設值 說明
    freq int／str／list 60 聚合週期。int 為分鐘數，'D' 為日線。list 為多週期，例如 [60, 'D'] 代表 base 為 60 分（觸發 on_bar）＋ 日線（觸發 on_bar2，純訊號，不進帳務）
    period list [['0845','1345'], ['1500','0500']] 交易時段。預設為期貨日盤 08:45–13:45 ＋ 夜盤 15:00–隔日 05:00；股票常用 [['0900','1330']]
    need_settlement bool True 是否計算結算日（期貨適用）。為 True 時 row 有 Settlement 欄
    args list ['DateTime','開盤價','最高價','最低價','收盤價','成交量'] feed_tick_df() 的欄位對應，同 feed_data()
    columns list [] feed_tick_df() 要帶入每根 K 棒的額外欄位

    freq 為 list 時，freq[0] 觸發 on_bar（進帳務），freq[1] 觸發 on_bar2，freq[2] 觸發 on_bar3，依此類推（純訊號）。設定了第 N 個週期但沒有實作對應的 on_barN 時，框架會顯示警告並略過該週期。

    set_other_period

    設定對標商品的聚合週期。對標商品只提供訊號參考，不進帳務，觸發 on_other／on_other2／on_other3。

    core.set_other_period(freq=60, period=..., need_settlement=True, args=..., columns=[])

    參數與 set_tick_period() 相同，freq 的各週期依序對應 on_other、on_other2、on_other3。

    feed_tick_df

    以 DataFrame 餵入主商品或對標商品的資料，由引擎依 set_tick_period()／set_other_period() 的設定聚合。

    core.feed_tick_df(df1)             # 只餵主商品
core.feed_tick_df(None, df2)       # 只餵對標商品
core.feed_tick_df(df1, df2)        # 主商品與對標商品依時間交錯（同一時點對標商品先執行）

    feed_tick

    逐筆餵入 tick，用於即時行情。

    core.feed_tick({'time': '20260821101500', 'price': 18500.0, 'vol': 3})
    key 說明
    time tick 的時間，字串 'YYYYMMDDHHMMSS'
    price 成交價
    vol 成交量

    Note

    從即時行情的 callback 餵入時，略過 data.total_volume == 0 的快照，避免同一筆成交被重複計入。

    聚合週期 freq

    bt.Tools.get_*_ohlc() 的 freq 與 set_tick_period() 的 freq 使用相同的轉換規則。先轉換好再以 feed_data() 餵入，與餵入小週期資料讓引擎聚合，產生的 K 棒逐根相同：

    # 先轉換好再餵入
dfD = bt.Tools.get_fut_ohlc('TXF', freq='D')
core.feed_data(dfD)

# 餵入小週期，由引擎聚合
df60 = bt.Tools.get_fut_ohlc('TXF', freq=60)
core.set_tick_period(freq='D')
core.feed_tick_df(df60)          # 餵入 1 分 K 也可以，結果相同

    freq 可以是分鐘數（int）或日線（'D'）。日線以日盤加上前一夜盤為同一個交易日。

    歷史 K 線

    bt.Tools 依 symbol 快取資料：原始資料只下載一次，不同 freq／period 組合的聚合結果也各自快取，重複呼叫不會重新下載或重算。下載時會顯示 【'開始下載':XXX ,freq=1】 與 【下載完成】。

    get_fut_ohlc

    取得期貨的歷史 K 線（日盤與夜盤合併）。資料為回溯約 2 年、到昨日為止的 1 分 K，依 freq 聚合。

    bt.Tools.get_fut_ohlc(symbol='TXF', freq=1,
                      period=[['0845', '1345'], ['1500', '0500']])
    參數 型別 預設值 說明
    symbol str 'TXF' 期貨代號。省略或 None 時為 'TXF'。'TXF' 直接讀取預先快取的近期資料，不另外下載；其他商品即時下載
    freq int／str 1 聚合週期。分鐘數或 'D'（日線）
    period list [['0845','1345'], ['1500','0500']] 交易時段

    回傳 DataFrame，欄位如下：

    欄位 說明
    DateTime K 棒的結束時間
    dt_period 這根 K 棒涵蓋的原始資料起訖時間（字串）
    開盤價／最高價／最低價／收盤價／成交量 開高低收量
    Settlement 該筆所屬的結算日
    結算 布林值，標記結算日 13:30 強制切斷的那根 K 棒

    範例

    df     = bt.Tools.get_stock_ohlc('0050', freq=60, adj=False)
df_fut = bt.Tools.get_fut_ohlc('TXF', freq=60)

    從 MSMP 取日 K

    要和自行從 api.MSMP 算出的訊號對齊時，日 K 也從 api.MSMP 取得，日期才會一致，不需要 reindex 或 ffill。get_stock_ohlc() 回傳的是由 1 分 K 聚合的 K 線，與 MSMP 的日頻不同。

    import pandas as pd

def daily_bars(api, symbol):
    k = api.MSMP.日_K
    zh2en = {'開盤價':'Open','最高價':'High','最低價':'Low','收盤價':'Close','成交量':'Volume'}
    df = pd.DataFrame({zh: getattr(k, en)[symbol] for zh, en in zh2en.items()})
    df.index.name = 'DateTime'
    return df.reset_index()

    完整範例見 回測概覽。

    時序檢查

    feed_data()、feed_tick()、feed_tick_df()、feed_other 四個入口都會檢查資料的時間順序，避免時間倒退的資料被當成新的 K 棒，造成 row_list 順序錯亂、self.row 變成舊價格、停損停利以錯誤的價位判斷。

    檢查分為兩步：

    步驟 對象 處理方式
    排序 同一批資料內部的順序 餵入前檢查是否依時間遞增，未遞增時自動穩定排序並顯示提示
    過濾 與先前已餵入資料重疊的區段 整段略過，並顯示一行摘要

    各種情況的處理：

    情況 處理方式
    同一批資料內部時間亂序 自動穩定排序後餵入
    同一份 df 內同一時間有多列 全部收下，維持原本的相對順序
    時間與前一筆相同（單筆 feed_tick()） 收下（同一秒多筆成交屬正常）
    與先前已餵入資料重疊的區段 整段略過
    邊界上時間完全相同的一列 feed_tick_df() 略過（資料為累加，重複會重算成交量）；feed_data() 保留（整根覆蓋，可用來重新餵入以更新當前 K 棒）
    時間落在 period 交易時段之外的 tick 略過，不歸入任何 K 棒，並顯示警告

    主商品與對標商品各自檢查，互不影響。分段餵入時，後一段的起始時間不可早於前一段的結尾，重疊的部分會被略過。

    警告訊息

    輸出
    [警告] 主商品資料時間 20240102103000 早於前一筆 20240102120000，已忽略（時序守門）
[警告] feed_tick_df 主商品: DateTime 沒有依時間遞增，已自動排序後才餵入
[警告] feed_data: 有 2 列時間早於已餵入的前一筆，已忽略（時序守門）

    Tip

    出現排序提示時，表示原始資料未依時間排序，建議檢查資料來源。
