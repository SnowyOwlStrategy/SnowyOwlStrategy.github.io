    策略範例

    常見回測寫法的範例集，每個範例示範一種寫法，可依自己的規格組合使用。範例只示範寫法，參數不是建議值，也不附績效數字。

    共用前置

    import sys
sys.path.insert(0, r'<snowyowl_project 路徑>')    # 用原始碼樹時才需要；pip 裝的不用
import pandas as pd
import snowyowl as so

api = so.login(type='google')        # 或 so.login('user@x.com', 'pwd')
bt = api.bt

    取日 K 的函式

    回測用的日 K 從 api.MSMP 取。bt.Tools.get_stock_ohlc 是由 1 分 K resample 而成，與 MSMP 的日頻資料對不上，下載量也較大。

    def daily_bars(api, symbol, adj=True):
    """回傳可直接餵 feed_data 的 df。adj=True 用還原價。"""
    k = api.MSMP.日_K
    p = 'adj_' if adj else ''
    cols = {'開盤價': f'{p}Open', '最高價': f'{p}High', '最低價': f'{p}Low',
            '收盤價': f'{p}Close', '成交量': f'{p}Volume' if adj else 'Volume'}
    df = pd.DataFrame({zh: getattr(k, en)[symbol] for zh, en in cols.items()})
    df.index.name = 'DateTime'
    return df.dropna().reset_index()      # ← dropna 必要，未上市期間是 NaN

    Note

    使用還原價時，整組欄位都用 adj_*（含 adj_Volume），不混用還原價與未還原量。

    成本設定

    標的 config
    台股個股（以股計） fee=0.001425, tax_long=0, tax_short=0.003, unit=1
    台股個股（以張計） 同上但 unit=1000，qty 要換算成張數
    台股 ETF（0050／0056…） fee=0.001425, tax_long=0, tax_short=0.001, unit=1
    台指期 fee=500, tax_long=0.00002, tax_short=0.00002, unit=200, margin_long=0.13
    美股 fee=0, tax_long=0, tax_short=0, unit=1

    台股只填 tax_short，tax_long 填 0；兩邊都填會重複計算證交稅。

    單檔技術指標策略

    以每次固定金額進場的單檔均線策略。

    • 標的：2330，還原價
    • 進場：MA20 在 MA60 之上時買進，每次 20 萬元
    • 出場：MA20 跌回 MA60 之下時賣出
    • 部位：qty = 金額 / 價格（股數），搭配 unit=1
    SYM, AMOUNT = '2330', 200_000
df = daily_bars(api, SYM, adj=True)

class MaCross(bt.Core):
    def on_init(self):                      # 只放參數與狀態，下單會 RuntimeError
        self.n_fast, self.n_slow = 20, 60
        self.amount = AMOUNT
        self.close_list = []

    def on_bar(self, row):
        self.close_list.append(row['Close'])         # row 的 key 一律英文
        fast = self.Ind.rolling_mean(self.close_list, self.n_fast)
        slow = self.Ind.rolling_mean(self.close_list, self.n_slow)
        self.char['ma20'], self.char['ma60'] = fast[-1], slow[-1]   # 進 char 才上圖
        if len(self.close_list) < self.n_slow:
            return                                   # 暖身期不下單

        if fast[-1] > slow[-1] and self.global_qty == 0:
            qty = self.amount / row['Close']         # ★ 股數，必須搭 unit=1
            self.Condition.Global(True, qty, 0, self.PriceType.market_ioc, None, 'bk')
        elif fast[-1] < slow[-1] and self.global_qty > 0:
            self.Condition.Global(True, -self.global_qty, 0,
                                  self.PriceType.market_ioc, None, 'bp')

core = MaCross()
core.feed_data(df, ['DateTime', '開盤價', '最高價', '最低價', '收盤價', '成交量'])

cfg = bt.config(name='MA20_60_2330', symbol=SYM,
                fee=0.001425, tax_long=0, tax_short=0.003, unit=1)   # 個股稅率（ETF 用 0.001）
bench = df.set_index('DateTime')['收盤價']                           # buy&hold 對照
rp = bt.generate_report({cfg: core}, capital=1_000_000, benchmark=bench)
rp.dashboard(path='dashboard_ma.html', view='web')      # ★ 腳本裡要給 path；'web' = 存檔並開瀏覽器

    說明：

    • 指標寫進 self.char 才會畫在 K 線上。
    • 在腳本中呼叫 rp.dashboard() 要給 path；view='web' 表示存檔並開啟瀏覽器。
    • 單策略時，報表的欄名是 Strategy（有 benchmark 時多一欄 benchmark），不是 config.name。取值寫成 rp.report['Strategy']。

    多檔組合（共用資金池）

    多檔股票共用同一筆資金，以比例下單。

    • 標的：2330、2317、2454、1301、2882
    • 訊號：MA5 與 MA20 交叉
    • 部位：每檔 qty = 1/檔數
    • 資金：capital=10_000_000

    qty 填 0～1 的比例時，capital 才會生效。以固定口數下單時走向量化路徑，capital 不參與計算。

    SYMS = ['2330', '2317', '2454', '1301', '2882']
W = 1 / len(SYMS)                     # ★ 1/檔數 是安全上限，見下方說明

class PctStrategy(bt.Core):
    def on_init(self):
        self.n_fast, self.n_slow = 5, 20
        self.close_list = []

    def on_bar(self, row):
        self.close_list.append(row['Close'])
        fast = self.Ind.rolling_mean(self.close_list, self.n_fast)
        slow = self.Ind.rolling_mean(self.close_list, self.n_slow)
        if len(self.close_list) < self.n_slow:
            return
        if fast[-1] > slow[-1] and self.global_qty == 0:
            self.Condition.Global(True, W, 0, self.PriceType.market_ioc, None, 'bk')
        elif fast[-1] < slow[-1] and self.global_qty > 0:
            self.Condition.Global(True, -self.global_qty, 0,
                                  self.PriceType.market_ioc, None, 'bp')

core_dic = {}
for s in SYMS:
    c = PctStrategy()
    c.feed_data(daily_bars(api, s), ['DateTime','開盤價','最高價','最低價','收盤價','成交量'])
    core_dic[bt.config(name=s, symbol=s, fee=0.001425,
                       tax_long=0, tax_short=0.003, unit=1000)] = c

rp = bt.generate_report(core_dic, capital=10_000_000)
print(rp.report['Strategy'])          # ★ 只有這一欄是組合，其餘是「該檔獨佔全部資金」
rp.dashboard(path='dashboard_portfolio.html', view='web')

    說明：

    • rp.report 只有 Strategy 欄是組合的績效；其餘各欄是「該檔獨佔全部資金」的單獨視角，逐檔加總不等於 Strategy。
    • 權重上限是 1/檔數：capital 只累加已實現損益，不扣除未平倉部位佔用的資金。N 檔同時進場時，每檔都以同一份 capital 的比例計算口數，weight × 同時持有檔數 > 1 就形成隱性槓桿。
    • capital × weight 買不起一個交易單位（台股以張計為 1000 股）時，floor 會把口數取整為 0；所有口數都為 0 時會出現 RuntimeError: make_daily: 每日損益全為 0。此訊息提到版本相容性，但在這種情況下原因是資金不足。處理方式：提高 capital、減少檔數，或改用零股 unit=1（檔數多、資金小時建議使用零股，見下方「目標權重輪動」）。

    台指期雙均線多空反手

    台指期 30 分 K 的雙均線策略，多空反手並在結算日強制出場。

    • 資料：api.MSMP._fut_TXF（期貨 1 分 K，底線開頭的屬性）
    • 週期：30 分 K，日盤＋夜盤
    • 進場：MA10 上穿 MA30 做多、下穿做空，多空反手
    • 出場：結算日以當根收盤強制平倉
    import numpy as np

df1 = api.MSMP._fut_TXF     # DateTime, Open, High, Low, Close, TotalVolume, settlement

class DualMA(bt.Core):
    def on_init(self):
        self.n_fast, self.n_slow = 10, 30
        self.tick_map = [(np.inf, 1)]        # ★ 期貨最小跳動 1 點，不設會套股票規格
        self.C = []

    def on_bar(self, row):
        self.C.append(row['Close'])
        fast = self.Ind.rolling_mean(self.C, self.n_fast)
        slow = self.Ind.rolling_mean(self.C, self.n_slow)
        if len(self.C) <= self.n_slow:
            return                            # 暖身期不下單
        self.char['fast'], self.char['slow'] = fast[-1], slow[-1]
        mkt = self.PriceType.market_ioc

        # 結算棒：用當根收盤強制平倉，這根不再開新倉
        if row['DateTime'] == row['Settlement']:
            self.Condition.Global(self.global_qty != 0, -self.global_qty, row['Close'],
                                  self.PriceType.compel_now, False, '結算')
            return

        # ★ 「上穿」要比較前一根，不是單純比大小
        cross_up = fast[-2] <= slow[-2] and fast[-1] > slow[-1]
        cross_dn = fast[-2] >= slow[-2] and fast[-1] < slow[-1]

        # ★ 多空反手拆兩張：先平舊倉（net），再開新倉（bk / sk）
        g = self.global_qty
        if cross_up and g <= 0:
            if g < 0:
                self.Condition.Global(True, -g, 0, mkt, None, 'net')
            self.Condition.Global(True, 1, 0, mkt, None, 'bk')
        elif cross_dn and g >= 0:
            if g > 0:
                self.Condition.Global(True, -g, 0, mkt, None, 'net')
            self.Condition.Global(True, -1, 0, mkt, None, 'sk')

core = DualMA()
core.set_tick_period(freq=30, need_settlement=True,      # 30 分 K，日盤+夜盤
                     args=['DateTime','Open','High','Low','Close','TotalVolume'])
core.feed_tick_df(df1)                        # ★ 期貨走 feed_tick_df，不是 feed_data
cfg = bt.config(name='dualma', symbol='TXF', fee=500,
                tax_long=0.00002, tax_short=0.00002, unit=200)
rp = bt.generate_report({cfg: core})
rp.dashboard(path='dashboard_txf.html', view='web')

    說明：

    • 期貨要設定的四項規格：tick_map=[(np.inf,1)]（最小跳動 1 點，不設定時套用股票規格）、fee=500（fee >= 1 時自動切換為每口固定金額）、unit=200、結算日判斷 row['DateTime'] == row['Settlement']。
    • 期貨以 set_tick_period() 搭配 feed_tick_df() 餵資料，不使用 feed_data()。
    • 多週期（例如 30 分進場＋日線過濾）要使用 set_tick_period(freq=[30,'D']) 搭配 feed_tick_df；feed_data 不會觸發 on_bar2。
    • 「上穿」要與前一根比較，不是只比較當根大小。

    多空反手：一張單或兩張單

    兩種寫法都能反手。以下是 2026-10-21 用上面這組參數執行的對照：

    寫法 交易筆數、損益、多空拆分 trade_detail['exit_rule']
    拆兩張（上面的寫法） 完全相同 舊倉出場標成 net、結算標成 結算
    一張補齊：Global(cross_up and g < 1, -g + 1, ...) 完全相同 舊倉出場標成新倉的規則名（bk／sk）

    只看總損益時兩種寫法都可以；要看各進出場規則的績效（儀表板、rp.save() 的規則分頁）時，拆成兩張。

    部位檢查使用 <= 0／>= 0（一張寫法為 < 1／> -1）。若寫成 == 0，只有空手時才會進場，無法反手。

    多空分開看損益：

    td = rp.trade_detail
for d in ('long', 'short'):
    s = td[td['direction'] == d]
    print(f'{d}: {len(s)} 筆, pnl {s["pnl"].sum():,.0f}, 勝率 {(s["pnl"]>0).mean()*100:.1f}%')

    目標權重輪動

    依因子選股，在公告日定期換股，每檔以目標權重下單。

    • 股池：排除 ETF、KY、DR
    • 因子：季報 ROE，取最高的 10 檔
    • 換股：每次季報公告日
    • 可交易性：股價 ≥ 20 元、20 日均成交額前 50%
    • 部位：每檔 qty = 1/10（比例下單），零股 unit=1
    • 資金：100 萬，benchmark 為 0050
    TOP_N, CAPITAL = 10, 1_000_000
M = api.MSMP

# ── 1) 股池：排除 ETF / KY / DR ─────────────────────────
bad = set(M.list['etf']) | set(M.list['KY']) | set(M.list['DR'])
close     = pd.DataFrame(M.日_K.adj_Close)
raw_close = pd.DataFrame(M.日_K.Close)      # ★ 未還原價才是真實股價，門檻用它
vol       = pd.DataFrame(M.日_K.Volume)     # 單位是「張」
univ = [c for c in close.columns if c not in bad]
close, raw_close, vol = close[univ], raw_close[univ], vol[univ]
R = close.index

# ── 2) 可交易性遮罩（排名前先套）────────────────────────
turnover = (raw_close * vol * 1000).rolling(20).mean()     # ★ Volume 是張，要 ×1000
tradable = (turnover.rank(axis=1, pct=True) > 0.5) & (raw_close >= 20)

# ── 3) 因子：季報 ROE，用官方方法轉成公告日 ──────────────
roe = M.季財報_財務指標.ROE_稅後權益報酬率
feat = pd.DataFrame(roe.index_str_to_date()).reindex(columns=univ)
feat = feat.reindex(feat.index.union(R)).ffill().reindex(R)   # union→ffill→reindex

# ── 4) 換股日 = 季報公告日，每次選 top_n ─────────────────
pub = pd.DataFrame(roe.index_str_to_date()).index
score = feat.where(tradable)                  # ★ 先遮罩再排名，母體才一致
picks = {d: score.loc[d].dropna().nlargest(TOP_N).index.tolist()
         for d in sorted(set(pub) & set(R)) if score.loc[d].notna().any()}

# ── 5) 攤成「每天該持有誰」的布林表 ──────────────────────
all_syms = sorted({s for v in picks.values() for s in v})
hold = pd.DataFrame(False, index=R, columns=all_syms)
cur = []
for d in R:
    if d in picks:
        cur = picks[d]
    if cur:
        hold.loc[d, [c for c in cur if c in hold.columns]] = True

# ── 6) 每檔一個 core，qty=1/N 走百分比路徑 ───────────────
W = 1 / TOP_N

class Rotate(bt.Core):
    def on_bar(self, row):
        if row['sig'] and self.global_qty == 0:
            self.Condition.Global(True, W, 0, self.PriceType.market_ioc, None, 'bk')
        elif not row['sig'] and self.global_qty > 0:
            self.Condition.Global(True, -self.global_qty, 0,
                                  self.PriceType.market_ioc, None, 'bp')

k = M.日_K
# ★ 迴圈前先把五個矩陣存成 DataFrame：每存取一次 k.adj_xxx 就發一次 HTTP 請求，
#   在迴圈裡逐檔取，檔數一多會很慢甚至 ReadTimeout
bars = {zh: pd.DataFrame(getattr(k, en)) for zh, en in
        [('開盤價', 'adj_Open'), ('最高價', 'adj_High'), ('最低價', 'adj_Low'),
         ('收盤價', 'adj_Close'), ('成交量', 'adj_Volume')]}
core_dic = {}
for s in all_syms:
    df = pd.DataFrame({zh: m[s] for zh, m in bars.items()}).dropna()
    if len(df) < 100:
        continue
    df.index.name = 'DateTime'
    df = df.reset_index()
    df['sig'] = df['DateTime'].map(hold[s]).fillna(False)
    if not df['sig'].any():
        continue
    c = Rotate()
    c.feed_data(df, ['DateTime','開盤價','最高價','最低價','收盤價','成交量'],
                columns=['sig'])
    core_dic[bt.config(name=s, symbol=s, fee=0.001425,
                       tax_long=0, tax_short=0.003, unit=1)] = c   # ★ unit=1 = 零股

rp = bt.generate_report(core_dic, capital=CAPITAL,
                        benchmark=pd.DataFrame(M.日_K.adj_Close)['0050'].dropna())
print(rp.report['Strategy'])        # ★ 只有這欄是組合
rp.dashboard(path='dashboard_rotation.html', view='web')

    說明：

    • 價格門檻與成交額使用未還原價 Close；Volume 的單位是張，計算成交額要 ×1000。
    • 先以可交易性遮罩過濾，再排名，排名的母體才是可交易的股票。
    • 季報因子以 index_str_to_date() 轉成公告日，再 union → ffill → reindex 對齊到日頻，見下方「訊號驗證」。
    • 每存取一次 k.adj_Open 這類 MSMP 屬性都會發出一次資料請求。迴圈前先把需要的欄位存成 DataFrame；在迴圈中逐檔存取，檔數多時會很慢，甚至出現 ReadTimeout。
    • 報表只看 rp.report['Strategy']，這一欄是組合的績效。

    零股與整股

    unit=1 表示以股計價，也就是零股。小資金做多檔輪動時，實際交易本來就是買零股。以下是另一組設定（capital 100 萬、20 檔、W=1/20）的執行對照：

    設定 結果
    unit=1（零股） 正常執行。單筆進場中位數 53,031 元（≈ capital/20）、股數中位數 1560 股、最小 120 股
    lot_size='inf,0,floor,1000'（整股） 全期只成交 2 筆，無法產生報表

    整股的情況下，capital × 1/20 = 5 萬，買不起一張台股，floor 把口數取整為 0，並出現以下錯誤：

    RuntimeError: make_daily: 每日損益全為 0，無法產生報表。
常見原因是 pandas / numpy 版本不相容…

    這個錯誤在此情況下與套件版本無關，原因是資金不足以買進一個單位。

    需求 設定
    零股（以 1 股為單位） unit=1，lot_size 用預設 'inf,0,floor,1'
    整股（以 1000 股為單位） unit=1 + lot_size='inf,0,floor,1000'，且 capital × W 要買得起一張
    以張數下單（qty 是張數） unit=1000，qty 自行換算成張數

    訊號驗證（IC 與分組單調性）

    在跑回測之前，先檢驗特徵與未來報酬的關係。

    • 特徵：季報營業利益率，轉成公告日後對齊到日頻
    • 目標：未來 20 日報酬
    • 檢驗：IC（逐日橫斷面相關係數）與 5 組分組報酬

    月頻／季頻資料轉成公告日

    月頻、季頻資料的 index 是字串。月_營收 的 index 是 '2026-M08'（營收所屬月份），不是公告日；8 月營收要到 9/10 才公告，直接與日頻資料對齊會用到尚未公告的資料。以 MSMP 矩陣的 index_str_to_date() 轉換：

    rev = api.MSMP.月_營收.YoY          # index: '2026-M06', '2026-M07', '2026-M08'
rev_d = rev.index_str_to_date()     # index: 2026-07-13, 2026-08-10, 2026-09-10
    處理 說明
    月頻 → 次月 10 日 月營收法定公告日，12 月跨年；遇非交易日順延到實際交易日（2026-M06 → 07-13，因為 7/10 是週末）
    季頻 → 財報公告日 Q1→5/15、Q2→8/14、Q3→11/14、Q4→次年 3/21。2025-Q4 → 2026-03-23
    遮蔽下市後的資料 依 delist_dates，下市後布林值填 False、數值填 NaN，避免倖存者偏差

    年頻（'2026-Y'）同樣支援。日期轉換統一使用 index_str_to_date()，不自行組合日期。

    使用 pandas 統計方法前轉成 DataFrame

    MSMP 回傳的是 ProboDataFrame（pd.DataFrame 的子類），相加、相除、比較大小等運算會自動對齊。呼叫 corrwith 這類 pandas 內建統計方法時，若兩邊 index 型態不同會出現：

    TypeError: '<=' not supported between instances of 'str' and 'Timestamp'

    先用 pd.DataFrame() 轉成一般的 pandas DataFrame：

    close = pd.DataFrame(api.MSMP.日_K.adj_Close)     # ← 加這層就好

    一般的矩陣運算保留 ProboDataFrame 即可，以使用自動對齊；只有呼叫 corrwith 這類方法時才需要轉換。

    完整程式碼

    import pandas as pd

close = pd.DataFrame(api.MSMP.日_K.adj_Close)     # ★ 脫殼
fwd = close.shift(-20) / close - 1                # 未來 20 日報酬
R = close.index

# 特徵：季報營業利益率，轉成公告日後對齊到日頻
feat = pd.DataFrame(api.MSMP.季財報_財務指標.營業利益率.index_str_to_date())
feat = feat.reindex(feat.index.union(R)).ffill().reindex(R)   # ★ union→ffill→reindex

# ① IC
ic = feat.corrwith(fwd, axis=1).dropna()
print(f'IC n={len(ic)}, mean={ic.mean():.4f}, IR={ic.mean()/ic.std():.3f}')

# ② 分組單調性（5 組）
q = feat.rank(axis=1, pct=True)
for i in range(5):
    mask = (q > i/5) & (q <= (i+1)/5)
    print(f'  Q{i+1}: {fwd.where(mask).stack().mean()*100:+.2f}%')

    說明：

    • 判讀標準：|IC| > 0.03 視為有訊號；分組報酬要單調才可信。
    • 兩項都未通過時，建議先更換因子或處理極端值，再進行回測。

    參數最佳化

    以 bt.Tools.optimize() 掃描「單檔技術指標策略」的均線參數。

    • 策略：沿用 MaCross、df、cfg
    • 參數範圍：n_fast 5～30（間隔 5）、n_slow 40～120（間隔 10）
    • 評分：CalmarRatio（CAGR / abs(MddRatio)）
    def opt(n_fast=20, n_slow=60):
    core = MaCross()
    core.n_fast, core.n_slow = n_fast, n_slow      # 覆寫 on_init 設的 self.xxx
    core.feed_data(df, ['DateTime','開盤價','最高價','最低價','收盤價','成交量'])
    return bt.generate_report({cfg: core}, capital=1_000_000)

best = bt.Tools.optimize(opt, {'n_fast': [5, 30, 5], 'n_slow': [40, 120, 10]}, times=20)
rp_best = opt(**best)
print(best, rp_best.report.loc['TotalTrades', 'Strategy'])   # ★ 評分不看交易次數，自己印出來
rp_best.dashboard(path='dashboard_best.html', view='web')

    說明：

    • 每次呼叫都建立新的 core。core 會保留狀態，重複使用會累積前一次的部位。
    • 評分 CalmarRatio 不考慮交易次數，可能選出只交易 3 次、剛好都獲利的參數，因此另外印出 TotalTrades。
    • 參數最佳化本身會帶來過度配適，建議至少把資料切成前後兩段分別驗證。

    前後兩段分別驗證

    td = rp.trade_detail
d = pd.to_datetime(td['entry_time'])        # ★ 時間欄是字串，要先轉
mid = d.min() + (d.max() - d.min()) / 2

for label, mask in (('前段', d < mid), ('後段', d >= mid)):
    s = td[mask]
    print(f'{label}: {len(s)} 筆, pnl {s["pnl"].sum():,.0f}, '
          f'勝率 {(s["pnl"]>0).mean()*100:.1f}%')

    trade_detail 的 entry_time／exit_time 是格式化後的字串，不是 datetime64，使用 .dt 前要先以 pd.to_datetime() 轉換。

    兩段差距很大（例如獲利幾乎全部來自其中一段）時，表示參數反映的是某段特定行情，而不是穩定的優勢。

    更嚴格的做法是只在前段尋優、以後段驗證（樣本外）：

    # 只餵前段資料尋優 → 得到 best → 用 best 跑後段，看還成不成立

    分段驗證未通過的參數，即使 optimize 的分數很高也不建議採用。

    多因子輪動（分步寫法）

    多因子輪動各步驟的寫法。這個範例不是可直接執行的完整腳本，請依自己的規格（因子、過濾條件、換股時機、部位）組合各步驟；登入、報表、benchmark、儀表板的寫法同「目標權重輪動」。

    適用的規格：

    • 多個財報／營收因子以 percentile 排名合成分數
    • 排名前先套可交易性過濾
    • 依公告日換股
    • 每檔固定權重

    規格與寫法對照

    規格類型 寫法 說明
    價格門檻（股價 ≥ X 元） raw_close >= X（未還原 日_K.Close） 門檻使用未還原價
    百分比排名過濾（前 X%） rank(axis=1, pct=True) > 1 - X 例如 > 0.4 為前 60%
    財報／營收因子 index_str_to_date() → union → ffill → reindex 月營收在次月 10 日、季報在公告日才可取得；同時遮蔽下市股
    換股日 各頻率公告日 union，to_period('M') 分組取 max 同月取最新的公告日
    每檔 1/N qty = 1/TOP_N（< 1 為比例下單），unit=1 零股 100 萬 / 20 檔 = 5 萬，買不起整張

    股池與日期軸

    k = M.日_K
raw_close, vol = pd.DataFrame(k.Close), pd.DataFrame(k.Volume)   # 未還原價、量(張)
R = raw_close.index                                              # 之後所有矩陣都對齊到這條日期軸
bad = set(M.list['etf']) | set(M.list['KY']) | set(M.list['DR'])
univ = [c for c in raw_close.columns if c not in bad]

    可交易性遮罩

    價格門檻與成交額排名的寫法同「目標權重輪動」。成交額使用未還原 Close，Volume 單位是張，要 ×1000：

    turnover20 = (raw_close[univ] * vol[univ] * 1000).rolling(20).mean()
tradable = (raw_close[univ] >= 價格門檻) & (turnover20.rank(axis=1, pct=True) > 0.4)   # 前 60%

    流動性地板（例如 20 日均成交額不低於 capital×max_w/衝擊比例）等其他可交易性條件，可自行以 MSMP 欄位（如 日_K.成交額_百萬）計算後再與 tradable 取 AND。

    因子對齊到日頻

    月／季資料的 index 是 '2024-03'、'2024-Q1' 這類字串，先轉成公告日，再 union → ffill → reindex。直接 reindex(R) 會因為日期對不上而幾乎全部變成 NaN；先 ffill 再 reindex，才會把公告後的值延續到每一天。

    def to_daily(tbl, col):
    s = pd.DataFrame(getattr(getattr(M, tbl), col).index_str_to_date()).reindex(columns=univ)
    return s.reindex(s.index.union(R)).ffill().reindex(R)

    表名與欄名依 MSMP 資料表與欄位 填寫，必須完全一致（例如 季財報_財務指標 底下的欄位）。

    percentile 合成分數

    先套遮罩再排名（排名母體為可交易的股票），反向因子用 1 - p，缺值填 0.5（中性），等權平均：

    p = to_daily(tbl, col).where(tradable).rank(axis=1, pct=True)
if 反向:
    p = 1.0 - p
score = p.fillna(0.5) if score is None else score + p.fillna(0.5)
# 迴圈跑完所有因子後
score = (score / 因子數).where(tradable)

    現金流量表因子的正負號

    例如 無形資產_增加_減少_CFI，買進記為負數。rank 由小到大排序，負得最多（買進最多）的排名最低，取反向 1 - p 後分數反而最高，等於給無形資產支出多的公司較高分數。要降低支出多的公司分數時使用正向。

    換股日與名單

    公告日從資料本身取：月頻取月營收任一欄、季頻取季財報任一欄的 index_str_to_date() index（下例只是借用欄位取得日期）。

    pub = pd.DatetimeIndex(
    pd.DataFrame(M.月_營收.YoY.index_str_to_date()).index.union(
    pd.DataFrame(M.季財報_財務指標.營業利益率.index_str_to_date()).index))
pub = pub[(pub >= R[0]) & (pub <= R[-1])]
rebal = [d for d in pd.Series(pub, index=pub.to_period('M')).groupby(level=0).max() if d in R]
picks = {d: score.loc[d].dropna().nlargest(TOP_N).index.tolist()
         for d in rebal if score.loc[d].notna().any()}

    換股日之間名單不變，展開成「日 × 股票」的持有表，回測時當作 sig 餵入：

    all_syms = sorted({s for v in picks.values() for s in v})
hold = pd.DataFrame(False, index=R, columns=all_syms)
cur = []
for d in R:
    cur = picks.get(d, cur)
    if cur:
        hold.loc[d, cur] = True

    回測的下單邏輯

    新進名單買 1/N、不在名單全部賣出、續留的不調整：

    class Rotate(bt.Core):
    def on_bar(self, row):
        self.Condition.Global(row['sig'] and self.global_qty == 0, 1 / TOP_N, 0,
                              self.PriceType.market_ioc, None, 'bk')
        self.Condition.Global((not row['sig']) and self.global_qty > 0, -self.global_qty, 0,
                              self.PriceType.market_ioc, None, 'bp')

    每檔一個 Core，餵還原價（adj_Open…adj_Volume），sig 欄由 hold[s] map 過去；bt.config(..., unit=1) 以零股計。五個欄位矩陣要在迴圈前先存成 DataFrame（寫法見「目標權重輪動」的 bars）。組成 core_dic 後的報表、benchmark、儀表板同「目標權重輪動」。

    說明

    • 回測期間：資料長度不是固定值（見 資料期間與頻率），rp.report 的 StartDate／EndDate 即為實際期間。期間短、換股次數少（例如 2 年、二十幾次）不足以證明策略有效。
    • 兩種成交額：日_K.成交額_百萬 是交易所的成交金額（單位百萬）；Close × Volume × 1000 是自行計算的成交額。兩者意義相同（都是未還原），但數字不完全相同。
