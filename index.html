    台美股資料、積木選股與回測

    SnowyOwl 是一個 Python 套件，把行情、歷史資料、 10000+ 組積木條件與一套事件式回測引擎收在同一個 api 物件底下。裝完之後，你的 AI 助理就能直接寫出跑得起來的策略腳本。

    快速開始 API 參考

    資料

    台股 114 張表格與美股表格查詢，以及全市場的日期 × 股票代號矩陣，涵蓋價量、籌碼、基本面與台指期。

    資料總覽 →

    積木選股

    現成的選股條件，填參數就能組合。選完可以拿到等價的 Python，也能直接把訊號餵進回測。

    積木選股概覽 →

    回測

    事件式回測引擎，支援五種委託型別、停損停利與多檔共用資金池，產出 28 項績效指標與互動式報告。

    回測概覽 →
    python
    # 站上 20 日均線的股票，排除 ETF
>>> import snowyowl as so
>>> api = so.login('user@x.com', 'pwd')
>>> con = api.Block.con_tw('今日收盤價<>D日(周月)均線',
...                        operator='>', period=20, table='日_K')
>>> r = api.Block.screener_tw([con], pool=['all', '~etf'])
>>> len(r['dataframe'])
1307

    搭配 AI 助理

    使用手冊同時提供給 AI 助理閱讀。安裝 Agent Skill 後，Claude Code 等 AI 工具就能依照手冊撰寫選股與回測程式。 見 安裝與設定。

    claude plugin marketplace add SnowyOwlStrategy/SnowyOwl
    claude plugin install snowyowl

    給 AI 的文件檔

    llms.txt：手冊索引，每頁一行說明。
    llms-full.txt：全部 43 頁合併成單一檔案。
    snowyowl.md：Agent Skill 原始檔。
