    組合條件

    con_tw()／con_us() 把一個積木和它的參數組成選股條件（dict），交給 執行選股 使用。 指定的參數會依積木的合法值檢查，未指定的參數自動填入預設值。

    語法

    api.Block.con_tw(name=None, **params)     # 台股
api.Block.con_us(name=None, **params)     # 美股

    參數

    參數 型別 說明
    name str／dict 積木名稱、積木代號（例：'o1'），或含 'id' 的條件 dict。積木名稱與代號見 查詢積木
    **params 要指定的參數，未指定的使用預設值。也可以用 id='o1' 指定積木

    回傳

    條件 dict。第一個 key 是積木代號 id，其餘是參數：

    {'id': 'o1', 'operator': '>', 'ohlc_field': 'adj_High', 'percent': 3, 'close_field': 'adj_Close', 'period': 1}
    • 可選參數之後是積木的固定參數（上例的 close_field、period），由積木定義，不能修改。
    • 少數積木的預設值不在合法值中（2026-10-21：台股 20 個、美股 0 個）。要明確指定參數時，請從 查詢積木 列出的合法值中選擇。

    範例

    使用預設值

    api.Block.con_tw('今日收盤價<>開高低P%')
    輸出
    {'id': 'o1', 'operator': '>', 'ohlc_field': 'adj_Low', 'percent': 3, 'close_field': 'adj_Close', 'period': 1}

    指定參數

    api.Block.con_tw('今日收盤價<>開高低P%', operator='>', ohlc_field='adj_High', percent=3)
    輸出
    {'id': 'o1', 'operator': '>', 'ohlc_field': 'adj_High', 'percent': 3, 'close_field': 'adj_Close', 'period': 1}

    參數值也可以寫成中文標籤或字串型數字，例如 ohlc_field='最高價' 等同 ohlc_field='adj_High'，percent='3' 等同 percent=3。 有中文標籤的選項，在 台股積木一覽 的合法值欄顯示為 adj_High（最高價）。

    以代號指定積木

    以下三種寫法結果相同：

    api.Block.con_tw('o1')            # 代號當第一個參數
api.Block.con_tw(id='o1')         # 代號當關鍵字參數
api.Block.con_tw({'id': 'o1'})    # 條件 dict
    輸出
    {'id': 'o1', 'operator': '>', 'ohlc_field': 'adj_Low', 'percent': 3, 'close_field': 'adj_Close', 'period': 1}

    共用代號的積木

    少數積木共用同一個代號，必須用名稱指定：台股 m9、m21、s1、r4，美股 m9、r23。

    以條件 dict 傳入

    con() 也接受條件 dict，會補上預設值與固定參數，並檢查合法值。以下三種寫法結果相同：

    api.Block.con_tw('dataA<>dataB+C', left='日_K.Volume', operator='>', const=3000)
api.Block.con_tw(id='a1', left='日_K.Volume', operator='>', const=3000)
api.Block.con_tw({'id': 'a1', 'left': '日_K.Volume', 'operator': '>', 'const': 3000})

    傳入 dict 時不能再加關鍵字參數。

    修改既有條件

    con() 的回傳值可以再傳回 con()，結果不變：

    c = api.Block.con_tw('今日收盤價<>開高低P%', percent=3)
api.Block.con_tw(dict(c)) == c
    輸出
    True

    要修改其中一個參數，展開後覆寫再交給 con()：

    c2 = api.Block.con_tw({**c, 'percent': 5})

    Note

    合法值檢查只在 con() 進行。直接修改條件 dict（例如 c['percent'] = 4）不會經過檢查，修改參數請透過 con()。

    負值參數

    部分積木的參數代表跌幅或與低點的距離，數值一律為負。傳入正數或負數，結果都會是負值：

    api.Block.con_tw('今日跳空跌>-P%')
api.Block.con_tw('今日跳空跌>-P%', percent=5)
api.Block.con_tw('今日跳空跌>-P%', percent=-5)
    輸出
    {'id': 'o18', 'percent': -3}
{'id': 'o18', 'percent': -5}
{'id': 'o18', 'percent': -5}

    台股有 9 個積木屬於這一類：o10、o12、o14、o18、o20、o23、o28、o36、mfunc1。

    固定參數

    部分積木的參數值由積木本身決定，不列在合法值中，con() 會自動帶入：

    api.Block.get_table_tw()['D日均線斜率<>0.4']
api.Block.con_tw('D日均線斜率<>0.4')
    輸出
    {'id': 'm9', 'period': [5, 10, 20, 60, 120, 240], 'operator': ['<', '>']}
{'id': 'm9', 'period': 20, 'operator': '>', 'value': 0.4}

    固定參數不能指定成其他值；傳入相同的值（value=0.4）則結果不變。2026-10-21 時，台股 44 個、美股 12 個積木有固定參數。

    錯誤處理

    錯誤訊息 原因 處理方式
    ValueError: 找不到積木 '今日收盤價'（market=tw），是不是想找：[…] 積木名稱不存在 改用訊息建議的名稱，或到 查詢積木 搜尋
    ValueError: 積木「今日收盤價<>開高低P%」沒有參數 ['pct']
    可用參數：['operator', 'ohlc_field', 'percent']    		 參數名稱錯誤 改用訊息列出的參數名稱
    ValueError: 積木「今日收盤價<>開高低P%」的參數 percent 不支援 4
    可用：1 / 2 / 3 / 5 / 7 / 9    		 參數值不在合法值中 改用訊息列出的值
    ValueError: 積木「D日均線斜率<>0.4」的參數 ['value'] 已由規格固定，不可指定 指定了固定參數 移除該參數
    ValueError: 編碼 'm9' 對應到多個積木：['D日均線斜率<>0.4', 'D日均線斜率<>-0.4'] 代號對應多個積木 改用積木名稱
    ValueError: 同時指定了積木 'D日均線斜率<>0.4' 和 id='m5'，請擇一 名稱與 id 指向不同積木 只保留其中一個

    con() 檢查的是每個參數是否在合法值內；參數之間的關係（例如上界要大於下界）在執行選股時才檢查。 條件組好後，用 screener_tw() 實際執行一次確認。
