    搭配 AI 使用

    SnowyOwl 的使用手冊也提供給 AI 助理（Claude Code、Cursor、ChatGPT 等）閱讀。把下列檔案提供給 AI，它就能依照手冊撰寫可執行的 SnowyOwl 程式。

    提供給 AI 的檔案

    檔案 用途
    llms.txt 手冊索引：每頁一行說明，AI 依需要再讀全文
    llms-full.txt 全部頁面合併成單一檔案，可直接提供給 AI 或放進專案
    snowyowl.md Agent Skill：AI 撰寫 SnowyOwl 程式時遵循的流程與規則

    安裝 Agent Skill

    Claude Code

    claude plugin marketplace add SnowyOwlStrategy/SnowyOwl
claude plugin install snowyowl

    不使用 plugin 時，也可以直接下載 skill 檔，放進 Claude Code 的指令目錄：

    mkdir -p ~/.claude/commands
curl -o ~/.claude/commands/snowyowl.md https://snowyowlstrategy.github.io/snowyowl.md

    安裝後重新啟動 Claude Code 才會生效。

    其他 AI 工具

    把 snowyowl.md 或 llms-full.txt 加入專案，作為 AI 的參考文件。
