    api.bt

    事件驅動回測引擎。繼承 Core 寫策略、用 config 設定商品規格與成本、用 generate_report 產出績效報告。

    成員摘要

    成員 型別 說明
    Core 類別 策略基底類別，繼承後覆寫 on_bar 等事件
    config(...) 類別 商品規格：稅、手續費、合約乘數、保證金
    generate_report(core_dic, ...) 類別 把跑完的策略彙整成績效報告 rp
    Tools 物件 取分 K 資料、參數尋優

    Core

    class MyStrategy(api.bt.Core):
    def on_bar(self, row):
        ...

    要覆寫的事件

    方法 觸發時機
    on_init(self) 策略建立時一次，初始化參數與狀態
    on_bar(self, row) 每根 K 棒收盤；row 是這根 K 棒的 dict
    on_bar2(self, row) 第二個週期收盤（純訊號，不撮合）
    on_intrabar(self, row) K 棒收盤前、盤中價格變動時
    on_position(self, P) 開倉、加倉、部分平倉時；P 是持倉物件
    on_other(self, row) 對標商品收盤（純訊號）

    方法

    方法 說明
    feed_data(df, args=['DateTime','開盤價','最高價','最低價','收盤價','成交量'], columns=['Settlement']) 餵入 K 棒，逐根觸發事件。args 依序對應時間、開、高、低、收、量欄名；columns 是要帶進 row 的額外欄位
    set_tick_period(freq=60, period=..., need_settlement=True, ...) 用 tick 或分 K 聚合成指定週期
    set_other_period(freq=60, period=..., ...) 設定對標商品的週期
    show_monitor(connect=False) 互動式監控面板

    下單：self.Condition

    方法 說明
    Global(triggered, add_qty, trade_price, trade_type, cancel_triggered, rule, match_uid='') 條件式下單
    set_STL(name, STL) 固定停損（進場價不利 STL%）
    set_PFT(name, PFT) 固定停利（進場價有利 PFT%）
    set_MoveLoss(name, DS) 移動停損（自極值價格回撤 DS%）
    set_TGT_PFT(name, TGT, PFT) 獲利達 TGT% 後，從最高獲利回吐 PFT% 出場

    Global 的參數：

    參數 說明
    triggered True 時送出委託
    add_qty 數量；正＝買、負＝賣。小於 1 的小數代表佔資金比例
    trade_price 委託價；0 為市價
    trade_type 委託型別：self.PriceType.market_ioc／limit_ioc／limit_rod／stop_rod／compel_now
    cancel_triggered True 時取消這筆委託；不需要時傳 None
    rule 規則名稱，報表依此分組
    match_uid 要平掉的持倉 uid；預設為新倉 
    self.Condition.Global(row['sig'] and self.global_qty == 0, 1, 0,
                      self.PriceType.market_ioc, None, '進場')

    狀態屬性

    屬性 說明
    self.global_qty 目前總持倉；正＝多、負＝空、0＝空手
    self.global_realized_point / self.global_unrealized_point 已實現／未實現損益（點數）
    self.positions 持倉 {uid: Position}
    self.orders 未成交委託
    self.row / self.row_list 當根 K 棒／所有已收盤 K 棒
    self.Ind 技術指標（ema、rsi、macd、atr…共 25 個）
    self.char / self.char1 要畫在報告 K 線主圖／副圖的值
    self.tick_map 跳動單位表；台指期設 [(np.inf, 1)]

    詳細說明：撰寫策略、下單與成交

    config

    api.bt.config(name='strategy', symbol='symbol', tax_long=0, tax_short=0,
              daytrade_discount=1, fee=0, unit=1, margin_long=1, margin_short=1,
              lot_size='inf,0,floor,1')
    參數 說明 預設
    name 策略名稱，報告的欄名 'strategy'
    symbol 商品代號 'symbol'
    tax_long / tax_short 進場／出場那一筆的稅率（台股填 tax_short=0.003） 0
    daytrade_discount 當沖稅率折扣 1
    fee 手續費；>= 1 為每口固定金額、< 1 為費率 0
    unit 合約乘數；股票 1（以股計）、台指期 200 1
    margin_long / margin_short 保證金；>= 10 為每口金額、< 10 為成數 1
    lot_size 比例下單時的口數限制 '最大,最小,取整,每幾口' 'inf,0,floor,1'

    generate_report

    rp = api.bt.generate_report(core_dic, margin_call=False, capital=1000000, benchmark=None)
    參數 說明 預設
    core_dic {config: 跑完的策略}，可放多組一起比較 必填
    margin_call 未實現虧損是否計入資金佔用 False
    capital 起始資金（比例下單時生效） 1000000
    benchmark 基準的每日收盤價（dict / Series） None

    rp 的成員

    成員 說明
    rp.report 28 項績效指標（報酬、回撤、Calmar、勝率…）
    rp.daily 每日權益曲線
    rp.trade_detail 逐筆交易（進出場配對、損益、成本）
    rp.trade_main 委託明細
    rp.position 每日持倉
    rp.daily_close 每日收盤價
    rp.dashboard(path=None, view='notebook', page_size=20, unit=1e4, unit_label='萬') 互動式 HTML 報告；view='web' 用瀏覽器開、None 只存檔
    rp.save(path=None) 存成 Excel（六個工作表）
    rp.set_benchmark(data) 事後設定基準 
    rp = api.bt.generate_report({api.bt.config(name='MA', symbol='2330', fee=0.001425, tax_short=0.003): s})
rp.report
rp.dashboard(view='web')

    詳細說明：商品設定與績效報告

    Tools

    方法 說明
    get_fut_ohlc(symbol=None, freq=1, period=[['0845','1345'],['1500','0500']]) 台指期分 K（日盤＋夜盤）
    optimize(my_strategy, search_range, times=50, random_ratio=0.5) 參數尋優，以 Calmar Ratio 評分，回傳最佳參數 dict

    詳細說明：資料與週期、技術指標與參數最佳化
