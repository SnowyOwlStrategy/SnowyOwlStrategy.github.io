    IB 美股

    Interactive Brokers（IB）以 TWS 或 IB Gateway 提供 API 連線。本頁以 Python 套件 ib_async 示範美股下單、查詢部位，並把 SnowyOwl 以 api.USMSMP 算出的目標部位送成委託。 完整功能以 ib_async 文件 與 IB 官方 API 文件為準。

    安裝與連線

    pip install ib_async

    ib_async 連線到本機執行中的 TWS 或 IB Gateway，不直接連 IB 伺服器。連線前先啟動並登入 TWS／IB Gateway，並在 API 設定中：

    • 勾選「Enable ActiveX and Socket Clients」（TWS 預設關閉）
    • 取消「Read-Only API」，否則無法下單
    • 將 127.0.0.1 加入 Trusted IPs
    from ib_async import IB, Stock, LimitOrder, MarketOrder

ib = IB()
ib.connect('127.0.0.1', 7497, clientId=1)    # TWS 模擬帳戶
    參數 預設值 說明
    host '127.0.0.1' TWS／IB Gateway 所在主機
    port 7497 TWS 模擬帳戶為 7497、正式帳戶為 7496；IB Gateway 以其 API 設定中的連接埠為準
    clientId 1 每個連線需使用不同的編號
    readonly False True 為唯讀連線，不能下單

    在 Jupyter 中使用時，先執行 from ib_async import util; util.startLoop()。程式中等待請用 ib.sleep()，不要用 time.sleep()。

    TWS／IB Gateway 需每日重新啟動

    TWS 與 IB Gateway 設計為每日重新啟動，可在設定中開啟自動重啟；每週伺服器重置後需手動重新登入。

    美股下單

    contract = Stock('AAPL', 'SMART', 'USD')
ib.qualifyContracts(contract)               # 補齊合約資訊

order = LimitOrder('BUY', 10, 180.0)        # 限價買進 10 股
trade = ib.placeOrder(contract, order)

while not trade.isDone():
    ib.sleep(1)
print(trade.orderStatus.status, trade.orderStatus.avgFillPrice, trade.filled())
    類別 語法 說明
    Stock Stock(symbol, exchange, currency) 美股合約，exchange 一般用 'SMART'
    LimitOrder LimitOrder(action, totalQuantity, lmtPrice) 限價單，action 為 'BUY'／'SELL'
    MarketOrder MarketOrder(action, totalQuantity) 市價單

    委託可再指定 tif（例如 'DAY'、'GTC'）與 outsideRth=True（盤前盤後），例如 LimitOrder('BUY', 10, 180.0, tif='GTC')。 placeOrder 回傳 Trade 物件，狀態會隨回報自動更新；trade.isDone() 在成交、取消或失效後為 True。

    刪單與查詢

    方法 回傳 說明
    ib.cancelOrder(trade.order) Trade 刪單
    ib.openTrades() list[Trade] 未完成的委託
    ib.fills() list[Fill] 本次連線期間的成交
    ib.positions() list[Position] 部位，欄位 account、contract、position、avgCost
    ib.portfolio() list[PortfolioItem] 部位與市值、未實現損益
    ib.accountSummary() list[AccountValue] 帳戶摘要 
    for p in ib.positions():
    print(p.account, p.contract.symbol, p.position, p.avgCost)

    回報事件

    def on_status(trade):
    print(trade.contract.symbol, trade.orderStatus.status)

def on_filled(trade):
    print('成交', trade.contract.symbol, trade.orderStatus.avgFillPrice)

ib.orderStatusEvent += on_status
trade = ib.placeOrder(contract, MarketOrder('BUY', 1))
trade.filledEvent += on_filled
ib.sleep(5)

    串接 SnowyOwl

    以 下單串接總覽 的美股選股名單 target（代號 → 股數）與 order_diff()，把部位調整成目標部位：

    current = {p.contract.symbol: int(p.position) for p in ib.positions()
           if p.contract.secType == 'STK' and p.position != 0}

for symbol, qty in order_diff(target, current).items():
    contract = Stock(symbol, 'SMART', 'USD')
    ib.qualifyContracts(contract)
    trade = ib.placeOrder(contract, MarketOrder('BUY' if qty > 0 else 'SELL', abs(qty)))

ib.sleep(5)
for t in ib.openTrades():
    print(t.contract.symbol, t.orderStatus.status)
ib.disconnect()

    代號格式

    api.USMSMP 的股票代號與 IB 的代號在一般股票相同；特別股、多類股等代號格式可能不同，送單前以 ib.qualifyContracts 確認合約。
