    Data.get_snapshots 即時快照

    所屬章節：Data 表格查詢 以 2026-08-20 11:11 盤中實際執行結果為準

    Overview

    取一批股票的即時報價快照。這是拉取式的一次性查詢，不是訂閱； 要持續推送請用 api.SWQuote。

    api.Data.get_snapshots(symbols)
    參數 型態 說明
    symbols list[str] 股票代號清單

    回傳 dict[str, Stock]，key 是股票代號。

    Manual Sample Input/Output

    Example 1：取兩檔

    input

    s = api.Data.get_snapshots(['2330', '2317'])
print(type(s).__name__, len(s), list(s))
s['2330']

    output

    dict 2 ['2330', '2317']

Stock(exchange='TWSE', datetime='20260820111140', price=2355.0, volume=1,
      total_volume=5893, bid_price=2355.0, ask_price=2360.0,
      bid_volume=132, ask_volume=365, open_price=2365.0,
      high_price=2370.0, low_price=2350.0, limit_up=2585.0,
      limit_down=2115.0, reference_price=2350.0)

    Example 2：Stock 欄位

    欄位 型態 說明
    exchange str 'TWSE'（上市）/ 'OTC'（上櫃）/ 'ES'（興櫃）
    datetime str 報價時間，格式 yyyyMMddHHmmss
    price float 最新成交價
    volume int 最新一筆成交量
    total_volume int 當日累計成交量
    bid_price / ask_price float 最佳買價 / 最佳賣價
    bid_volume / ask_volume int 最佳買量 / 最佳賣量
    open_price / high_price / low_price float 當日開 / 高 / 低
    limit_up / limit_down float 漲停價 / 跌停價
    reference_price float 參考價（昨收）

    Stock 是 dataclass，可用 dataclasses.asdict() 轉 dict：

    from dataclasses import asdict
asdict(s['2330'])

    Example 3：算漲跌幅

    Stock 沒有漲跌幅欄位，要自己用 price 與 reference_price 算：

    d = s['2330']
change = d.price - d.reference_price
pct = change / d.reference_price * 100 if d.reference_price else 0.0
print(f"{change:+.2f} ({pct:+.2f}%)")

    +5.00 (+0.21%)

    注意

    • 興櫃（exchange='ES'）的 total_volume 單位是「股」，其他交易所是「張」。 要放在同一張表比較時，興櫃要先除以 1000。
    • 盤後執行拿到的是最後一筆收盤快照，datetime 停在收盤時間。
