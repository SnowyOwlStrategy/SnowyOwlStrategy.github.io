    Block.get_table 積木參數與合法值

    所屬章節：積木 Block 以 2026-08-20 實際執行結果為準

    Overview

    回傳每個積木可填的參數與合法值清單。con 只接受這裡列出的值。

    api.Block.get_table_tw()
api.Block.get_table_us()

    沒有參數。回傳 dict：

    {積木名稱: {參數名: [合法值, ...]}}

    台股 402 筆、美股 257 筆。資料來源是 block_spec.json（由 bulid_spec/build_spec.py 從「台股積木API.xlsx / 美股積木API.xlsx」離線產生，再複製進 snowyowl/blocks/）。

    Manual Sample Input/Output

    Example 1：查單一積木能填什麼

    input

    api.Block.get_table_tw()['今日收盤價<>開高低P%']

    output

    {'operator': ['<', '>'],
 'close_field': ['adj_Open', 'adj_High', 'adj_Low'],
 'percent': [1, 2, 3, 5, 7, 9]}

    Example 2：前四筆

    input

    for k, v in list(api.Block.get_table_tw().items())[:4]:
    print(f"{k!r}: {v}")

    output

    '今日收盤價<>開高低P%': {'operator': ['<', '>'], 'close_field': ['adj_Open', 'adj_High', 'adj_Low'], 'percent': [1, 2, 3, 5, 7, 9]}
'今日收盤價距今日最低價 <>-P%': {'percent': [3, 5, 7, 9]}
'今日收盤價(開低高)與近D日內最高價<P%': {'close_field': ['adj_Open', 'adj_High', 'adj_Low', 'adj_Close'], 'period': [5, 10, 20], 'percent': [3, 5, 8, 10, 15, 20]}
'今日收盤價(開高低)與近D日內最低價<-P%': {'close_field': ['adj_Open', 'adj_High', 'adj_Low', 'adj_Close'], 'period': [5, 10, 20], 'percent': [3, 5, 8, 10, 15, 20]}

    無參數的積木會是空 dict：

    input

    api.Block.get_table_tw()['月KD 黃金交叉']

    output

    {}

    Example 3：美股同名積木的參數名稱不同

    input

    api.Block.get_table_us()['今日收盤價<>開高低P%']

    output

    {'operator': ['<', '>'],
 'field1': ['Open', 'High', 'Low'],
 'percent': [1, 2, 3, 5, 7, 9]}

    台股叫 close_field、美股叫 field1，值也不同（台股是還原價 adj_*， 美股是未還原 Open/High/Low）。同名積木不能假設參數一致，兩邊都要各查一次。

    Example 4：搜尋積木

    get_table 的 key 就是積木名稱，直接用字串比對即可：

    input

    [n for n in api.Block.get_table_tw() if '均線' in n][:5]

    output

    ['D日均線糾結<P%',
 '均線連三日持續向上(下)',
 'D日均線<>T日均線',
 'D日均線<>T日均線<>H日均線',
 '今日收盤價<>D日(周月)均線']

    完整清單（含每個積木的邏輯說明、預設值）見 台股積木完整參考、美股積木完整參考。
