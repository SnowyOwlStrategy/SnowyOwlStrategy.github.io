    選股程式碼

    screener_tw()／screener_us() 回傳的 r['code'] 是這組條件的等價 Python 程式碼，可用於：

    • 確認積木實際的計算方式
    • 貼進回測腳本或自己的流程，不必經過 api.Block
    • 作為範本改寫成自訂條件

    程式碼可以獨立執行：作用域中只要有已登入的 api 就能執行，不需要任何 import。 程式碼開頭以 msmp = api.MSMP（美股為 usmsmp = api.USMSMP）取得資料，用到的輔助函式直接以函式定義寫在程式碼中，只包含這組條件實際用到的部分。 執行完成後留下變數 sig，即訊號矩陣。

    程式碼結構

    程式碼依序包含以下段落，沒用到的段落會省略：

    段落 內容
    msmp = api.MSMP 資料來源。美股為 usmsmp = api.USMSMP
    # Helper functions 這組條件用到的輔助函式定義，見下方「輔助函式」
    # Stock pool 由 pool 參數展開的 msmp.list[...] 運算
    _operators 比較運算子的 lambda 表。crossup／crossdown 是穿越，不是單純比大小
    各積木的運算 一個積木一段，變數名為 sig1、sig2…
    # Combine conditions 套用股池，並把各 sigN 以 & 合併成 sig

    範例

    以下範例的資料日為 2026-09-18。

    取出並閱讀

    b = api.Block.con_tw('日K<>日D', operator='>')
r = api.Block.screener_tw([b])
print(b)
print(r['dataframe'].shape, r['date'])
print(r['code'])
    輸出
    {'id': 't2', 'operator': '>'}
(2004, 5) 2026-09-18 00:00:00

msmp = api.MSMP

# Stock pool
pool = msmp.list['all']

_operators = {
    'crossup': lambda x, y: (x > y) & (x.shift(1) < (y if isinstance(y, (int, float)) else y.shift(1))),
    'crossdown': lambda x, y: (x < y) & (x.shift(1) > (y if isinstance(y, (int, float)) else y.shift(1))),
    '>': lambda x, y: x > y,
    '<': lambda x, y: x < y,
    '>=': lambda x, y: x >= y,
    '<=': lambda x, y: x <= y,
    '==': lambda x, y: x == y,
}

K = msmp.日_技術指標.K
D = msmp.日_技術指標.D
op_func = _operators['>']
sig1 = op_func(K, D)
# sig1 variable is ready

# Combine conditions
sig1 = sig1.loc[:, sig1.columns.isin(pool)]
sig = sig1

    執行程式碼

    命名空間只需提供 api，其餘由程式碼建立：

    ns = {'api': api}
exec(r['code'], ns)

sig = ns['sig']
print('sig shape =', sig.shape)
print('最後一列 True 檔數 =', int(sig.iloc[-1].sum()))
print('screener 回報檔數  =', r['dataframe'].shape[0])
    輸出
    sig shape = (1000, 2874)
最後一列 True 檔數 = 2004
screener 回報檔數  = 2004

    執行 code 的結果與 screener_tw() 相同。執行後命名空間中的名稱：

    ['api', 'msmp', 'pool', '_operators', 'K', 'D', 'op_func', 'sig1', 'sig']

    美股

    美股的程式碼以 usmsmp = api.USMSMP 開頭，同樣只需提供 api：

    b = api.Block.con_us('今日收盤價<>開高低P%',
                     operator='>', field1='Open', percent=1)
r = api.Block.screener_us([b])

ns = {'api': api}
exec(r['code'], ns)
sig = ns['sig']

    美股沒有股池，程式碼中沒有 # Stock pool 段落。

    多個條件

    兩個條件時，# Combine conditions 段落為：

    # Combine conditions
sig = sig1 & sig2
sig = sig.loc[:, sig.columns.isin(pool)]

    & 是 pandas 的逐元素 AND，兩個矩陣的 index 與 columns 會自動對齊。 不同頻率（日／月／季）的積木在選股時已先以聯集日期與向前填補對齊，產生的程式碼反映對齊後的結果。

    輔助函式

    通用積木（a1／a2／a3）與部分原生積木會用到輔助函式，這些函式以原始碼的形式寫在 code 中，不從 SnowyOwl 匯入：

    b1 = api.Block.con_tw(id='a1', left='日_K.Volume', operator='>', const=3000)
b2 = api.Block.con_tw(id='a1', left='日_三大法人.三大法人買賣超_張數',
                      operator='>', const=300, rank=30)
r = api.Block.screener_tw([b1, b2], pool=['tse', 'otc', '~etf'])
print(r['code'])

# Helper functions
def _continue(sig, days):
    """連續 days 根都成立。days<=1 時原樣回傳。"""
    if days is None or days <= 1:
        return sig
    return sig.rolling(days).sum() == days

def index_str_to_date(df):
    """月/季/年頻的字串 index 轉成日頻公告日；日頻與常數原樣回傳。"""

    return df.index_str_to_date().ffill()

    _continue 積木有 continue_days 參數

    積木名稱與實際計算

    積木名稱是條件的簡述，實際的計算方式以 code 為準。選股結果與預期不同時，可以印出 r['code'] 確認計算內容。

    例如台股 漲跌幅介於P1%到P2%之間（o6）的名稱沒有寫出期間，實際計算的是近 period 日的漲跌幅：

    參數 說明
    period 計算漲跌幅的天數，合法值 1／5／10／20／60／120／240，預設 20。當日漲跌幅請指定 period=1
    percent1 上界
    percent2 下界。percent1 須大於 percent2 
    api.Block.con_tw('漲跌幅介於P1%到P2%之間', percent1=9, percent2=5, period=1)   # 當日漲跌幅介於 5% 到 9%

    美股同名積木的參數是 percent_lower／percent_upper，計算的是當日漲跌幅的絕對值。
