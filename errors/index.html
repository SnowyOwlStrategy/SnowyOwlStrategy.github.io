    錯誤訊息

    依功能列出常見的錯誤訊息、原因與處理方式。錯誤訊息為 2026-08-21 實際執行時顯示的內容。

    積木 api.Block

    con_tw()／con_us() 檢查每個參數是否在合法值內，參數之間的關係在 screener_tw()／screener_us() 執行時檢查。

    錯誤訊息 原因 處理方式
    ValueError: 找不到積木 '不存在的積木'（market=tw） 積木名稱不存在 使用 get_table_tw()／get_table_us() 中的積木名稱，可用關鍵字搜尋：[n for n in api.Block.get_table_tw() if '關鍵字' in n]。名稱相近時，訊息會附上建議的積木名稱
    ValueError: 積木「…」沒有參數 ['pct'] 參數名稱錯誤，或該積木沒有這個參數 以 api.Block.get_table_tw()['積木名稱'] 查看可用參數
    ValueError: 積木「…」的參數 percent 不支援 4 參數值不在合法值中 參數值要從合法值中選擇，合法值以 api.Block.get_table_tw()['積木名稱'] 查看。少數積木的預設值不在合法值中（2026-10-21：台股 20 個）
    ValueError: 積木「…」的參數 ['value'] 已由規格固定，不可指定
    value = 0.4    		 指定了固定參數。固定參數的值由積木定義，con() 會自動帶入 移除該參數；傳入相同的值不會報錯。2026-10-21 時，台股 44 個、美股 12 個積木有固定參數
    ValueError: percent1 (5) must be greater than percent2 (7) o6（漲跌幅介於P1%到P2%之間）的 percent1 是上界、percent2 是下界，percent1 必須大於 percent2 較大的值填入 percent1
    TypeError: Block.screener_us() got an unexpected keyword argument 'pool' 美股不提供股池，screener_us() 沒有 pool 參數 自行篩選結果的欄位（股票代號），見 美股矩陣資料 USMSMP
    IndexError: list index out of range 傳入空的積木清單（screener_tw([])） 至少傳入一個積木條件

    表格查詢 api.Data／USData

    錯誤訊息 原因 處理方式
    ValueError: 找不到 table: 不存在的表 表名不存在 表名須與 get_table() 列出的名稱完全一致，包含全形括號與斜線。部分表名以「取得」開頭（例如 取得個股內外盤…），部分沒有（例如 個股營收資訊…）
    ValueError: 參數輸入錯誤，正確用法：Data.get('…', '2330') 參數個數不符，少傳或多傳都會出現此訊息 依訊息中的正確用法修改
    ValueError: 參數輸入錯誤，正確用法：Data.get('取得即時分K(最後交易日)', '2330', 1) # minutes 可選: [1, 3, 5, 15, 30, 60] 分 K 表缺少 minutes 參數 補上 minutes。各分 K 表是否需要 minutes 不同，見 盤中與分 K
    KeyError: 'symbol' 產業個股清單 的 sector 值不在合法值中 sector 填 台股產業對照表 的 指數彙編分類（172 種）。例如 '半導體' 不是合法值
    KeyError: '內盤' 內外盤資料的欄名是簡體字 内盤 使用 df['内盤']
    IndexError: positional indexers are out-of-bounds 股票代號不存在（例如 '999999'） 先以 上市櫃/ETF清單(含當沖限制) 或 api.MSMP.INFO 確認代號

    矩陣資料 api.MSMP／USMSMP

    錯誤訊息 原因 處理方式
    AttributeError: '_融資券' object has no attribute '融資餘額' 欄位名稱錯誤。融資券的欄名帶單位：融資餘額_張、融券餘額_張 欄位名稱見 MSMP 資料表與欄位
    AttributeError: '_MSMP' object has no attribute '日_不存在' 表名不存在 表名見 MSMP 資料表與欄位（台股 25 張、美股 10 張）
    ValueError: cannot reindex on an axis with duplicate labels MSMP.list['all'] 含一個重複代號（'7834'），作為 DataFrame 的 columns 時產生此錯誤 先去除重複：list(dict.fromkeys(api.MSMP.list['all']))。以 isin() 篩選不受影響。股池說明見 股池

    回測 api.bt

    錯誤訊息 原因 處理方式
    RuntimeError: 還沒有任何 K 棒就下單了 (self.row 是空的)。Condition.Global 只能在 on_bar / on_intrabar / on_position 裡呼叫，on_init 只用來初始化參數。 在 on_init 中下單 on_init 只設定參數與狀態容器，下單放在 on_bar、on_intrabar 或 on_position。見 撰寫策略
    RuntimeError: make_daily: 每日損益全為 0，無法產生報表。…常見原因是 pandas / numpy 版本不相容… 資金不足以買進一個交易單位時部位為 0，每日損益全為 0，產生此訊息 提高 capital、減少檔數，或改用單價較低的標的。台股一張為 1000 股。見 商品設定與績效報告
    AttributeError: 'generate_report' object has no attribute 'trade' generate_report 沒有 trade 屬性 逐筆交易使用 rp.trade_detail
