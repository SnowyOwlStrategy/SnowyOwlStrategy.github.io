    SWQuote.set_cb 行情回呼與 SWMarketData

    所屬章節：即時行情 以 2026-08-21 盤中實際執行結果為準（StarWaveQuoteAPI 1.0.0.4 / DLL build Jul 31 2026） 六種 data_type 全部實際收到，欄位表由 summary() 的真實輸出反推

    Overview

    api.SWQuote.set_cb(callback)      # callback(data: SWMarketData) -> None

    先 set_cb 再 subscribe，否則資料來了沒有人接。 set_cb 是覆蓋不是累加——再呼叫一次就換掉前一個回呼。

    回呼在背景執行緒觸發。要更新共享狀態或 UI 請自己加 lock：

    import threading
lock = threading.Lock()
book = {}

def on_quote(d):
    with lock:
        book[d.symbol] = d.close

api.SWQuote.set_cb(on_quote)
api.SWQuote.subscribe('2330')

    SWMarketData 欄位

    實測屬性共 19 個（18 個資料欄 + 一個 summary() 方法）：

    欄位 型態 說明
    exchange str 交易所：TWSE / OTC / ES / TAIFEX / TWSEOdd / OTCOdd
    symbol str 商品代號。零股會帶 .Odd 後綴（'2330.Odd'）
    data_type int 0~5，決定哪些欄位這一筆真的有值，見下節
    datetime str HH:mm:ss.SSS，只有時間沒有日期
    open / high / low / close float 當日開高低與最新成交價
    volume int 這一筆的成交量
    total_volume int 當日累計成交量
    bid_prices / bid_volumes list 買方五檔，由內而外（bid_prices[0] 是最佳買價）
    ask_prices / ask_volumes list 賣方五檔，由內而外
    simtrade int 1 = 試撮合（開盤前／收盤前的模擬撮合），不是真實成交
    status_remarks int 8-bit 揭示狀態，用 so.SWQuote_status_remarks() 解
    raise_fall_remarks int 8-bit 漲跌停狀態，用 so.SWQuote_raise_fall_remarks() 解
    delay_time float 資料延遲秒數，即時推送是 0.0
    summary() method 回傳只含「這個 data_type 真正帶有的欄位」的 JSON 字串

    成交量單位隨市場不同：整股（TWSE/OTC）是張，零股（TWSEOdd/OTCOdd）是股。 下面 Example 1 的零股 total_volume=400904 是 40 萬股、約 400 張。

    data_type：哪些欄位這一筆才有值

    這是最容易踩的地方。 SWMarketData 永遠有全部 18 個屬性， 但一筆 Orderbook 更新裡的 close 只是上一次的殘值，不是「現在成交在這個價」。 summary() 只吐出該類型真正攜帶的欄位，可以拿它當權威判斷。

    data_type 名稱 意義 這一筆真正帶的欄位
    0 Snapshot 訂閱瞬間的完整快照 全部（OHLC + 量 + 五檔 + 兩個 remarks）
    1 Orderbook 五檔更新 bid_*、ask_*、status_remarks、raise_fall_remarks
    2 MatchInfo 這一筆成交 close、volume、兩個 remarks
    3 TotalMatchInfo 累計量更新 total_volume、兩個 remarks
    4 DayHighLow 日內高低更新 high、low
    5 OpenInfo 開盤價更新 open

    實測 25 秒訂閱三檔（2330 整股／零股、2317 整股）的分布： data_type=1 最多（五檔跳動最頻繁），其次 2 與 3 成對出現，0 只在訂閱瞬間各一筆， 4 / 5 很稀少（只在高低點或開盤更新時）。

    status_remarks / raise_fall_remarks 解碼

    兩個都是 8-bit 整數（0~255）。snowyowl 頂層直接匯出解碼函式，不必自己拆位元：

    import snowyowl as so
so.SWQuote_status_remarks(num)        # 揭示狀態
so.SWQuote_raise_fall_remarks(num)    # 漲跌停狀態

    只有 TWSE / OTC / TWSEOdd / OTCOdd 會給這兩個值；期貨（TAIFEX）不提供。

    SWQuote_status_remarks

    bit 鍵 0 1
    bit7 disclosure_type 一般揭示 試算揭示
    bit6 delayed_open False True
    bit5 delayed_close False True
    bit4 matching_method 集合競價 逐筆撮合
    bit3 is_open False True
    bit2 is_close False True

    bit1-0 保留未使用。

    input

    so.SWQuote_status_remarks(16)      # 盤中整股實測到的值

    output

    {'ErrMsg': '', 'raw_value': 16, 'binary_value': '00010000',
 'disclosure_type': {'code': '0', 'label': '一般揭示'},
 'delayed_open':    {'code': '0', 'label': False},
 'delayed_close':   {'code': '0', 'label': False},
 'matching_method': {'code': '1', 'label': '逐筆撮合'},
 'is_open':         {'code': '0', 'label': False},
 'is_close':        {'code': '0', 'label': False}}

    其他實測值：0 全部一般狀態（零股實測到的值）、128 試算揭示、 8 is_open=True、4 is_close=True。

    SWQuote_raise_fall_remarks

    每 2 bits 一組，合法值只有 00 / 01 / 10：

    bit 組 鍵 00 01 10
    bit7-6 trade_status 一般成交 跌停成交 漲停成交
    bit5-4 buy_status 一般買進 跌停買進 漲停買進
    bit3-2 sell_status 一般賣出 跌停賣出 漲停賣出
    bit1-0 disclosure_status 一般揭示 暫緩撮合且瞬間趨跌 暫緩撮合且瞬間趨漲

    input

    so.SWQuote_raise_fall_remarks(136)

    output

    {'ErrMsg': '', 'raw_value': 136, 'binary_value': '10001000',
 'trade_status':      {'code': '10', 'label': '漲停成交'},
 'buy_status':        {'code': '00', 'label': '一般買進'},
 'sell_status':       {'code': '10', 'label': '漲停賣出'},
 'disclosure_status': {'code': '00', 'label': '一般揭示'}}

    兩個函式都不拋例外，用 ErrMsg 判斷

    輸入無效時不會 raise，而是回一個 ErrMsg 非空的 dict，其餘鍵不可信：

    so.SWQuote_status_remarks(None)     # ErrMsg: 'num 不可為空值 (None)'
so.SWQuote_status_remarks('abc')    # ErrMsg: "num 不可為字串，收到 'abc'"
so.SWQuote_status_remarks(256)      # ErrMsg: 'num 超出範圍 (0~255)，收到 256'
so.SWQuote_status_remarks(-1)       # ErrMsg: 'num 超出範圍 (0~255)，收到 -1'
so.SWQuote_raise_fall_remarks(255)  # ErrMsg: "trade_status 代碼未定義，收到 '11'"

    所以取用前要先檢查：

    r = so.SWQuote_status_remarks(d.status_remarks)
if r['ErrMsg']:
    ...   # 不要用 r 的其他欄位
else:
    是逐筆 = r['matching_method']['code'] == '1'

    Manual Sample Input/Output

    Example 1：逐筆成交明細

    只認 data_type==2，因為只有它帶著「這一筆」的價與量：

    trades = []

def on_tick(d):
    if d.data_type == 2:
        trades.append({'time': d.datetime, 'symbol': d.symbol,
                       'price': d.close, 'volume': d.volume})

api.SWQuote.set_cb(on_tick)
api.SWQuote.subscribe('2330')

    Example 2：五檔價差

    def on_book(d):
    if d.data_type in (0, 1) and d.bid_prices and d.ask_prices:
        bid, ask = d.bid_prices[0], d.ask_prices[0]
        print(f'{d.symbol} 買 {bid} / 賣 {ask} / 價差 {ask - bid:.2f}')

api.SWQuote.set_cb(on_book)
api.SWQuote.subscribe('2330')

    Example 4：監控延遲

    def on_delay(d):
    if d.delay_time > 0.5:
        print(f'{d.symbol} 延遲 {d.delay_time:.3f}s')

    注意

    • set_cb 要在 subscribe 之前，而且是覆蓋式的。
    • 回呼在背景執行緒跑；裡面不要做慢的事（畫圖、寫 DB），先丟進 queue。
    • datetime 是字串且沒有日期，要完整時間戳得自己補當天日期。
    • 屬性永遠存在但值可能是舊的——先看 data_type 或直接用 summary()。
    • exchange 決定成交量單位（整股張／零股股）與有沒有 remarks（期貨沒有）。
    • 訂閱與連線層級的事件（連上、登入、斷線）走 set_event，見 swquote-event.md。
