    快速開始

    SnowyOwl 是台股與美股的 Python 資料套件，提供歷史資料查詢、積木選股與回測。 安裝並登入後，所有功能都從登入取得的 api 物件使用。

    安裝

    SnowyOwl 需要 Python 3.10 以上（3.10～3.14 可用），以 SnowyOwl 提供的 wheel 檔安裝。 依作業系統安裝對應的檔案；macOS 的檔案 Intel 與 Apple 晶片通用，Intel 晶片需加上 --prefer-binary：

    # Windows
pip install snowyowlstrategy-1.0.0-cp310-abi3-win_amd64.whl

# Linux
pip install snowyowlstrategy-1.0.0-cp310-abi3-manylinux_2_17_x86_64.manylinux2014_x86_64.whl

# macOS（Apple 晶片）
pip install snowyowlstrategy-1.0.0-cp310-abi3-macosx_11_0_universal2.whl

# macOS（Intel 晶片）
pip install snowyowlstrategy-1.0.0-cp310-abi3-macosx_11_0_universal2.whl --prefer-binary

    套件名稱是 snowyowlstrategy，程式中匯入的名稱是 snowyowl：

    import snowyowl as so

    安裝在虛擬環境

    建議安裝在虛擬環境（venv）。資料快取存放在套件目錄（site-packages/snowyowl/）內，該目錄必須可寫入。 快取在首次登入時自動下載，長期使用可能累積數百 MB 到 1 GB。

    登入

    以 so.login() 登入，取得 api 物件：

    import snowyowl as so

api = so.login('user@x.com', 'pwd')
api

Api Instance is ready

    也可以用 Google 或 Apple 帳號登入（so.login(type='google')、so.login(type='apple')），執行後會開啟瀏覽器完成驗證。 登入約需 10～15 秒，期間會下載或更新本機的 MSMP 資料快取。登入方式與登入訊息的說明見 登入與登出。

    入門範例

    以下範例為 2026-08-21 的執行結果（資料日 2026-08-20）。

    查詢漲幅 5% 以上的檔數

    k = api.MSMP.日_K              # index 是日期，columns 是股票代號
t = k.漲跌幅.iloc[-1].dropna()  # 最後一個交易日的漲跌幅
len(t[t >= 5]), str(k.Close.index[-1].date())
    輸出
    (89, '2026-08-20')

    api.MSMP 的每個欄位都是「日期 × 股票代號」的 DataFrame。資料到前一交易日為止，最後一個資料日以 k.Close.index[-1] 取得。 說明見 矩陣資料 MSMP。

    以積木選股

    block = api.Block.con_tw('今日收盤價<>開高低P%',
                         operator='>', ohlc_field='adj_High', percent=3)
result = api.Block.screener_tw([block])
result['date'], result['dataframe'].shape
    輸出
    (Timestamp('2026-08-20 00:00:00'), (2416, 8))

    con_tw() 把積木與參數組成選股條件，screener_tw() 執行選股並回傳 dict，包含 code、dataframe、date、sig 四個 key。 dataframe 是符合條件的股票（一列一檔），date 是結果對應的資料日期。說明見 組合條件、執行選股。

    取得單一標的的歷史資料

    api.Data.get('還原日K價量資料(個股、ETF、大盤)-單檔股票多個區間', '2330').tail(3)
    輸出
    DataFrame shape: (1000, 14)

    api.Data 一次取一張表，回傳欄位為中文名稱的 pandas.DataFrame。 歷史長度不是固定值，各資料可回溯的期間見 資料期間與頻率。

    功能一覽

    命名空間 用途 主要成員 文件
    api.MSMP／api.USMSMP 矩陣式歷史資料（日期 × 股票代號），適合全市場運算、選股與回測 <表名>.<欄位>、get()、get_table() 矩陣資料 MSMP、MSMP 資料表與欄位、美股矩陣資料 USMSMP
    api.Data／api.USData 表格式查詢，一次取一張表。台股 114 張（2026-10-29）、美股 25 張 get()、get_table()；美股另有 get_snapshots() 表格查詢 api.Data、台股資料一覽、美股資料 api.USData
    api.Block 積木選股，台股 416 個、美股 260 個積木 get_table_tw()、con_tw()、screener_tw()（美股為 _us 結尾） 積木選股概覽
    api.bt 回測 Core、config、generate_report、Tools 回測概覽

    各命名空間的方法與參數見 API 參考：snowyowl 與 api。

    選擇合適的功能

    查詢資料用 api.MSMP（單一標的的明細與財報也可用 api.Data），篩選同時符合多個條件的股票用積木 api.Block，驗證交易規則用回測 api.bt。

    需求 使用 頁面
    查詢資料，例如最近交易日漲幅 5% 以上的股票、台積電最近一個月的股價、成交額前 10 名 api.MSMP 矩陣資料 MSMP、資料期間與頻率
    查詢單一標的的明細、財報、分 K api.Data／api.USData 資料總覽
    篩選同時符合多個條件的股票，例如突破 20 日高、外資買超、成交額佔比大於 1% api.Block 積木選股概覽
    驗證一組交易規則的歷史績效 api.bt 回測概覽

    資料範圍

    台股資料包含價量與 K 線、籌碼、基本面、盤中與分 K、券商分點、期貨、清單與事件，分類見 台股資料一覽； 美股資料見 美股資料 api.USData。各資料可回溯的期間見 資料期間與頻率。

    以下資料不提供：

    • 選擇權（台指選擇權、個股選擇權）
    • 匯率（USD/TWD 等外匯行情）。表格中出現的「匯率」是財報項目「匯率變動對現金之影響」。
    • 央行利率。表格中出現的「利率」指殖利率、毛利率等財務比率。
    • 原物料（原油、黃金等）
    • 海外期貨。期貨資料只有台指期（TXF），見 期貨。

    SnowyOwl 不提供即時行情訂閱，也不提供下單與帳務功能。盤中資料以查詢方式取得： 台股以 api.Data.get() 查詢分 K 表（見 盤中與分 K），美股以 api.USData.get_snapshots() 取得即時快照（見 美股資料 api.USData）。
