    USMSMP 美股矩陣資料

    所屬章節：MSMP 歷史資料 以 2026-08-21 實際執行結果為準（台股資料日 2026-08-20、美股 2026-08-19） 10 張表的形狀與期間都是實測值

    Overview

    api.USMSMP 與 api.MSMP 是同一個類別（_MSMP），用法完全相同， 但表格較少、沒有股池與大盤指數，而且各頻率的歷史長度規則和台股不一樣。

    api.USMSMP.日_K.Close
api.USMSMP.get('日_K', 'Close')

    與台股 MSMP 的差異

    成員 api.MSMP（台股） api.USMSMP（美股）
    資料表數 25 10
    list（股池） 有（8 個） 沒有
    INFO 有 沒有
    INDEX 有（D / M / Q） 沒有
    大盤指數 TSE / OTC 有 沒有
    期貨 _fut_TXF 有 沒有
    get / get_table / DataFrame / msmp_to_dic 有 有

    10 張表：欄位、形狀與期間

    月_K 5 (49, 13174) 2022-08-01 ~ 2026-08-01 4.0

    台股的「降頻拿長歷史」在美股不成立

    台股的週／月 K 回溯 11.7 年，比日 K 的 4.1 年長得多，所以問「近十年」可以降頻。 美股不行——週 K 只有 4.5 年、月 K 只有 4 年，跟日 K 差不多。

    問「近 N 年」 台股 美股
    四年內 日頻 日頻
    五 ~ 十年 週／月頻（11.7 年） 只能用季財報（27.8 年）；價格資料沒有
    十年以上 月營收（16.6 年） 季財報（27.8 年）、年股利（34 年）

    美股要長期股價就沒辦法。 價格類（日／週／月 K）最多 4.5 年。 長歷史只存在於財報與股利這兩塊。台股版的對照見 data-history.md。

    覆蓋的股票數也不同

    價格類 13174 檔，財報類只有 5801 檔（股利 5809）。 跨表運算後一定要 .dropna()，否則會拿到一堆 NaN：

    U = api.USMSMP
per = U.季財報_財務指標.本益比            # (111, 5801)
close = U.日_K.Close                     # (1000, 13174)
# 兩者頻率與欄位都不同，不能直接相除

    Manual Sample Input/Output

    Example 1：公開成員

    input

    [n for n in dir(api.USMSMP) if not n.startswith('_')]

    output

    ['DataFrame', 'get', 'get_table', 'msmp_to_dic',
 '季營收', '季股利資訊', '季財報_其他', '季財報_損益表_千',
 '季財報_現金流表_千', '季財報_財務指標', '季財報_資產負債表_千',
 '日_K', '月_K', '週_K']

    台股獨有的 INFO、INDEX、list、TSE、OTC、_fut_TXF 都不在這裡。

    Example 2：矩陣長相

    input

    api.USMSMP.日_K.Close.iloc[-3:, :6]

    output

    DataFrame shape: (1000, 13174)

                  A      AA     AAA    AAAA    AAAC    AAAD
date
2026-08-14 148.5300 49.9800 24.9600 30.9670 20.0950 49.5900
2026-08-17 148.4500 51.7100 24.9500 30.9550 20.0900 49.4950
2026-08-18 148.4400 50.0200 24.9500 30.7000 20.0950 49.4653

    美股矩陣寬 13174 檔（台股 2866）。日_K 比台股多了 買量 / 賣量 / 資金淨流 三欄， 但沒有台股的 adj_* 還原價、成交額_百萬、市值_百萬、漲跌幅。

    美股沒有 漲跌幅 欄，要自己算：U.日_K.Close.pct_change() * 100。

    Example 3：財報（美股最有價值的一塊）

    年季 是字串（'2026-Q2'），不是日期——排序與篩選用字串比較。

    input

    U = api.USMSMP
rev = U.季財報_損益表_千.營業收入['AAPL'].dropna()
{i: f'{v / 1e6:.1f} 十億' for i, v in rev.tail(4).items()}

    output

    {'2025-Q3': '102.5 十億', '2025-Q4': '143.8 十億',
 '2026-Q1': '111.2 十億', '2026-Q2': '109.4 十億'}

    單位是千（美元），÷ 1e6 得十億美元。所有 _千 結尾的表都一樣。

    常用組合：

    U.季財報_財務指標.本益比['AAPL']          # PER 時間序列，回溯到 1998
U.季財報_財務指標.稅後權益報酬率['AAPL']    # ROE
U.季財報_現金流表_千.自由現金流['AAPL']     # FCF
U.季財報_其他.財報發布日['AAPL']           # 做回測時用它避開前視偏誤
U.季股利資訊.殖利率['AAPL']               # 年頻，回溯到 1993

    做回測要用 財報發布日 而不是 年季——2026-Q2 的財報不是 Q2 結束當天就知道的。

    Example 4：沒有股池的後果

    因為沒有 list，積木的美股 screener 不開放 pool：

    input

    api.Block.screener_us(block_list, pool=['all'])

    output

    TypeError: Block.screener_us() got an unexpected keyword argument 'pool'

    要限定範圍請自己切 columns：

    r = api.Block.screener_us([b])
watch = ['AAPL', 'MSFT', 'NVDA']
sub = r['sig'].loc[:, r['sig'].columns.isin(watch)]

    要按產業或市值篩，用 api.USData.get('美股產業對照表')（13187 列， 含 粗產業名稱 / 細產業名稱 / 是否為ETF / 市值(美元)）先取代號清單。 見 usdata.md。

    Example 5：資料日期比台股晚一天

    實測（2026-08-21 執行）：

    api.MSMP   最後日期 = 2026-08-20
api.USMSMP 最後日期 = 2026-08-19

    時區與結算的差異造成的。所以 screener_tw 與 screener_us 的 date 不會相同， 不要假設一致——跨市場比較前先各自取 index[-1] 對齊。

    注意

    • 沒有 漲跌幅 欄，自己用 Close.pct_change() * 100 算。
    • 價格類最多 4.5 年，長歷史只有財報（27.8 年）與股利（34 年）。
    • 財報覆蓋 5801 檔、價格覆蓋 13174 檔，跨表運算後要 .dropna()。
    • _千 結尾的欄位單位是千美元，÷ 1e6 得十億。
    • 成交量 Volume 的單位是股（美股沒有「張」的概念）。
    • 表格式查詢（單檔完整財報、分K、明細）用 api.USData，25 張表。
