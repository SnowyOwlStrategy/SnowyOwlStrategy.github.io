    登入與登出

    使用 SnowyOwl 前要先登入。so.login() 會驗證身分、下載資料快取，並回傳 api 物件，之後所有功能都從這個物件取用。

    語法

    so.login(person_id=None, person_pwd=None, type='account')

    參數

    參數 型別 預設值 說明
    person_id str None 帳號。帳密登入時必填
    person_pwd str None 密碼。帳密登入時必填
    type str 'account' 登入方式：'account'（帳號密碼）、'google'、'apple'

    回傳

    api 物件。資料、選股、回測等功能都掛在這個物件上，見 snowyowl 與 api。

    登入方式

    帳號密碼

    import snowyowl as so

api = so.login('user@x.com', 'pwd')

    帳號與密碼都要提供。缺少任一項時會顯示 [系統訊息] 登錄失敗：帳號或密碼欄位不可為空。，不會登入。 帳密登入每次都會重新驗證，不保留登入快取。

    Google／Apple 帳號

    api = so.login(type='google')     # Apple 帳號：type='apple'

    執行後會開啟瀏覽器，在瀏覽器中選擇帳號完成驗證，不需要在程式裡提供帳密。 驗證結果保存在本機 ~/.snowyowl/auth.json，72 小時內再次登入不必重新驗證。

    登入過程

    登入約需 10～15 秒，期間會下載或更新本機的 MSMP 資料快取。過程中依序顯示：

    輸出
    [2026-08-20 11:05:58] INFO - [v6.4.17]開始執行 TokenManager
[2026-08-20 11:05:58] INFO - 開始執行 貓頭鷹 Token 取得流程
[2026-08-20 11:05:58] INFO - 成功取得 貓頭鷹 Token
正在下載 ...
[系統訊息] MSMP 物件初始化完成。
[系統訊息] USMSMP 物件初始化完成。
[系統訊息] 已將資料存入本地暫存
[系統訊息] API 加載完成，歡迎使用。
    訊息 說明
    正在下載 ... 首次登入或快取過期，正在更新 MSMP 資料
    MSMP 物件初始化完成。 api.MSMP 可以使用
    USMSMP 物件初始化完成。 api.USMSMP 可以使用
    API 加載完成，歡迎使用。 登入程序結束

    api.Data、api.USData、api.bt 在 Token 有效時建立。 若顯示 [系統訊息] Token無效，停止初始化行情與資料，表示身分驗證沒有取得授權。此時只有 api.MSMP 與 api.USMSMP 可以使用，api.Data、api.USData、api.bt 不會建立。

    確認登入結果

    [n for n in dir(api) if not n.startswith('_')]
    輸出
    ['Data', 'MSMP', 'USData', 'USMSMP', 'bt', 'login', 'logout',
 'person_id', 'person_pwd', 'type']

    登出與重新登入

    api.logout()
    輸出
    [系統訊息] 已登出。

    logout() 會清除 api 上的所有功能與本機的登入快取（~/.snowyowl/auth.json），只保留帳號、密碼與登入方式。登出後再存取 api.MSMP 等功能會出現 AttributeError。

    要再次使用時呼叫 api.login()，不帶參數就用原本的身分登入，也可以傳入新的帳號密碼：

    api.login()                            # 用原本的身分重新登入
api.login('other@x.com', 'pwd2')       # 改用其他帳號

    Google／Apple 登入在登出後重新登入，會再次開啟瀏覽器驗證。
