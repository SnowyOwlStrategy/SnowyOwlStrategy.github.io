    回測：技術指標與參數尋優

    所屬章節：回測

    self.Ind — 技術指標工具箱

    self.Ind 是 Core 的類別屬性（所有策略共用同一份），採增量計算： 每根新 K 棒呼叫一次，回傳目前累積的完整序列（list），取 [-1] 就是最新值。

    同一條序列若有多種用途，用 name= 參數區分狀態快取； 不指定時以 window 加資料物件 id 自動區分。

    函式 簽名 備註
    rolling_mean (ls, window, min_period=None, name=None) 移動平均
    rolling_max (ls, window, min_period=None, name=None) 移動最大
    rolling_min (ls, window, min_period=None, name=None) 移動最小
    rolling_std (ls, window, k=1, min_period=None, name=None) ta-lib 相容 STDDEV：母體標準差（ddof=0）× k
    ema (ls, window, alpha=None, name=None) alpha=None → α=2/(N+1) 標準 EMA；alpha=1/N → Wilder 平滑（ATR/RSI 用）
    macd (ls, short_window=12, long_window=26, macd_window=9, name=None) 回傳 macd_dif, macd_ema, macd_hist
    atr (high, low, close, window=14, name=None) ta-lib 相容，Wilder 平滑
    rsi (ls, window=14, name=None) ta-lib 相容
    stochastic (high, low, close, rsv_window=9, k_window=3, d_window=3, name=None) KD，與 pandas ewm(adjust=False) 對齊 
    def my_indicators(self, row):
    self.close_list.append(row['Close'])
    ma5  = self.Ind.rolling_mean(self.close_list, 5)
    ma20 = self.Ind.rolling_mean(self.close_list, 20)
    self.char['ma5']  = ma5[-1]      # 存進 self.char，show_monitor() 就會顯示
    self.char['ma20'] = ma20[-1]
    return ma5[-1], ma20[-1]

    兩個容易踩的地方

    每根 bar 都要呼叫一次。 增量計算的前提是「每來一根就餵一次」， 包在 if 裡條件性呼叫會讓內部狀態跟資料脫節。

    同一條序列不同用途要給 name。 例如同一份 close_list 同時要 5 日與 5 日 （但不同 min_period）的平均，不給 name 會共用同一份快取狀態。

    bt.Tools.optimize — 參數尋優

    bt.Tools.optimize(my_strategy, search_range, times=50, random_ratio=0.5)
    參數 說明 預設
    my_strategy 自訂策略函式，需回傳有 report 屬性的物件（即 generate_report 的結果） 必填
    search_range 參數範圍字典，格式 {'名稱': [最小, 最大, 步長]} 必填
    times 優化總次數 50
    random_ratio 前面隨機探索的比例，之後用智能（TPE）尋優 0.5

    回傳最佳參數 dict。評分函數預設 TotalReturns / abs(MaxDrawdown)。

    def opt(percent_in=2, percent_out=3):
    core = MyStrategy()
    core.percent_in  = percent_in       # 覆寫 on_init 設的 self.xxx
    core.percent_out = percent_out
    core.feed_data(df)
    return bt.generate_report({cfg: core})

arg = {'percent_in': [1, 5, 0.1], 'percent_out': [1, 10, 0.1]}
best = bt.Tools.optimize(opt, arg, times=50)

rp_best = opt(**best)                   # 用最佳參數重跑一次
print(rp_best.report)

    尋優要注意的事

    參數必須是 on_init 裡設的 self.xxx，optimize 才能從外面覆寫。 寫死在 on_bar 裡的常數改不到。

    每次呼叫都要建新的 core。 core 是有狀態的，重複用同一個會累積前一次的部位與統計。

    預設評分是 TotalReturns / abs(MaxDrawdown)（近似 Calmar）。 這個目標偏好高報酬低回撤，但完全不看交易次數—— 可能挑出只交易 3 次剛好都對的參數。自己看 rp.report 的 TotalTrades 檢查。

    尋優本身就是過度配適的來源。 times=50 在兩個參數上已經掃過相當比例的空間， 挑出的最佳值在樣本外不見得成立。至少把資料切成前後兩段分別驗。
