    美股資料 api.USData

    api.USData 以表格形式查詢美股資料：一次取一張表，回傳 pandas.DataFrame。另提供 get_snapshots() 取得即時報價快照。 適合查單一標的的完整財報、分 K 與明細；跨全市場的運算與選股用 美股矩陣資料 USMSMP。

    api.USData api.USMSMP
    形狀 一張表一個主題，欄位是欄名 日期 × 股票代號的矩陣
    適合 單一標的的完整財報、分 K、明細 跨全市場計算指標、選股
    資料日 到前一交易日；盤中表另有即時值 到前一交易日

    語法

    api.USData.get_table(type='print')   # 列出所有表名與參數
api.USData.get(table, *args)         # 取一張表，回傳 DataFrame
api.USData.get_snapshots(symbols)    # 即時快照，回傳 dict[str, Symbol]

    get_table() 與 get() 的參數與回傳和台股相同，見 表格查詢 api.Data。get() 沒有關鍵字參數，全部依 get_table() 標示的順序以位置傳入。

    成交量單位

    美股各表的 成交量 單位是股。台股 api.Data 的成交量是張（1 張 = 1000 股），跨市場比較前先換算。

    資料表

    以下形狀為 2026-08-21 的執行結果（單一股票的表以 AAPL 為例）。

    不需要參數（多檔股票最新時間）

    表名 形狀 欄位

    ROE/ROA-多檔股票最新時間 (5635, 5) 股票代號、股票名稱、年季、ROE-稅後權益報酬率(%)、ROA-稅後資產報酬率(%)
    日K價量資料(個股、ETF)-多檔股票最新時間 (13167, 10) 股票代號、股票名稱、日期、開盤價、最高價、最低價、收盤價、成交量、漲跌、漲跌幅(%)

    美股產業對照表 有 4 個長文字欄（經營概述／產業地位 的中英簡版本），單筆可達數千字。只需要分類時，取 ['股票代號','粗產業名稱','細產業名稱','是否為ETF','市值(美元)'] 即可。

    需要 symbol（單檔股票多個區間）

    表名 形狀（AAPL） 欄位

    月K價量資料(個股、ETF)-單檔股票多個區間 (49, 13) 同週 K
    個股營收資訊-單檔股票多個區間 (110, 14) 年季、單季/累計合併營收(千)、季變動與年成長率、毛利／營益／稅前／稅後／總資產／淨值成長率
    個股資本支出-單檔股票多個區間 (30, 4) 年度、資本支出(千)、固定資產(千)
    個股股利資訊(年)-單檔股票多個區間 (30, 4) 年度、股利合計(元)、殖利率
    季稅後淨利/季稅後EPS-單檔股票多個區間 (114, 6) 年季、日期、公告日、稅後純益(千)、每股稅後盈餘(元)
    季毛利率/季營益率/ROE-單檔股票多個區間 (114, 7) 年季、日期、公告日、毛利率(%)、營業利益率(%)、ROE–稅後權益報酬率(%)
    個股季財報資訊-單檔股票多個區間 (110, 81) 資產負債、損益、現金流量與財務比率，見下方「財報」
    近四季財報加總-單檔股票多個區間 (111, 24) 近四季公告EPS(元)、近四季營收／毛利／淨利／三大現金流、最近一季之加權平均流通在外股數(千) 等
    取得個股內外盤-單檔股票多個區間 (589, 5) 日期、股票代號、買量(股)、賣量(股)、資金淨流
    分價量 (1951, 5) 股票代號、日期、類型、價格、成交量
    取得最新一筆成交明細 (1, 11) timestamp、代號、OHLC、成交量（該筆）、當日成交量、上個交易日的收盤價、漲跌、漲跌幅(%)

    需要多個參數

    表名 參數 形狀
    取得指定日期前幾天的分價量歷史資料 symbol、endDate（yyyyMMdd）、days (62, 4)
    取得全天含盤前盤後歷史分k(最後交易日) symbol、market（F 全天／P 盤前／M 盤中／A 盤後） (946, 8)
    取得歷史1/3/5/15/30/60分K symbol、minutes（1／3／5／15／30／60） (999, 8)

    三張分 K 表的欄位相同：股票代號、日期、hhmm、開盤價、最高價、最低價、收盤價、成交量。日期與時間分為兩欄：日期 是 datetime64[ns]，hhmm 是 4 位字串。

    需要 List[symbol]（批次盤中）

    表名 形狀（傳 2～3 檔） 欄位
    批次取得個股盤中多筆分K (780, 8) 同分 K 表
    批次取得個股盤中最新行情 (3, 10) timestamp、代號、OHLC、當日成交量、上個交易日的收盤價、漲跌、漲跌幅(%)
    批次取得個股盤中內外盤 (2, 5) 日期、股票代號、買量(股)、賣量(股)、資金淨流

    批次表沒有明文的檔數上限，傳入的檔數越多回應越慢；全市場的資料請用 api.USMSMP。

    盤中類的表（分價量、取得最新一筆成交明細、批次*）的值隨盤變動，非交易時段取得的是最後一筆。

    財報

    個股季財報資訊-單檔股票多個區間 共 81 欄，包含：

    類別 欄位舉例
    資產負債 資產(千)、流動資產(千)、現金及約當現金(千)、存貨(千)、負債(千)、股東權益(千) …
    損益 營業收入(千)、營業成本(千)、營業毛利(千)、研究發展費用(千)、稅後純益(千)、EBIT(稅前息前淨利)(千) …
    現金流 營業活動現金流量(千)、投資活動現金流量(千)、籌資活動現金流量(千)、自由現金流(千)、資本支出(千)
    比率 毛利率(%)、營業利益率(%)、稅後權益報酬率(%)、負債比率(%)、流動比率(%)、存貨週轉率單季(次)、股價淨值比、企業價值對EBITDA比率 …
    其他 財報發布日、股價、市值、股數(千)、本益比、每股股息

    只需要 EPS、ROE 或近四季加總時，可用欄位較少的表：

    eps = api.USData.get('季稅後淨利/季稅後EPS-單檔股票多個區間', 'AAPL')   # (114, 6)
roe = api.USData.get('季毛利率/季營益率/ROE-單檔股票多個區間', 'AAPL')  # (114, 7)
ttm = api.USData.get('近四季財報加總-單檔股票多個區間', 'AAPL')          # (111, 24)

    財報表以 年季（字串，例：'2026-Q1'）為時間軸，排序或對齊前先轉換。財報表另有 公告日／財報發布日，回測時以公告日對齊資料，可避免使用到當時尚未公布的財報。

    get_snapshots

    取得一批美股的即時報價快照，為一次性查詢。台股 api.Data 沒有這個方法；台股盤中資料用分 K 與逐筆查詢，見 盤中與分 K。

    參數

    參數 型別 說明
    symbols list[str] 美股代號清單，例：['AAPL', 'MSFT']

    回傳

    dict[str, Symbol]，key 是股票代號。Symbol 是 dataclass，有 9 個欄位：

    欄位 型別 說明
    timestamp str 報價時間，17 位字串 yyyyMMddHHmmssSSS（毫秒）
    open／high／low／close float 當日開／高／低／最新價
    volume int 當日累計成交量（股）
    previousClose float 前一交易日收盤價
    netChange float 漲跌（相對前一交易日收盤）
    percentChange float 漲跌幅（%）

    Symbol 不含五檔買賣價量與漲跌停價。盤後執行時取得的是收盤時的最後一筆快照，timestamp 停在收盤時間（例：160000000 為 16:00）。

    範例

    s = api.USData.get_snapshots(['AAPL', 'MSFT'])
print(type(s).__name__, len(s), list(s))
s['AAPL']
    輸出
    dict 2 ['AAPL', 'MSFT']

Symbol(timestamp='20260910160000000', open=316.67, high=326.74, low=316.51,
       close=326.57, volume=70011913, previousClose=315.34,
       netChange=11.23, percentChange=3.56)

    以 dataclasses.asdict() 轉為 dict：

    from dataclasses import asdict
asdict(s['AAPL'])
    輸出
    {'timestamp': '20260910160000000', 'open': 316.67, 'high': 326.74,
 'low': 316.51, 'close': 326.57, 'volume': 70011913,
 'previousClose': 315.34, 'netChange': 11.23, 'percentChange': 3.56}

    直接讀取漲跌與漲跌幅：

    d = s['AAPL']
print(f"{d.netChange:+.2f} ({d.percentChange:+.2f}%)")
    輸出
    +11.23 (+3.56%)

    錯誤處理

    錯誤訊息 原因 處理方式
    KeyError: '不存在的表' 表名不存在 用 get_table() 確認表名
    ValueError: 參數輸入錯誤，正確用法：
    USData.get('日K價量資料(個股、ETF)-單檔股票多個區間', 'AAPL')    		 參數個數不對（缺少或多傳） 依訊息中的正確用法傳入參數

    表名必須完全一致，包含全形括號與斜線。部分表名以「取得」開頭，例如 取得個股內外盤-單檔股票多個區間；個股營收資訊-單檔股票多個區間 則沒有。
