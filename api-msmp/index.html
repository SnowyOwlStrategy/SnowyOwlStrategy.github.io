    api.MSMP／api.USMSMP

    矩陣式歷史資料：每個欄位是一張 日期（列）× 股票代號（欄） 的 DataFrame，用於全市場的選股、排名與回測。資料存在本機快取，不需要逐檔查詢。

    成員摘要

    成員 型別 說明
    表名.欄位 DataFrame 例：api.MSMP.日_K.Close，日期 × 代號
    get(table, name) DataFrame 同上，用字串指定表與欄位
    get_table() None 印出所有表與欄位
    list dict 股池（全部、上市、上櫃、ETF…）
    INFO DataFrame 全市場代號、名稱、市場、上市日（僅台股）
    INDEX dict 日／月／季的日期序列（僅台股）
    TSE／OTC 物件 加權指數、櫃買指數；另有 _週、_月 版本（僅台股）
    DataFrame(df) DataFrame 把一般 DataFrame 包成可與 MSMP 矩陣運算的型態
    msmp_to_dic(names, *dataframes, startday='20100101') dict 多個矩陣轉成以股票代號為 key 的長表

    台股的表：日_K、日_三大法人、日_融資券、日_指標、日_技術指標、日_CAPM、週_K、週_技術指標、週_大小股東持股、月_K、月_技術指標、月_營收、季財報_損益表_千、季財報_資產負債表_千、季財報_現金流表_千、季財報_財務指標、季股利資訊、其他_大盤、其他_籌碼集中。完整欄位見 MSMP 資料表與欄位。

    成員說明

    表名.欄位

    api.MSMP.日_K.Close

    回傳：DataFrame，index 是日期、columns 是股票代號。

    close = api.MSMP.日_K.Close
close['2330'].tail()          # 單一股票的序列
close.iloc[-1].nlargest(10)   # 最新一天收盤價最高的 10 檔

    Note

    資料到前一個交易日。還原價用 adj_Close 等欄位。

    get

    api.MSMP.get(table, name)
    參數 型別 說明
    table str 表名，例 '日_K'
    name str 欄位名，例 'Close'

    回傳：與 api.MSMP.<table>.<name> 相同的 DataFrame。適合表名、欄位名放在變數裡的情況。

    get_table

    api.MSMP.get_table()

    印出所有表與欄位名稱。

    list

    api.MSMP.list['etf']

    回傳：dict，key 為股池名稱：all、tse、otc、esm、etf、KY、DR、delist；value 為代號清單。詳見 股池 list。

    INFO

    api.MSMP.INFO

    回傳：DataFrame，全市場的 股票代號、股票名稱、日期、市場、ETF、上市日 等欄位。

    INDEX

    api.MSMP.INDEX['D']

    回傳：dict，key 為 'D'（日）、'M'（月）、'Q'（季），value 為日期序列。

    TSE／OTC

    api.MSMP.TSE.Close        # 加權指數收盤
api.MSMP.OTC_週.Close     # 櫃買指數週收盤

    指數的 Open／High／Low／Close／Volume、還原價與 K、D、ADX 等欄位。週、月頻率用 TSE_週、TSE_月、OTC_週、OTC_月。

    DataFrame

    api.MSMP.DataFrame(df)

    把自己算出來的 pandas.DataFrame 包成與 MSMP 矩陣相同的型態，才能與 MSMP 欄位直接運算。

    msmp_to_dic

    api.MSMP.msmp_to_dic(names, *dataframes, startday='20100101')
    參數 型別 說明
    names list[str] 每個矩陣在結果裡的欄名
    *dataframes DataFrame 要合併的矩陣，數量與 names 相同
    startday str 起始日 'yyyyMMdd'

    回傳：dict，key 為股票代號，value 為該股票的長表：每列一個交易日（停牌日已排除），欄位為 date、id、names 指定的各欄，以及自動補上的 adjclose／adjopen／adjhigh／adjlow。適合把矩陣轉成逐檔回測的輸入。

    詳細說明：矩陣資料 MSMP

    api.USMSMP

    美股矩陣資料，用法與 api.MSMP 相同，但沒有 list、INFO、INDEX、TSE／OTC。

    台股以外的表：日_K、週_K、月_K、季營收、季財報_損益表_千、季財報_資產負債表_千、季財報_現金流表_千、季財報_財務指標、季財報_其他、季股利資訊。詳見 美股矩陣資料 USMSMP。
