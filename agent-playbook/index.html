    給 AI 的工作守則（寫 SnowyOwl 程式之前先讀這頁）

    所屬章節：入門 同一份文件、同一段需求，結果好壞差在做事方法，不是 API 知識。 這頁是做事方法；API 細節照連結去查。

    一、五步流程

    步驟 做什麼 查哪裡
    ① 分流 查事實 → api.MSMP 一行算；組條件選股 → 積木；驗規則 → 回測 getting-started.md
    ② 找寫法 先到配方集找用得上的寫法，照規格組合，不要整份照抄。多因子合成看配方八、輪動看配方五、積木進出場看配方二、期貨看配方四 recipes.md
    ③ 規格逐條對應 每一條規格先找積木；做不到才手寫，並在程式註解寫「積木做不到：原因」 block-reference-tw.md、block-auto.md
    ④ 執行 寫完一定要跑。報錯就修、數字不合理就查。不能執行時要明說「未執行」，不要把沒跑過的程式當成品交出去 errors.md
    ⑤ 交付 print(rp.report) ＋ 打開儀表板 見第三節

    二、寫法鐵則（違反任何一條，數字就是錯的）

    規則 錯了會怎樣
    回測一律用 api.bt（api.bt.Core 寫策略、api.bt.generate_report 出報表），跑完一律產儀表板並打開 rp.dashboard(path=..., view='web') 自己用 pandas 算報酬，成本、成交價、報表都跟框架對不上；沒有儀表板，使用者看不到權益曲線與逐筆交易
    欄名照 msmp-tables.md 一字不差（ROA_稅後資產報酬率、公告累計EPS_元、無形資產_增加_減少_CFI…） AttributeError
    月／季頻一律 index_str_to_date() 轉公告日 用到未公告的資料（未來函數）、混進下市股
    對齊用 union → ffill → reindex，不要直接 reindex 公告日對不上換股日，整片 NaN
    先套可交易遮罩再排名 排名母體含買不到的股票
    反向因子 1 - p，缺值填 0.5 用負號會讓排名方向錯；缺值填 0 會懲罰沒資料的股票
    價格門檻、成交額用未還原 Close；Volume 是張要 ×1000 門檻差好幾倍、成交額差 1000 倍
    日 K 從 api.MSMP 取，不用 bt.Tools.get_stock_ohlc 頻率跟積木 sig 對不上
    輪動用 qty = 1/N（百分比路徑）；小資金 unit=1（零股） 固定口數時 capital 不參與計算；整股買不起被夾成 0
    台股只填 tax_short=0.003（ETF 0.001），tax_long=0 證交稅收兩次
    指標寫進 self.char（主圖）／self.char1（副圖） 就會畫在 show_monitor() 與 rp.dashboard() 的 K 線，不用自己改 HTML

    三、交付格式

    1. 程式產出 rp 就收手：print(rp.report) ＋ rp.dashboard(path=..., view='web')（最常用）
2. 回覆時介紹 rp 底下有什麼：dashboard()、report、trade_detail、trade_main、position、daily、daily_close、save()、set_benchmark()
3. 檔案位置（腳本、儀表板 html）

    毛損益、成本佔比、曝險率、前後兩段這類 rp.report 沒有的數字，使用者問了才算，不要每次都加。 程式也一樣盡量乾淨：只寫需求要的計算，不要另外印缺值比例、因子分布、名單、檔數這類東西，除非使用者自己要加工。
