    SWQuote 即時行情（StarWave）

    所屬章節：即時行情 以 2026-08-20 實際執行結果為準（StarWaveQuoteAPI 1.0.0.4 / DLL build Jul 31 2026）

    Overview

    api.SWQuote 是 StarWave 即時行情訂閱。

    api.SWQuote.set_cb(callback)          # 設定行情回呼
api.SWQuote.subscribe(symbol, odd=False)
api.SWQuote.get_subscriptions()
api.SWQuote.unsubscribe(label)
api.SWQuote.unsubscribe_all()
api.SWQuote.set_event(callback)       # 設定連線事件回呼

    SWQuote 的實作是 Quote_sw.py。分三頁：

    頁 內容
    本頁 訂閱／取消、多通道、訂閱上限、頂層匯出的名稱
    swquote-callback.md set_cb 的 SWMarketData 全欄位、六種 data_type 各帶哪些欄位、status_remarks / raise_fall_remarks 解碼
    swquote-event.md set_event 的事件碼與狀態碼全表、具名常數的缺口、斷線重連

    訂閱

    api.SWQuote.subscribe(symbol, odd=False)
    參數 說明
    symbol 商品代號。台股是純代號（'2330'）；期貨要帶月份的完整代碼（'TXFH6'，不是 'TXF'）
    odd True 訂零股（exchange 變 TWSEOdd、symbol 變 '2330.Odd'）。期貨沒有這個概念

    subscribe() 是非同步的：呼叫後立刻返回，資料由 set_cb 的回呼推送。 要先 set_cb 再 subscribe。

    各市場的單位不同，算金額前先確認：

    exchange 標的 價 量
    TWSE / OTC / ES 整股 元 張
    TWSEOdd / OTCOdd 零股 元 股
    TAIFEX 期貨 點 口

    這頁只記 snowyowl 這邊需要注意的差異。

    snowyowl 的差異

    1. 兩套行情來源，SWQuote 需購買

    即時行情有兩套：

    • api.SWQuote（StarWave） —— 介面統一，台股、美股、期貨都走這條。需要另外 購買即時行情權限才會開通：沒購買的帳戶 api 上不會掛 api.SWQuote 這個屬性 （不是 None，是不存在），直接存取會 AttributeError。
    • api.Quote / api.USQuote / api.FutQuote（TradeCom） —— 台股／美股／期貨 分開的舊路徑。介面和 SWQuote 不同：不是一個 subscribe，而是 tick / bidask / all / kbar 四種通道，每種各有成對的 set_cb_X + subscribe_X （subscribe_tick(symbol, odd_lot=False)…；FutQuote 沒有 odd_lot 與 kbar）。

    有 api.SWQuote 就優先用它；沒有才退回 api.Quote 家族。判斷方式：

    if hasattr(api, 'SWQuote'):
    api.SWQuote.set_cb(on_quote)        # 統一介面：一個 callback、一個 subscribe
    api.SWQuote.subscribe('2330')
else:
    api.Quote.set_cb_tick(on_tick)      # 退路：通道成對，set_cb_tick 配 subscribe_tick
    api.Quote.subscribe_tick('2330')

    2. api.SWQuote 是多通道容器

    api.SWQuote 的型態是 SubscribeList，預設保留 10 個通道、延遲初始化。 直接對它呼叫方法會轉發到通道 0；要用其他通道就用索引：

    api.SWQuote.subscribe('2330')       # 通道 0
api.SWQuote[1].subscribe('2317')    # 通道 1

    第一次使用某通道時會印出：

    [系統訊息] 開始訂閱服務初始化 (通道 0)。

    3. 頂層匯出的輔助函式

    snowyowl 頂層直接匯出了行情相關的名稱，不用從子模組拿：

    input

    import snowyowl as so
[n for n in dir(so) if not n.startswith('_')]

    output

    ['Event', 'QuoteData', 'SWEvent', 'SWMarketData',
 'SWQuote_raise_fall_remarks', 'SWQuote_status_remarks',
 'attr', 'login', 'ssl_config']
    名稱 用途
    SWQuote_status_remarks(num) 解析 8-bit 揭示狀態（試撮/延後開收盤/撮合方式/開收盤）
    SWQuote_raise_fall_remarks(num) 解析漲跌註記
    SWEvent / SWMarketData StarWave 的事件與行情資料型態
    QuoteData / Event TradeCom 版（api.Quote 家族）的事件與行情資料型態

    Manual Sample Input/Output

    Example 1：初始訂閱清單為空

    input

    api.SWQuote.get_subscriptions()

    output

    []

    Example 2：訂閱與取消

    input

    def on_quote(data):
    print(data)

api.SWQuote.set_cb(on_quote)
api.SWQuote.subscribe('2330')            # 整股
api.SWQuote.subscribe('2330', odd=True)  # 零股（內部代號變成 '2330.Odd'）
api.SWQuote.get_subscriptions()

    output

    [系統訊息] 開始訂閱服務初始化 (通道 0)。
['TWSE.2330', 'TWSEOdd.2330.Odd']

    回呼收到的是 SWMarketData：

    SWMarketData(exchange=TWSE, symbol=2330, data_type=1, datetime=11:29:44.088,
             open=2365.0, high=2370.0, low=2350.0, close=2355.0,
             volume=2, total_volume=6159,
             bid_prices=[2355.0, 2350.0, 2345.0, 2340.0, 2335.0],
             bid_volumes=[148, 447, 636, 690, 435],
             ask_prices=[2360.0, 2365.0, 2370.0, 2375.0, 2380.0],
             ask_volumes=[548, 434, 573, 598, 441],
             simtrade=0, status_remarks=16, raise_fall_remarks=0, delay_time=0.0)

    bid_prices / ask_prices 是五檔（由內而外），datetime 只有時間沒有日期。 status_remarks 與 raise_fall_remarks 是位元碼，用頂層匯出的 so.SWQuote_status_remarks() / so.SWQuote_raise_fall_remarks() 解碼。

    取消訂閱：

    input

    api.SWQuote.unsubscribe('TWSE.2330')     # label 格式是 'exchange.symbol'
print(api.SWQuote.get_subscriptions())
api.SWQuote.unsubscribe_all()
print(api.SWQuote.get_subscriptions())

    output

    ['TWSEOdd.2330.Odd']
[]

    unsubscribe() 在清空最後一筆訂閱後會自動斷線釋放資源，並觸發一個 disconnected / SW001 事件——那是正常流程，不是錯誤。

    取消一個不存在的 label 不會報錯也不會有任何輸出，所以 label 打錯了你不會知道。要確認就自己比對 get_subscriptions()：

    api.SWQuote.unsubscribe('TWSE.9999')      # 靜默無事發生
assert 'TWSE.9999' not in api.SWQuote.get_subscriptions()

    行情欄位的完整說明見 swquote-callback.md。

    Example 3：商品代碼不存在

    subscribe() 不會拋錯，只印訊息後 return：

    [系統訊息] 商品代碼不存在，請輸入正確商品代碼。

    期貨走 TAIFEX 交易所，不在台股商品表裡也能訂閱，但要帶月份的完整代碼：

    api.SWQuote.subscribe('TXFH6')
api.SWQuote.get_subscriptions()
# ['TAIFEX.TXFH6']

    傳 'TXF'（沒有月份）會被當成不存在的商品代碼。

    Example 4：訂閱上限

    連線成功時 StarWave 會回報各交易所的可訂閱數，實測為 6 個交易所、 每個上限 100 檔：

    OnLoginReply[1:登入成功]
 - ExCount[6]
 -- Exchange1[ES]        Count1[100]
 -- Exchange2[OTC]       Count2[100]
 -- Exchange3[TWSE]      Count3[100]
 -- Exchange4[TAIFEX]    Count4[100]
 -- Exchange5[OTCOdd]    Count5[100]
 -- Exchange6[TWSEOdd]   Count6[100]

    整股（TWSE / OTC / ES）、零股（TWSEOdd / OTCOdd）、期貨（TAIFEX） 各自獨立計算，所以整股訂到 100 檔不會影響零股額度。 需要更多時可用 api.SWQuote[n] 的其他通道。

    注意

    • SWMarketData 有個 summary() 方法，只吐出該 data_type 真正帶有的欄位，debug 時比直接 print 整個物件清楚很多。
    • 訂閱是推送式、需要維持連線。只要一次性報價請用 Data.get_snapshots。
    • api.logout() 會先停掉行情訂閱再清空 api。
