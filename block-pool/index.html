    股池

    股池限定台股選股的範圍，例如只選上市股票，或全市場排除 ETF。 股池名稱與成員來自 api.MSMP.list，也可以直接用來篩選 MSMP 矩陣。

    語法

    api.Block.screener_tw(block_list, pool=['all', '~etf'])

    pool 是股池名稱的清單：

    寫法 選股範圍
    None 或 ['all'] 全市場（預設）
    ['tse'] 上市
    ['otc'] 上櫃
    ['tse', 'otc'] 上市與上櫃。多個不帶 ~ 的名稱取聯集
    ['all', '~etf'] 全市場排除 ETF。~ 前綴表示排除
    ['all', '~etf', '~KY', '~DR'] 可同時排除多個股池

    股池名稱

    以下檔數為 2026-08-20 的數字：

    名稱 檔數 說明
    all 2873 全市場，含已下市股票（2026-10-21 時 delist 的 147 檔全部包含在 all 中）
    tse 1125 上市
    otc 923 上櫃
    esm 412 興櫃
    etf 382 ETF
    KY 143 KY 股（外國企業來台上市）
    DR 14 存託憑證
    delist 145 已下市

    Note

    美股沒有股池：api.USMSMP 沒有 list，screener_us() 也沒有 pool 參數。

    範例

    不同股池的選股結果

    b1 = api.Block.con_tw('今日收盤價<>開高低P%',
                      operator='>', ohlc_field='adj_High', percent=3)
for pool in (None, ['all'], ['tse'], ['all', '~etf']):
    r = api.Block.screener_tw([b1], pool=pool)
    print(f"pool={pool!r:22} -> {r['dataframe'].shape[0]} 檔")
    輸出
    pool=None                   -> 2343 檔
pool=['all']                -> 2343 檔
pool=['tse']                -> 955 檔
pool=['all', '~etf']        -> 2102 檔

    pool=None 與 ['all'] 結果相同。

    查詢股池成員

    api.MSMP.list 是 dict，key 是股池名稱，value 是股票代號清單：

    api.MSMP.list['tse']
api.MSMP.get('list', 'tse')   # 同上

    各股池檔數

    {k: len(v) for k, v in api.MSMP.list.items()}
    輸出
    {'all': 2873, 'tse': 1125, 'otc': 923, 'esm': 412,
 'etf': 382, 'KY': 143, 'DR': 14, 'delist': 145}

    股池成員

    api.MSMP.list['etf'][:5]
    輸出
    ['00400A', '00401A', '00402A', '00403A', '00404A']

    搭配矩陣篩選

    股池成員可以直接用來篩選 MSMP 矩陣的欄位（股票代號）：

    close = api.MSMP.日_K.adj_Close
tse_only = close.loc[:, close.columns.isin(api.MSMP.list['tse'])]

    全市場排除 ETF，與 pool=['all', '~etf'] 的範圍相同：

    mask = ~close.columns.isin(api.MSMP.list['etf'])
no_etf = close.loc[:, mask]

    取不重複的代號清單

    api.MSMP.list['all'] 中代號 '7834' 出現兩次：

    lst = api.MSMP.list['all']
len(lst), len(set(lst))
    輸出
    (2873, 2872)

    用 isin() 篩選不受影響，pool 參數也不受影響。要把清單當作 DataFrame 的 columns 使用時，先去除重複並保持原順序：

    symbols = list(dict.fromkeys(api.MSMP.list['all']))

    未去除重複時，後續 reindex 會出現 InvalidIndexError: Reindexing only valid with uniquely valued Index objects。

    錯誤處理

    錯誤訊息 原因 處理方式
    TypeError（pool） 對 screener_us() 傳入 pool 美股不傳 pool
    InvalidIndexError: Reindexing only valid with uniquely valued Index objects 以含重複代號的 api.MSMP.list['all'] 當 columns 先用 list(dict.fromkeys(...)) 去除重複
